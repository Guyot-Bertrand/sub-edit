# subedit-cli — руководство

<!-- machine-translated -->
> Эта страница переведена машинным способом и ещё не проверена носителем языка.

Программа subedit для командной строки: работа с файлами субтитров без графического
интерфейса, пакетами или из скрипта. О другой программе и о том, с чего
начать, см.
[руководство](../index.md).

> **Текущее состояние.** Все семнадцать подкоманд `subedit-cli` существуют: проверить,
> преобразовать, сдвинуть, пересчитать позиции, изменить тайминг при другой частоте кадров, привязать к сетке кадров, удалить
> пометки для слабослышащих, подогнать длительности, заменить текст, изменить регистр,
> курсив и тире в диалогах, восстановить порядок субтитров, исправить
> тексты по шаблонам Gaupol, соединить файлы один за другим, разрезать
> файл на два и записать перевод в позициях его основного файла. Это руководство
> описывает то, что существует, а не то, что планируется; дальнейшие планы изложены в
> [дорожной карте](../../../../feuille-de-route.md).

## Разделы

| Раздел | Содержание |

| [`transform`](transform.md) | исправить все позиции по двум заведомо верным точкам |

| [`replace`](replace.md) | заменить текст, не повредив тег |

| [`correct`](correct.md) | исправить тексты по шаблонам Gaupol: пометки, объединение и разделение слов, типичные ошибки, заглавные буквы, разбиение на строки |
| [`append`](append.md) | поставить файлы после первого, в один файл |
| [`split-file`](split-file.md) | разрезать файл на два, перенеся хвост к началу отсчёта |
| [`pair`](pair.md) | записать перевод в позициях его основного файла и сообщить, как сопоставились его строки |
| [`config`](config.md) | перечислить, показать и изменить настройки операций, общие с окном |
