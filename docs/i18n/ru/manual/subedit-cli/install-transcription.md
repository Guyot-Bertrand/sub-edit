# Установка инструментов расшифровки

<!-- machine-translated -->
> Эта страница переведена машинным способом и ещё не проверена носителем языка.

Для расшифровки звука в субтитры — [`transcribe`](transcribe.md) в командной строке,
[`Transcribe Audio…`](../subedit-gui/video.md#расшифровка-звука) в окне — нужны три
вещи, которые **subedit не поставляет и не загружает**: движок, модель для этого движка и
`ffmpeg`. Вы устанавливаете их сами и сообщаете subedit, где лежит модель.

**Без них ничего не ломается.** Остальная часть программы работает как прежде; отключается только
расшифровка, с сообщением, которое отсылает сюда.

## Движок: whisper.cpp

[whisper.cpp](https://github.com/ggml-org/whisper.cpp) — это движок, который запускает subedit. Это программа
`whisper-cli`, работающая на обычном процессоре — видеокарта лишь ускоряет её. Соберите её
так, как сказано в её собственной документации (достаточно компилятора C++ и CMake):

```bash
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -B build -DBUILD_SHARED_LIBS=OFF
cmake --build build -j --config Release
```

Программа окажется в `build/bin/whisper-cli`. Собранная с `-DBUILD_SHARED_LIBS=OFF`, как выше, она представляет собой один файл, которому не нужна рядом никакая библиотека, поэтому её можно скопировать куда угодно. Поместите её туда, где её найдёт `PATH`, или **укажите её путь** в subedit настройкой `transcription.executable` — в окне для этого есть поле в [настройках](../subedit-gui/preferences.md#расшифровка). Сборка для видеокарты добавляет одну опцию в первую строку `cmake`: `-DGGML_CUDA=1` для карты NVIDIA, `-DGGML_VULKAN=1` для большинства остальных; subedit запускает ту, что вы установили, и ничего не выбирает за вас.

Чтобы оставить только программу, **установите** её и удалите клон:

```bash
cmake --install build --prefix ~/.local
```

`--prefix` указывает, куда. `~/.local` не требует прав администратора, а его каталог `bin` должен быть в вашем `PATH`; без этой опции по умолчанию используется `/usr/local`, который запрашивает `sudo`. `whisper-cli` окажется в каталоге `bin` этого префикса, рядом с инструментами, которые subedit не использует; когда он там, клон и его каталог `build` можно удалить.

## Модель

Движок читает **модель** — файл размером от нескольких сотен мегабайт до нескольких гигабайт, который вы
загружаете один раз. Официальные модели перечислены на
[huggingface.co/ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp), а
в репозитории движка есть скрипт, который загружает одну из них:

```bash
sh ./models/download-ggml-model.sh small
```

Затем укажите её путь параметром `--model` в командной строке, или настройкой `transcription.model`,
или в [настройках](../subedit-gui/preferences.md#расшифровка) окна, которые его запоминают.

### Модель обнаружения речи, чтобы начинать там, где начинается речь

По желанию **модель обнаружения речи** (Silero) позволяет движку пропускать паузы перед декодированием. Без неё whisper начинает первый субтитр с 0, что бы ни звучало в фильме первым, включая музыку, и округляет свои времена до целых окон; с ней первый субтитр начинается там, где начинается речь, а остальные следуют за ним. В репозитории движка есть скрипт, который её загружает:

```bash
sh ./models/download-vad-model.sh silero-v6.2.0
```

Укажите её путь параметром `--vad-model`, настройкой `transcription.vad-model` или в [настройках](../subedit-gui/preferences.md#расшифровка) окна.

### Какая модель для какого языка

Whisper не меняет модель после того, как нашёл язык: **заданная вами модель определяет, что он
умеет.**

| Модель | Языки | Определяет язык | Размер |
| :---- | :-------- | :------------------- | :--- |
| `tiny`, `base`, `small`, `medium`, `large-v3`, `large-v3-turbo` | около сотни | да | от примерно 75 МБ до примерно 3 ГБ |
| `tiny.en`, `base.en`, `small.en`, `medium.en` | только английский | нет | как у тех же размеров выше |

- **Для любого языка, кроме английского, берите многоязычную модель** — ту, в названии которой нет `.en`. Модель
  только для английского отказывается от другого языка: команда сообщает об этом до начала любой работы.
- **Самые маленькие модели заметно хуже вне английского.** Для французского, немецкого, испанского и
  подобных `small` — минимум, а `medium` или `large-v3-turbo` дают гораздо лучшие результаты ценой
  большего объёма памяти и большего времени.
- **Определение языка настолько хорошо, насколько хороша модель.** Маленькая модель может ошибиться, если начало состоит из
  музыки или тишины; указывайте язык параметром `--language`, когда вы его знаете.

## ffmpeg

[`ffmpeg`](https://ffmpeg.org/download.html) извлекает звуковую дорожку видео, а `ffprobe`, который идёт
вместе с ним, перечисляет дорожки. Установите его менеджером пакетов вашего дистрибутива. Без него аудиофайл,
который движок читает как есть (`wav`, `mp3`, `flac`, `ogg`), всё же можно расшифровать, а видео —
нельзя.

## Проверка работы

```bash
subedit-cli transcribe --model /path/to/ggml-small.bin --output film.srt film.mkv
```

Если чего-то не хватает, сообщение говорит, чего именно, и отсылает на эту страницу.
