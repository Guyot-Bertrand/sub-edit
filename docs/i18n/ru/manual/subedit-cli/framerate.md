# `framerate`

<!-- machine-translated -->
> Эта страница переведена машинным способом и ещё не проверена носителем языка.

> **Это не [`snap`](snap.md).** Эта команда **масштабирует
> файл**: она нужна, когда тайминг неверен и к концу фильма расходится на несколько
> секунд. `snap` возвращает метки времени на ближайшую
> сетку, ничего не меняя в тайминге, и нужен, когда тайминг уже
> верен. У обеих команд одна форма — одна частота кадров или две, — и если их перепутать, то
> ошибки не будет.

```
subedit-cli framerate --from <fps> --to <fps>
                      (--output FILE | --output-dir DIR | --in-place)
                      [--dry-run]
                      [--recursive]
                      <file>...
```

Изменяет тайминг файла, рассчитанного на одну частоту кадров, под другую. Это
операция, которая нужна файлу субтитров, когда он был взят для копии, не
совпадающей с имеющейся у вас копией фильма, например для DVD в PAL при наличии записи в NTSC.

Формат прочитанного файла **сохраняется**: смена формата — задача
[`convert`](convert.md).

<!-- example: subedit-cli framerate --help -->
```console
$ subedit-cli framerate --help
Re-time a file mastered at one frame rate for another
Usage: subedit-cli framerate [OPTIONS] files...

Positionals:
  files TEXT ... REQUIRED     Subtitle files to re-time

Options:
  -h,--help                   Print this help message and exit
  -r,--recursive              Take directories as inputs, and every subtitle file in them
  --from TEXT REQUIRED        Frame rate the file is timed at: 25, 23.976
  --to TEXT REQUIRED          Frame rate to time it for: 24, 29.97
  --output TEXT               File to write, for a single input
  --output-dir TEXT           Directory to write into
  --in-place                  Write back over the inputs
  --dry-run                   Work out and say what would be written, and write nothing
```

## Аргументы и параметры

| Параметр | Обязательный | Значения | По умолчанию |
| :----- | :----- | :------ | :----- |
| `<file>...` | да | один или несколько путей | — |
| `--recursive`, `-r` | нет | флаг | выключен — см. [Обработка дерева каталогов](lots.md) |
| `--from` | **да** | частота кадров, см. ниже | — |
| `--to` | **да** | частота кадров, см. ниже | — |
| `--output` / `--output-dir` / `--in-place` | **один из трёх**, кроме случая `--dry-run` | см. [Запуск](invocation.md#место-назначения) | — |
| `--dry-run` | нет | флаг: вычисляет и сообщает, ничего не записывает — см. [Просмотр перед записью](invocation.md#просмотр-перед-записью) | выключен |

`--from` — это частота кадров, на которую файл **рассчитан**, `--to` — та, на
которую его нужно перевести. Если поменять их местами, файл сместится
в другую сторону (примерно на семь секунд на полнометражном фильме между 25 и
23,976 кадр/с), и ничто не подскажет об этом, пока фильм не будет просмотрен.

## Запись частоты кадров

В кадрах в секунду, допускаются десятичные дроби, разделитель — точка:

```
25      24      23.976      29.97      60
```

**Нулевая или отрицательная частота кадров отвергается**: это не частота кадров.

### Три частоты кадров NTSC невозможно записать точно

`23.976`, `29.97` и `59.94` — это **обозначения**. Частоты кадров, которые они
называют, равны `24000/1001`, `30000/1001` и `60000/1001`, и ни у одной из них нет
конечной десятичной записи. Программа распознаёт их как таковые:

| Что записано | Что обозначает |
| :------------- | :------------------ |
| `23.976` | `24000/1001` — кино, перенесённое на видео NTSC |
| `24` | `24` — кино |
| `25` | `25` — видео PAL и SECAM |
| `29.97` | `30000/1001` — видео NTSC |
| `30`, `50`, `60` | сами себя |
| `59.94` | `60000/1001` |

Распознаётся **значение, а не написание**: `23.9760`
обозначает ту же частоту кадров, что и `23.976`.

Любая другая десятичная дробь понимается буквально: `23.9` не является ничьим
стандартом, и искать в ней скрытый смысл не нужно. Именно поэтому нужна и приведённая выше таблица:
без неё `23.976` означало бы `23976/1000`, и командная строка
говорила бы не то же самое, что окно, об одних и тех же словах.

## Во что превращаются позиции

```
t′ = round( t × (from / to) )
```

Фильм, сведённый с частотой 23,976 кадр/с и воспроизводимый с частотой 25 кадр/с, идёт быстрее,
поэтому его субтитры приходят раньше; в обратном случае они приходят
позже.

**Множитель — точное рациональное число, и округление происходит лишь один раз.** Путь,
который выглядит равноценным (перевод позиции в номер кадра при
исходной частоте, а затем обратно в миллисекунды при выходной), на самом деле
таким не является: он квантует каждую позицию по исходной сетке и ошибается вплоть до
половины кадра, измеренные 21 мс. См.
[ADR 0013](../../../../adr/0013-mise-a-l-echelle-exacte-des-positions.md).

На практике при переходе с 25 на 23,976 кадр/с множитель равен `1001/960`:

| Прочитанная позиция | Записанная | Что дал бы переход через кадры |
| -----------: | -----: | -----------------------------------------: |
| `1 010 ms` | `1 053 ms` | `1 043 ms` |
| `3 600 017 ms` | `3 753 768 ms` | `3 753 750 ms` |

<!-- example: printf '1\n00:00:01,010 --> 00:00:02,020\nUn.\n\n' > a.srt; subedit-cli framerate --from 25 --to 23.976 --output b.srt a.srt; cat b.srt -->
```console
$ printf '1\n00:00:01,010 --> 00:00:02,020\nUn.\n\n' > a.srt; subedit-cli framerate --from 25 --to 23.976 --output b.srt a.srt; cat b.srt
a.srt: 1 subtitle retimed from 25 to 24000/1001 fps -> b.srt
1
00:00:01,053 --> 00:00:02,106
Un.
```

## Вывод

**Стандартный вывод** — пуст: результат — это записанный файл. С `--dry-run` он тоже пуст: файла нет, и строка пояснений сообщает об этом — см. [Просмотр перед записью](invocation.md#просмотр-перед-записью).

| Уровень | Что добавляется в поток ошибок |
| :----- | :------------------------------------- |
| 1 | `<path>: N subtitles retimed from 25 to 24000/1001 fps -> <destination>` |
| 2 | `<path>: SubRip, UTF-8, no BOM, LF line endings kept` — формат, кодировка, метка и символы конца строки прочитанного файла, возвращённые в прежнем виде |
| 3 | `<path>: N bytes read, M written`, затем **каждое диагностическое сообщение чтения** — см. [Запуск](invocation.md#чтение-диагностических-сообщений) |

**Пояснения называют точную частоту кадров, а не введённое обозначение.** Если бы в этой строке было написано
`23.976`, она сообщала бы о преобразовании, которого не было; это
единственное место, где видно, какая из двух величин была использована. Частота кадров,
которую десятичная дробь записывает точно, показывается там как десятичная дробь, остальные — как обыкновенная.

### В формате JSON

С [`--format json`](invocation.md#вывод-пригодный-для-чтения-скриптом) объект каждого файла содержит `counts.subtitles` (все субтитры файла). Полная таблица приведена в разделе [Запуск](invocation.md#что-каждая-подкоманда-помещает-в-counts).

## Коды завершения

Коды самой программы: `0`, если записаны все файлы, `2`, если не записан ни один, `3`, если
записаны лишь некоторые, `1` при ошибке использования.

Ни один отказ не зависит от содержимого файла: две частоты кадров всегда определяют
множитель. Это единственная из подкоманд, записывающих файлы, все отказы которой
происходят до первого чтения.

<!-- example: printf '1\n00:00:01,010 --> 00:00:02,020\nUn.\n\n' > a.srt; subedit-cli framerate --from 0 --to 25 --output b.srt a.srt; echo "code=$?" -->
```console
$ printf '1\n00:00:01,010 --> 00:00:02,020\nUn.\n\n' > a.srt; subedit-cli framerate --from 0 --to 25 --output b.srt a.srt; echo "code=$?"
"0" is not a frame rate: a frame rate must be strictly positive; nothing runs at that speed
code=1
```

## Ошибки

| Что её вызывает | Сообщение |
| :------------------ | :------ |
| нулевая или отрицательная частота кадров | `"…" is not a frame rate: a frame rate must be strictly positive; nothing runs at that speed` |
| десятичная запятая | `"…" is not a frame rate: use a decimal point and not a comma, in every language` |
| текст, не являющийся числом | `"…" is not a frame rate: expected frames per second, like 25 or 23.976` |
| частота кадров несуразной величины | `"…" is not a frame rate: no video runs at that many frames per second` |

**Без одного из трёх параметров места назначения ничего не записывается**, а их
ошибки общие для подкоманд, которые записывают:
см. [Запуск](invocation.md#место-назначения).
