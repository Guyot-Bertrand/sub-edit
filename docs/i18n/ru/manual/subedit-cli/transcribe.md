# `transcribe`

<!-- machine-translated -->
> Эта страница переведена машинным способом и ещё не проверена носителем языка.

```
subedit-cli transcribe --output FILE
                       [--to FORMAT]
                       [--audio-track N]
                       [--language CODE]
                       [--start TIME] [--end TIME]
                       [--suppress-notes | --keep-notes]
                       [--model FILE]
                       [--engine NAME]
                       [--keep-audio FILE]
                       [--raw]
                       <input>

subedit-cli transcribe --list-languages [--model FILE] [--engine NAME]
```

Записывает **речь видео или аудиофайла в виде файла субтитров**. Звук подготавливается и передаётся
движку, который определяет, что и когда сказано, а нарезанные им части объединяются в субтитры,
соблюдающие заданные длительность и длину.

**Ничего из необходимого не поставляется вместе с программой**: движок (whisper.cpp), модель и `ffmpeg`
устанавливает пользователь, который сам указывает, где лежит модель. [Установка инструментов
расшифровки](install-transcription.md) подсказывает, где найти каждый из них и какую модель выбрать. **Их отсутствие ничего
не ломает**: команда сообщает, чего не хватает, со ссылкой на эту страницу, ничего не записывает
и завершается с ненулевым кодом.

- **Входной файл — видео или аудиофайл.** Из видео `ffmpeg` извлекает одну звуковую дорожку; без
  `ffmpeg` аудиофайл, который движок читает как есть (`wav`, `mp3`, `flac`, `ogg`), всё же
  расшифровывается, а видео — нет, как и любой файл, если запрошена дорожка.
- **Только один файл за раз**, а место назначения — `--output`: ни `--output-dir`, ни
  `--in-place` нет, поскольку результат — новый файл, а не переписывание.
- **Язык определяется автоматически**, если его не задаёт `--language`, и использованный язык сообщается. Модель,
  созданная только для английского, ничего не определяет и ничего другого не расшифровывает: язык, который она не
  может принять, отклоняется *до* начала любой работы с указанием предела модели.
- **Язык вводится двумя буквами — `fr`, `en`, `de` — или трёхбуквенным кодом, который указывает файл, `fra`, `eng`;
  он читается как двухбуквенный.** Всё остальное отклоняется до начала любой работы. **Определение языка слушает только
  первые тридцать секунд**: фильм, который начинается с музыки или тишины, могут принять за другой язык, и движок тогда
  записывает речь, *переведённую* на этот язык — французский фильм, принятый за английский, выходит на английском или в виде
  `[SPEAKING FRENCH]`. Если вы знаете язык, укажите его.
- **Можно расшифровать только часть фильма** с помощью `--start` и `--end` — см.
  [Расшифровка части фильма](#расшифровка-части-фильма). Так модель пробуют на двух минутах, прежде чем запускать её на двух часах.
- **Языки, которые предлагает движок, можно перечислить** с помощью `--list-languages` — см.
  [Перечень языков](#перечень-языков).
- **По умолчанию звуки не записываются как заметки**: движку велено этого не делать (`--suppress-notes`; его собственная опция — `--suppress-nst`), поэтому
  `(Sonnerie de téléphone)` или `[MUSIC PLAYING]` не попадают в субтитры ни в круглых, ни в квадратных скобках. `--keep-notes` записывает их, для субтитров для слабослышащих.
  Когда заметки запрещены, движок пишет `...` для отрывка без речи, а **постобработка отбрасывает фрагменты, в которых нет ни буквы, ни цифры** — `...`, `…`, `♪` —
  прежде чем объединять и резать; `--raw` сохраняет их, как пришли фрагменты движка.
- **Сегменты объединяются и режутся** по пределам настроек (`transcription.merge-gap-ms`,
  `transcription.max-duration-ms`, `transcription.max-characters`): две близкие части одного предложения
  становятся одним субтитром, а слишком длинная или слишком широкая часть режется по слову. **`--raw`
  записывает сегменты движка как есть**, по одному на субтитр; так же можно увидеть, что делает
  объединение.

## Аргументы и параметры

| Параметр | Обязательный | Значения | По умолчанию |
| :----- | :----- | :------ | :----- |
| `<input>` | да, кроме `--list-languages` | видео или аудиофайл | — |
| `--output` | да, кроме `--list-languages` | файл субтитров для записи; его каталог создаётся, если отсутствует | — |
| `--to` | нет | краткое название формата: `srt`, `vtt`, `subviewer2`, `ssa`, `ass`, `microdvd`, `mpl2`, `tmplayer`, `lrc` | формат, который указывает расширение `--output`, иначе `srt` |
| `--audio-track` | нет | целое число, начиная с 0: место среди звуковых дорожек видео | `0`, первая |
| `--language` | нет | две буквы, код ISO 639-1: `en`, `fr`; трёхбуквенный код, например `fra`, читается как `fr` | настройка `transcription.language`; пусто: язык определяется автоматически |
| `--suppress-notes` | нет | флаг: не записывать звуки как заметки; отклоняется для движка, которому этого нельзя велеть | настройка `transcription.suppress-notes` |
| `--keep-notes` | нет | флаг: записывать их, вопреки настройке; противоположность `--suppress-notes`, а оба вместе отклоняются | настройка `transcription.suppress-notes` |
| `--list-languages` | нет | флаг: перечислить языки, которые движок предлагает для модели, и ничего не расшифровывать | выключен |
| `--start` | нет | время: `2:00`, `1:02:03`, `2:00.5` или число секунд, `90` | начало звука |
| `--end` | нет | время, записанное так же, как для `--start`; оно должно идти после `--start` | конец звука |
| `--model` | нет | файл модели | настройка `transcription.model` |
| `--engine` | нет | название движка: `whisper.cpp` | настройка `transcription.engine` |
| `--keep-audio` | нет | файл, в котором сохраняется извлечённый звук, как 16-битный моно PCM в файле WAV, с частотой дискретизации, которую запрашивает движок (16 кГц для whisper.cpp); его каталог создаётся, если отсутствует, а имя может содержать `{rate}`, заменяемое этой частотой в герцах (`film.{rate}.wav` записывается как `film.16000.wav`) | звук нигде не сохраняется |
| `--raw` | нет | флаг: записать сегменты движка без объединения и без нарезки | выключен |

**Настройки** читаются из файла настроек так же, как у [`adjust`](adjust.md) — см.
[Файл настроек](invocation.md#файл-настроек), — и у каждой есть свой параметр:

| Ключ | Значение | По умолчанию |
| :-- | :------ | :------ |
| `transcription.engine` | движок | `whisper.cpp` |
| `transcription.executable` | программа движка, абсолютный путь; пусто: ищется в `PATH` | пусто |
| `transcription.model` | файл модели, абсолютный путь | пусто |
| `transcription.language` | язык звука, две буквы; пусто: определяется автоматически | пусто |
| `transcription.suppress-notes` | не записывать звуки как заметки | `true` |
| `transcription.merge-gap-ms` | части одного предложения, расстояние между которыми меньше этого числа миллисекунд, объединяются | `400` |
| `transcription.max-duration-ms` | наибольшая длительность показа субтитра на экране, в миллисекундах | `7000` |
| `transcription.max-characters` | наибольшее число символов в субтитре, без учёта переводов строки | `84` |

## Выбор звука

В видео может быть несколько звуковых дорожек — оригинал, комментарий, другой язык. `--audio-track`
принимает **место среди звуковых дорожек** файла, начиная с 0, в том порядке, в каком их перечисляет файл.
Дорожка, которой в видео нет, отклоняется **с перечислением тех, что есть**, чтобы следующий вызов
был верным:

```bash
subedit-cli transcribe --audio-track 4 --output film.srt --model small.bin film.mkv
```

```text
film.mkv: the video has no audio track 4
audio track 0: fra, Original
audio track 1: eng, Commentary
```

## Расшифровка части фильма

`--start` и `--end` ограничивают работу частью фильма между ними. Можно указать только один из них: один `--start` идёт до конца, один `--end` начинается с начала.

```bash
subedit-cli transcribe --start 2:00 --end 3:30 --output test.srt --model large-v3.bin film.mkv
```

- **Время записывается как `M:SS` или `H:MM:SS`, при необходимости с дробной частью после точки (`2:00.5`), либо как число секунд (`90`, `90.5`)**. Запятая отклоняется, как и везде в инструменте.
- **Субтитры сохраняют время фильма**: реплика, сказанная на 2:10 фильма, записывается как `00:02:10`, а не `00:00:10`. Файл можно накладывать на весь фильм как есть.
- **Границы приблизительны**: движок работает окнами по тридцать секунд, поэтому то, что он возвращает, потом обрезается по диапазону; предложение, попавшее на границу, обрезается там.
- **Ничего не начинается, если диапазон непригоден**: граница, не являющаяся временем, или `--end`, не идущий после `--start`, — это ошибка использования, которая называет проблему, ничего не записывает и не запускает ни `ffmpeg`, ни движок.

Звук всего фильма всё равно извлекается: диапазон экономит расшифровку, которая намного дольше.

## Перечень языков

`--list-languages` выводит языки, которые движок предлагает **для модели**, по одному в строке: код, который принимает `--language`, табуляция и название
языка на языке интерфейса. Ему не нужны ни входной файл, ни выходной, и он ничего не расшифровывает.

```bash
subedit-cli transcribe --list-languages --model ggml-small.bin
```

```text
en	English
zh	Chinese
de	German
…
```

Перечень зависит от движка и от модели: около ста языков для многоязычной модели whisper.cpp, только `en` для модели только для
английского. Движок, который не умеет перечислять свои языки, не выводит ничего. Модель, которая не указана или отсутствует, — ошибка, с указанием на руководство; только
текстовая форма, с [`--format json`](invocation.md#вывод-пригодный-для-чтения-скриптом) ничего не записывается.

## Вывод

**Стандартный вывод** — пусто: результат — это записанный файл.

| Уровень | Что добавляется в поток ошибок |
| :----- | :------------------------------------- |
| 1 | `<input>: N subtitles transcribed, language: xx -> <output>` |
| 2 | этап и ход работы, по одной строке на каждый процент: `extracting the audio…`, затем `transcribing…`, затем `transcribing: 25%, 0:12:30 of 0:50:00, about 38 min left, elapsed: 0:05:12` — процент, достигнутая позиция в звуке, оставшееся время и затраченное время; **строка повторяется каждые десять секунд, если ничего нового не пришло**, чтобы долгое ожидание не приняли за зависание |
| 3 | и каждый новый текст, полученный движком, `last text: …` |

**Процент — это позиция движка в звуке, а не счёт его собственных окон**: движок записывает расшифрованное по мере работы, а команда читает, докуда он дошёл, поэтому цифра движется с первой минуты. (Собственный ход работы движка приходит шагами по 5 % звука, после того как обработано окно в тридцать секунд: сам по себе он может оставаться на 0 % четверть часа на длинном фильме с большой моделью на процессоре.) **Оставшееся время вначале не показывается**: оно выводится, когда сделано достаточно, чтобы экстраполировать, и следует скорости последней минуты, а не среднему за весь прогон.

### В формате JSON

С параметром [`--format json`](invocation.md#вывод-пригодный-для-чтения-скриптом) (глобальный параметр, пишется перед
подкомандой) объект файла содержит использованный язык в `language`, `counts.subtitles` (записанные
субтитры) и `counts.segments` (части движка, из которых они сделаны), а также `audio`, если
`--keep-audio` сохранил звук.

## Уведомления

Одно уведомление выводится на первом уровне, до работы, потому что оно меняет то, чего следует ожидать:

- **С моделью только для английского**: `This model is for English only: whatever language the film
  speaks, the result will be English, or notes in brackets. Choose a multilingual model in the preferences.` Такова модель,
  имя файла которой заканчивается на `.en`.

## Коды завершения

Те же, что у всего инструмента: `0`, если файл записан, `2`, если записать его не удалось — не хватает инструмента или модели,
модель не может принять язык, не удалось извлечение или расшифровка —, `1` при ошибке использования, например
если указан движок, который никто не зарегистрировал, или непригодный диапазон.

## Ошибки

| Причина | Сообщение |
| :---- | :------ |
| программа движка не найдена, или настроенной нет на месте | `the transcription engine was not found`, затем указание на руководство |
| модель не указана, или её нет на месте | `no model was given, or the model file is not there`, затем указание на руководство |
| `ffmpeg` не найден для видео | `ffmpeg was not found, so the audio of a video cannot be extracted`, затем указание |
| дорожка, которой в видео нет | `the video has no audio track N`, затем имеющиеся дорожки |
| язык, который модель не может расшифровать | `the model cannot transcribe the language xx` |
| язык не указан, а модель не умеет его определять | `the model cannot detect the language: give one` |
| движок, который никто не зарегистрировал | `no transcription engine is called NAME` |
| не указан `<input>` или `--output` | `input is required` или `--output is required` |
| `--suppress-notes` вместе с `--keep-notes` | `--suppress-notes and --keep-notes say opposite things; give one of them` |
| `--suppress-notes` для движка, которому этого нельзя велеть | `the engine NAME cannot be told not to write sounds as notes` |
| язык, не являющийся кодом | `"TEXT" is not a language code: write two letters, such as fr, en, de or es` |
| граница диапазона, не являющаяся временем | `"TEXT" is not a time: write it as 2:00, 1:02:03 or 2:00.5, or in seconds` |
| `--end` не после `--start` | `the end of the range must come after its start` |
| любой другой сбой | `the transcription failed`, с тем, что сказал движок |

Указание на руководство — `See the manual page "Installing the transcription tools"
(install-transcription).`
