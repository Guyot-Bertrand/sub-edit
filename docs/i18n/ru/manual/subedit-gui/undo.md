# Отмена и повтор

<!-- machine-translated -->
> Эта страница переведена машинным способом и ещё не проверена носителем языка.

Каждая операция попадает в историю и может быть отменена. Отредактированная ячейка считается
**одной** записью: набор не записывается по нажатиям клавиш, учитывается только
подтверждение.

| Действие | Комбинация клавиш | Где |
| :------- | :---------------- | :-- |
| Отменить | `Ctrl+Z` | меню **«Правка»**, панель инструментов |
| Повторить | `Ctrl+Shift+Z` | меню **«Правка»**, панель инструментов |

## Действие называет то, что отменит

В меню написано не «Отменить», а **«Отменить: редактирование текста»** — по
названию операции, которая будет отменена. Кнопка панели инструментов сохраняет голое слово — иначе
её ширина следовала бы за последней операцией, и она сдвигалась бы под
указателем, — но её подсказка содержит полную подпись.

| Операция | Что читается в действии |
| :------- | :---------------------- |
| отредактированная ячейка текста | `editing a text` |
| начало, конец | `editing a start`, `editing an end` |
| длительность | `editing a duration` |
| вставка строк | `inserting` |
| удаление строк | `removing` |
| сдвиг, включая `Shift Whole File onto Grid` | `shifting` |
| преобразование | `transforming` |
| преобразование частоты кадров | `converting the frame rate` |
| выравнивание по частоте кадров | `aligning on the frame rate` |
| удаление пометок | `removing hearing-impaired mentions` |
| выделение курсивом | `putting in italics` |
| снятие курсива | `taking italics out` |
| смена регистра | `changing the case` |
| добавление, удаление тире | `adding dialogue dashes`, `removing dialogue dashes` |
| объединение строк | `merging` |
| разделение строки | `splitting` |
| вырезанные, вставленные тексты | `cutting texts`, `pasting texts` |
| подгонка длительностей | `adjusting durations` |
| открытие перевода | `opening a translation` |
| добавление файла | `appending a file` |
| разделение проекта | `splitting the project` |
| исправление, принятое в `Correct Texts…` или сделанное `Check Spelling…` | `correcting texts` |
| замена, все замены | `replacing`, `replacing all` |

**Двадцать семь подписей — это всё, что может выдать окно.** Ядро называет
двадцать восьмую — `sorting`, — до которой не дотягивается ни одно действие окна: сортировка
происходит только при строгой политике порядка, а окно открывает свои документы
по мягкой политике, которая сообщает о нарушении порядка, а не исправляет его.

**`Shift Whole File onto Grid` не отличается от сдвига**, и это
верно: это и есть сдвиг, величину которого измерили, а не набрали.

Это те же слова, что и в командной строке: они записаны один раз,
в ядре.

Когда отменять нечего, в действии написано просто «Отменить», **и оно
недоступно**: его комбинация клавиш ничего не делает.

## Отметка об изменении

В заголовке окна стоит отметка, пока файл отличается от файла
на диске, — звёздочка или то, что использует платформа вместо неё. **То же и в
подписи вкладки**, `premier.srt*`: заголовок говорит только о проекте, на
который вы смотрите, а подпись сообщает о тех, на которые вы не смотрите.

**У каждой вкладки своя история.** «Отменить» отменяет только то, что получил проект
текущей вкладки, — включая `Replace All`, выполненную по всем проектам:
она оставляет одну запись в каждом затронутом проекте.

**Отметка исчезает, если отменить всё до исходной точки.** Это не деталь
отображения: число изменений считается, а не записывается как «да» или «нет», так
что возврат может привести его к нулю, и отметка пропадает.

## Две вещи, которые нужно знать

**Точка отсчёта — последнее сохранение** или открытие файла, если
сохранения не было. Сохранение сдвигает её: отметка исчезает, а последующая отмена
возвращает её.

Операция, выполненная после отмены, **стирает то, что можно было повторить**:
повтор воспроизвёл бы команду, исходного состояния которой больше нет. Так ведёт себя
любой редактор, и это сделано намеренно.

**Пока ячейка открыта**, `Undo` и `Redo` — из меню или с панели инструментов —
сначала подтверждают ввод, как и остальные жесты из раздела
[Редактирование ячейки](editing.md). Только что набранное становится последней
записью истории: `Undo` отменяет именно её, а не предыдущую операцию; повторять `Redo`
уже нечего, так как ввод стирает то, что можно было повторить. Открытая
ячейка, в которой ничего не набрано, не оставляет записи: тогда `Undo` отменяет предыдущую
операцию.

История хранит тысячу записей и забывает самые старые сверх этого числа.
