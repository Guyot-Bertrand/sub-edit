# subedit — руководство

<!-- machine-translated -->
> Эта страница переведена машинным способом и ещё не проверена носителем языка.

subedit читает и проверяет файлы субтитров и изменяет их тайминг. Он состоит из двух
программ с общим ядром, а значит, с одними и теми же правилами и одними и теми же словами.

| Программа | Для чего | Руководство |
| :-------- | :-------------- | :--------- |
| `subedit-gui` | открыть файл, увидеть его в таблице, отредактировать, сверить с фильмом | [руководство по окну](subedit-gui/index.md) |
| `subedit-cli` | обрабатывать файлы пакетами, из скрипта, без интерфейса | [руководство по командной строке](subedit-cli/index.md) |

Обе программы читают и записывают **девять форматов** — SubRip, WebVTT, SubViewer 2,
Sub Station Alpha, Advanced SSA, MicroDVD, MPL2, TMPlayer, LRC — и
определяют формат по содержимому, а не по расширению. **Кодировка тоже
определяется по содержимому**: файл в Latin-1, в CP1252 или в UTF-16
открывается, программа сообщает, как он был прочитан, а записывается он обратно в той же кодировке — файл,
который открыли, а затем сохранили без изменений, не отличается ни на байт.

## С чего начать

| Что нужно | Куда обратиться |
| :----------------- | :------- |
| установить программу | [Установка](subedit-cli/installation.md) — подходит для обеих программ |
| открыть файл и посмотреть, что в нём | [Таблица](subedit-gui/table.md) |
| изменить тайминг субтитров, сдвинутых на постоянную величину | [Операции](subedit-gui/operations.md#shift-positions) или [`shift`](subedit-cli/shift.md) |
| изменить тайминг файла, написанного для другой частоты кадров | [`framerate`](subedit-cli/framerate.md), а если тайминг уже верен, то [`snap`](subedit-cli/snap.md) |
| узнать, для какой частоты кадров написан файл | [Сетка кадров](subedit-gui/frame-grid.md) или [`inspect`](subedit-cli/inspect.md) |
| удалить пометки для слабослышащих | [Операции](subedit-gui/operations.md#remove-hearing-impaired-mentions) или [`hearing-impaired`](subedit-cli/hearing-impaired.md) |
| исправить пометки, типичные ошибки, регистр и разбиение на строки за один проход | [`Correct Texts…`](subedit-gui/correct-texts.md) или [`correct`](subedit-cli/correct.md) |
| проверить орфографию слово за словом по словарям системы | [`Check Spelling…`](subedit-gui/check-spelling.md) |
| удлинить субтитры, слишком короткие для чтения | [`Adjust Durations…`](subedit-gui/operations.md#adjust-durations) или [`adjust`](subedit-cli/adjust.md) |
| восстановить порядок в файле, где субтитры идут не по порядку | [`sort`](subedit-cli/sort.md) |
| сделать один субтитр из нескольких подряд идущих частей одного текста | [`Join Repeated Subtitles`](subedit-gui/lines.md#объединение-повторяющихся-субтитров) или [`join-repeats`](subedit-cli/join-repeats.md) |
| привести за один раз в порядок файл с плохой сегментацией, нарушенным порядком и перекрытиями | [`repair`](subedit-cli/repair.md) |
| устранить перекрытия между субтитрами | [`Make Ranges Disjoint…`](subedit-gui/lines.md#устранение-перекрытий-диапазонов) или [`disjoint`](subedit-cli/disjoint.md) |
| соединить встык две части фильма | [`Append File…`](subedit-gui/operations.md#append-file) или [`append`](subedit-cli/append.md) |
| разрезать фильм на две части | [`Split Project…`](subedit-gui/operations.md#split-project) или [`split-file`](subedit-cli/split-file.md) |
| изменить регистр, курсив или тире в диалогах во всём файле | [Операции](subedit-gui/operations.md#italic) или [`case`](subedit-cli/case.md), [`italics`](subedit-cli/italics.md), [`dialogue-dashes`](subedit-cli/dialogue-dashes.md) |
| найти слово и заменить его, не повредив теги | [Поиск и замена](subedit-gui/find-and-replace.md) или [`replace`](subedit-cli/replace.md) |
| записать речь фильма в виде субтитров | [`Transcribe Audio…`](subedit-gui/video.md#расшифровка-звука) или [`transcribe`](subedit-cli/transcribe.md) — после [установки инструментов](subedit-cli/install-transcription.md) |
| пересчитать время файла субтитров по звуку фильма | [`Synchronize with Audio…`](subedit-gui/video.md#синхронизация-со-звуком) или [`sync`](subedit-cli/sync.md) — после [установки инструментов](subedit-cli/install-transcription.md) |
| переводить рядом с исходным текстом | [Открытие перевода](subedit-gui/files.md#открытие-перевода) или [`pair`](subedit-cli/pair.md), чтобы изменить его тайминг по основному файлу |
| обработать сотню файлов сразу | [Обработка дерева каталогов](subedit-cli/lots.md), затем [Запуск](subedit-cli/invocation.md) |

**Между `framerate` и `snap` ошибка остаётся незамеченной.** Если
сомневаетесь, [`snap`](subedit-cli/snap.md#snap--это-не-framerate-и-путаница-между-ними-незаметна)
начинается со сравнения этих двух подкоманд.

## Что обещает это руководство

**Оно описывает то, что существует, а не то, что планируется.** Что будет дальше и
в каком порядке, изложено в [дорожной карте](../../../feuille-de-route.md).

**Это руководство написано на английском языке и переведено.** Переводы повторяют его
страница за страницей и лежат в каталоге репозитория `docs/i18n/`, по одному дереву на язык. Программы
говорят на языке вашей среды; названия, которые они показывают — подкоманды,
параметры, пункты меню, — приведены здесь так, как программа пишет их по-английски.

**Примеры и изображения создаются автоматически, текст — нет.** Блоки
`console` получаются реальным запуском команды; снимки экрана — сборкой
настоящего окна и его фотографированием. Поэтому ни то
ни другое не может описывать инструмент, которого больше нет. Без такой страховки остаётся
только окружающий текст, правильность которого держится на вычитке.

**Снимки экрана показывают обе палитры**, `Light` и `Dark` — те,
что предлагают [параметры](subedit-gui/preferences.md#тема).

## Обе программы говорят одними и теми же словами

Есть причина читать любое из двух руководств, когда пользуетесь другой программой:
сообщения об ошибках, названия форматов, вердикты по сетке и названия
отмены записываются **один раз**, в ядре, и обе программы
цитируют их. Отклонённый файл вызывает одну и ту же фразу с обеих сторон.

Различается то, что умеет каждый интерфейс:

| | `subedit-gui` | `subedit-cli` |
| :--- | :------------ | :------------ |
| несколько файлов сразу | да — одна вкладка на проект | да |
| перевод рядом с основным файлом | да | да — `-t` в текстовых подкомандах и [`pair`](subedit-cli/pair.md), чтобы изменить его тайминг |
| добавить файл, разделить проект | да | да — [`append`](subedit-cli/append.md), [`split-file`](subedit-cli/split-file.md) |
| отмена | да, тысяча записей | неприменимо — на месте без запроса ничего не меняется |
| править текст или позицию вручную | да | нет |
| вставлять, удалять, объединять и разделять строки | да | нет |
| найти и заменить | да | да — [`replace`](subedit-cli/replace.md) |
| вырезать, копировать и вставлять тексты | да | нет |
| подгонять длительности, курсив, регистр, тире | да | да — [`adjust`](subedit-cli/adjust.md), [`italics`](subedit-cli/italics.md), [`case`](subedit-cli/case.md), [`dialogue-dashes`](subedit-cli/dialogue-dashes.md) |
| исправлять тексты по шаблонам | да — `Correct Texts…` | да — [`correct`](subedit-cli/correct.md) |
| проверять орфографию слово за словом | да — `Check Spelling…` | нет |
| смотреть фильм во время тайминга | да | нет |
| записывать поверх входного файла | `Save` | `--in-place` |
