# 根据视频设定时间

<!-- machine-translated -->
> 本页为机器翻译，尚未经过熟悉该语言的读者审校。

*这里假定影片已经打开，并且已了解播放器：参见[播放器](player.md)。*

观看影片，停在某条字幕应当开始的那一帧上，**该位置就成为字幕的开始时间**。共有五个操作，位于**视频**菜单中，沿用 Gaupol 给它们起的名称。它们建立在已有功能之上：设置位置**与在单元格中输入数值是同一个命令**，插入**与 `编辑(E) ▸ 插入字幕…` 相同**。

| 命令 | 快捷键 | 作用 |
| :------ | :------- | :----------- |
| 视频(D) ▸ 根据视频位置设置开始(T) | `Alt+U` | 把选中字幕的**开始时间**设为影片的当前位置 |
| 视频(D) ▸ 根据视频位置设置结束(D) | `Alt+K` | 把它的**结束时间**设为影片的当前位置 |
| 视频(D) ▸ 在视频位置插入字幕(I) | `Alt+J` | 插入一条**从该位置开始**的字幕，并选中它 |
| 视频(D) ▸ 从视频位置选择上一条 | `Alt+Up` | 选中最后一条**开始时间早于**该位置的字幕 |
| 视频(D) ▸ 从视频位置选择下一条 | `Alt+Down` | 选中第一条**开始时间晚于**该位置的字幕 |

**没有打开视频时，这些操作全部被禁用**，与播放器的操作一样。在没有选中任何内容时，`Set Start…` 和 `Set End…` 也被禁用：它们作用于选区的**第一行**。

**快捷键沿用 Gaupol 的，并加上 `Alt`**：在 Gaupol 中它们是 `U`、`K` 和 `J`——单独的字母，窗口会先于正在编辑的单元格处理它们，这样在文本中输入一个 `k` 就会设置一个结束时间。`Select Previous…` 和 `Select Next…` 在 Gaupol 中是 `Ctrl+Y` 和 `Ctrl+U`；`Ctrl+Y` 在某些系统上是*重做*，而且带 `Alt` 的方向键比两个字母更能表达*之前*和*之后*。正在编辑的单元格会在 `Set Start…`、`Set End…` 或 `Insert Subtitle…` 之前被**提交**，与任何修改之前的做法一样。

## 设置边界

- **每个操作对应一条历史记录**：`编辑(E) ▸ 撤销` 会还原先前的位置，别无其他。
- **规则与单元格相同**。开始时间设在字幕结束时间之后，或结束时间设在其开始时间之前，**都不会被拒绝**：照常设置，表格会像标记手动输入的值那样标记这条字幕——参见[异常情况](table.md#异常情况)。不会悄悄更正任何内容。
- **位置本来就是该边界的值时，什么也不做**，也不会向历史记录添加任何内容。
- **位置始终是某一帧的起点**：播放器从不报告帧内部的位置。设置某个边界，然后再回到它——例如用 `Seek Selection Start`——**显示的是同一帧**。

## 在该位置插入

新字幕**从该位置开始**，持续**三秒**；如果下一条字幕开始得更早，则持续到下一条的开始。它的文本为空。它按文件的顺序就位：排在所有在该位置或之前开始的字幕之后。插入是**一条历史记录**，插入的字幕会被选中：可以立即输入。

## 从该位置选择

两者都依照文件的顺序，而不是当前的选区。**在那一侧没有相邻字幕时**，选区会转到文件中的最后一条（对 `Select Next…`）或第一条（对 `Select Previous…`）——这是 Gaupol 的行为。这两个操作不会移动影片。

## 逐帧

**前进和后退一帧**——或者 N 帧，见下文——以便把边界设置**到准确的那一帧**。共有两个操作，以及播放栏中的两个按钮，位于播放按钮的两侧：

| 命令 | 快捷键 | 作用 |
| :------ | :------- | :----------- |
| 视频(D) ▸ 后退一步 | `Alt+Left` | 把影片后退一个帧步长 |
| 视频(D) ▸ 前进一步 | `Alt+Right` | 把影片前进一个帧步长 |

- **步长是帧的个数，至少为一**：它是[首选项](preferences.md#播放器)中的 `Frame step` 设置。N 帧的步长显示**往后 N 帧**的那一帧，无论是 25 帧每秒还是 23.976 帧每秒；它**绝不以毫秒表示**。
- **影片在其边界处停止**：从第一帧后退会停留在原处，从最后一帧前进也是如此。每走一步之后，播放都会停止。
- **栏中的按钮**——两个图标，位于播放/暂停的两侧——**触发与菜单相同的操作**：步长相同，没有视频时与菜单中的条目一样被禁用，工具提示也相同，其中给出快捷键。**手指一直按住按钮或按键，就会连续步进。**
- **一次只走一步**。按住不放的按键重复得比一步完成得更快：第一次重复立即发出，而在步进进行期间到达的重复**不会堆积**——它们共用一个位置，即最后一个，该位置在此之后发出。因此松开按键就会让画面停在你所在的位置，而不会让影片在惯性下继续前进。

## 按一帧微调边界

用键盘调整边界：把**选中字幕的开始时间或结束时间**提前或推后一个步长。

| 命令 | 快捷键 | 作用 |
| :------ | :------- | :----------- |
| 视频(D) ▸ 将开始时间微调提前 | `Alt+Q` | 字幕**提前一个步长开始** |
| 视频(D) ▸ 将开始时间微调推后 | `Alt+W` | 它**推后一个步长开始** |
| 视频(D) ▸ 将结束时间微调提前 | `Alt+Shift+Q` | 它**提前一个步长结束** |
| 视频(D) ▸ 将结束时间微调推后 | `Alt+Shift+W` | 它**推后一个步长结束** |

`Q` 和 `W` 是 Gaupol 用于*提前*和*推后*的键，加上 `Alt` 的原因同上；结束时间使用 `Alt+Shift`，因为 Gaupol 的 `E` 在这里是 `Edit` 的字母。

- **每次微调对应一条历史记录**，可以撤销。相邻字幕和重叠情况的报告方式**与手动输入时相同**：边界照常设置，表格会标记不再自洽的内容——参见[异常情况](table.md#异常情况)。
- **步长与播放器相同**，因此默认是一帧。**一帧有多长**，按以下顺序读取：**视频所声明的帧率**，**以帧计数的文档**（MicroDVD）的帧率，然后是**位置所呈现的网格**。**三者都没有时，该操作会拒绝执行并说明原因**：随意选一个帧率，会使任何边界偏移一个并非一帧的量。
- **它不需要视频**，只需要有选区：它也可用于以帧计数、没有影片的文件。打开影片时，**播放会移到新的位置**，以显示该边界刚刚到达的那一帧。
- 边界不会早于起点：从不足一帧的位置后退一个步长，会把它置于零。
