# 插入、删除、合并、拆分、排序以及使字幕互不重叠

<!-- machine-translated -->
> 本页为机器翻译，尚未经过熟悉该语言的读者审校。

`Edit` 菜单中的八个条目，位于一条分隔线之下，与 `Find and Replace…` 隔开。其中四个的共同点是会改变字幕的行数，而前文的剪切、复制和粘贴移动的是文本；`Sort Subtitles` 只改变各行的**顺序**，`Join Repeated Subtitles` 把同一段文本中前后相接的几个片段重新合成一条字幕，`Make Ranges Disjoint…` 则在字幕相互重叠之处把它们重新切开。

| 条目 | 快捷键 | 作用 |
| :---- | :------- | :----------- |
| 插入字幕… | `Ins` | 打开一个对话框，然后添加空白行 |
| 删除字幕 | `Del` | 删除选中的内容，不作任何询问 |
| 合并字幕(M) | 无 | 把一块相邻的行合成一行 |
| 拆分字幕(S) | 无 | 在持续时间的中点把一行切成两行 |
| 合并重复字幕(J) | 无 | 把同一段文本中前后相接的几个片段合成一条字幕 |
| 字幕排序(O) | 无 | 在整个项目范围内，按开始时间把各行重新排好顺序 |
| 使时间段互不重叠…(D) | 无 | 切开相互重叠的行，使任何时间范围都不再与另一个重叠 |
| 修复字幕…(R) | 无 | 一次性依次执行前面三个条目：连接重复的字幕、排序、切分时间范围 |

这八个操作都会进入历史记录：`Ctrl+Z` 可以像撤销其他操作一样撤销它们。

## 插入

![插入对话框，浅色调色板：行数，
以及新行放在选区的哪一侧。](captures/insertion.png)

![同一个对话框，深色调色板。](captures/insertion-sombre.png)

| 字段 | 内容 | 默认值 |
| :---- | :------------ | :------ |
| `How many` | 1 到 99,999 之间的整数 | `1` |
| `Where` | `Above the selection` 或 `Below the selection` | 上一次的选择，首次启动时为 `Below` |

`OK` 添加这些行，`Cancel` 不添加任何内容。

### 新行放在哪里

放在**最后一个被选中的行**之后，而不是第一个。选中第 1 行和第 3 行，再向下插入，新行会出现在第 4 位，而不是第 2 位。这是 Gaupol 二十年来的做法，也符合从上到下拖选之后手的预期。

`Above the selection` 则把新行放在同一行之前。

### 持续多久

空白行没有文本，但有位置。位置根据可用的空间推算：

| 情形 | 开始时间 | 持续时间 |
| :-------- | :---- | :------- |
| 在两条字幕之间 | 前一条的结束时间 | 到下一条之间的空间，平均分配 |
| 在最后一条之后 | 最后一条的结束时间 | 每行三秒 |
| 在文件开头 | 原点 | 到第一条之间的空间，平均分配 |
| 在空文件中 | 原点 | 每行三秒 |

如果文件在所选位置存在重叠，则**没有空间可分**：各行的持续时间为零，表格会如实显示，而不是编造一个会越过相邻字幕的持续时间。

### 空文档

**不需要任何选区**，而且这是开始一个新文件的唯一办法：各行被放到索引零处。此时对话框中选择一侧的选项会被禁用，因为没有可以用来定位的选区。

文档一旦有了一行，只要没有选中任何内容，`Insert Subtitles…` 条目就会**被禁用**：没有选区，就只能猜测索引。

### 之后

新添加的行会被**选中**，表格也会跳到这些行。因此再按一次 `Ins`，就会插在它们之后，无需在两次之间单击。

### 记住所在的一侧

`Above` 或 `Below` 会被**记住，从一次插入到下一次插入，从一次会话到下一次会话**：它就是[设置文件](preferences.md#文件)中的 `edit.insert-placement` 选项。你不会只插入一次，而是连续插入十行，而且总在同一侧。

## 删除

`Remove Subtitles` 或 `Del` 会删除选中的行，包括不连续的选区；撤销时，每一行都会回到原来的位置。

**不会要求确认**，这并非疏忽：该操作可以用 `Ctrl+Z` 撤销。对一个可以撤销的操作，如果先弹出模态对话框，每次都要多单击一下，只是为了省下偶尔的一次 `Ctrl+Z`。

**没有选中任何内容时，该条目被禁用。** 在窗口的其他地方，“未选中任何内容”表示“整个文件”，这样移动位置时就不必选中四千行。而在这里，这种解读会让一次不小心的 `Del` 清空整个文档，所以不提供这种用法。

删除之后，**顶替了被删除的第一行的那一行会被选中**；如果删除的是文件末尾，则选中剩下的最后一行。因此连续按几次 `Del`，就会逐行删除。

文件被完全清空后，窗口仍然可用：`Insert Subtitles…` 会重新变为可用，因为空文档不需要选区就能插入。

## 合并

`Merge Subtitles` 把选中的各行合成**一行**：

| 合并后的行得到什么 | 来自哪里 |
| :---------------------------- | :------------------ |
| 开始时间 | 第一行的开始时间 |
| 结束时间 | 最后一行的结束时间 |
| 文本 | 所有行的文本，按顺序排列，两段之间换行 |
| 翻译 | 各行的翻译，以同样的方式连接 |
| 格式额外携带的内容——样式、图层、坐标 | 第一行的 |

**空文本不会留下空行**：合并 `Un.`、一个没有文本的行和 `Trois.`，得到的是两行文本，而不是三行。

被合并的各行会消失，替代它们的那一行占据第一行的位置。

只要选区不是**至少两个相邻行组成的一块**，该条目就会**被禁用**。单独一行没有可合并的对象；第 1 行和第 3 行而不含第 2 行同样不行，因为结果会越过第 2 行并把它盖住。

合并之后，**合并出的行会被选中**：`Split Subtitle` 随时可以把它重新切开。

## 拆分

`Split Subtitle` 在选中的行的**持续时间中点**把它切开，精确到毫秒：

| 一半 | 开始时间 | 结束时间 | 文本 |
| :--- | :---- | :-- | :--- |
| 前一半 | 原来的开始时间 | 中点 | **全部**文本和翻译 |
| 后一半 | 中点 | 原来的结束时间 | 空 |

**文本不会在其换行处被切开。** 这对两行的字幕合适，对一行或三行的字幕则不合适；全部文本都留在前一半，需要移到后一半的部分由你自己移动。

前一半保留格式在文本之外携带的内容；后一半的产生方式与插入的行相同，什么都不带。

只要选区包含的不是**恰好一行**，该条目就会**被禁用**。这里，没有选中任何内容并不表示“整个文件”。

拆分之后，**两半都会被选中**——这与 Gaupol 在任何插入之后的做法一样，随后 `Merge Subtitles` 可以随时撤销这一操作。

## 排序

`Sort Subtitles` 把**整个项目**按开始时间重新排好顺序。绝不只针对选区：顺序是文档的属性，只给文件的一半排序毫无意义。排序是**稳定的**：开始时间相同的两条字幕保持文件原来给出的先后。

**排序期间状态栏中会出现一个进度条，光标变成沙漏**：对于较长的文件，窗口会有一段时间没有响应——表格逐行重建——如果没有这个提示，你就无从知道是否正在进行。进度条不显示比例，因为排序不报告比例，排序结束它也随之消失。

状态栏会说明有多少行改变了位置——`3 subtitles moved`——如果一切本来就有序，则显示 `already in order`。**已经有序的项目不会进入历史记录**：不改变任何内容的操作，不是需要撤销的操作。只有一条字幕的项目，该条目被禁用。

打开时**有需要更正之处**的文件，会自行提出更正，[放在一个对话框中](#打开时只有一个框)：见下文。顺序错乱的字幕也会[计入诊断信息](files.md#读取的诊断信息)，这样无需滚动表格就能发现它们。

在命令行中，[`sort`](../subedit-cli/sort.md) 对文件执行同样的操作，而 `--sort` 则在 [`convert`](../subedit-cli/convert.md#写入时排序)、[`append`](../subedit-cli/append.md#对结果排序) 和 [`split-file`](../subedit-cli/split-file.md#按时间顺序切分) 中顺带完成排序。

## 连接重复的字幕

`Join Repeated Subtitles` 把连续显示同一内容的字幕合成**一条字幕**：一段文本被切成了前后相接的几块，某些分段工具就会留下这样的结果。它作用于**整个项目**。

**重复项**与另一条字幕具有相同的文本、相同的翻译和相同的格式设置（样式、位置、提示设置），并且**最迟在那一条结束时开始**。一串重复项合成其中最早开始的那一条，结束时间取这一串中最大的结束时间；其余的消失。`Alpha [1, 2]`、`Alpha [2, 4]` 和 `Alpha [4, 6]` 得到 `Alpha [1, 6]`。

- **文件中的顺序对此没有影响，该操作也不会改变它**：保留下来的是最早开始的那一条，其余的无论在哪里。
- **不会误连任何内容**：文本不同、设置不同、两个片段之间有间隔、没有文本，或结束时间早于开始时间的字幕，都保持独立。
- 状态栏会说明做了什么——`2 repeated subtitles joined`，或 `no repeated subtitles`。

**应当先于排序和切分执行**，这样它们读到的序列更干净：一段文本被切成三块，另一段文本覆盖整个范围，且顺序混乱，排序和切分之后会得到在两个片段之间来回切换的行；先连接，它就会回到正确的顺序，并且干净地合并。下文的打开对话框按这个顺序依次执行这三项。

## 使时间范围互不重叠

`Make Ranges Disjoint…` 切开相互重叠的字幕，使**任何 `[start, end]` 范围都不再与另一个重叠**。它作用于**整个项目**，绝不只针对选区：一组相互重叠的字幕要在它们重叠之处切开，只处理其中一半毫无意义。

**不会缩短也不会延长任何内容。** 在每一个时刻，窗口显示的文本都与之前相同。改变的是时间线的切法：在每一组的每个开始时间和每个结束时间处切开；只被一条字幕覆盖的区间仍属于那条字幕；被多条字幕覆盖的区间变成**一条**字幕，其各行就是它们的各行，**最早的那一条放在第 1 行**。`A [0, 5]` 和 `B [3, 8]` 得到 `[0, 3] A`、`[3, 5] A / B`、`[5, 8] B`。

对话框询问三项设置，每次都会被记住：

| 字段 | 内容 | 默认值 |
| :---- | :------------ | :------ |
| `Shortest interval kept` | 0 到 10,000 ms：更短的区间由相邻的字幕接管 | `80 ms`（约两帧） |
| `Most lines in a subtitle` | 0 到 10；为 0 时显示 `No limit` | `2` |
| `Put a dash before each subtitle's text` | 在每条字幕贡献给合并后字幕的内容之前加一个破折号 | 不选中 |

`OK` 执行切分，`Cancel` 什么也不做。之后，**写入的各行会被选中**，状态栏会说明做了什么：`2 subtitles split, 1 merged`。再执行第二遍不会改变任何内容，并会这样说明：`already disjoint`。

- **绝不会重复出现同一行。** 两条文本相同的字幕，在它们重叠之处只给出一行；显示同一内容的两个相邻片段只构成一条字幕。除此之外，被切成几块的字幕，其文本会在每一块中重复出现：这就是那一时刻屏幕上显示的内容。
- **很短的区间由相邻的字幕接管**：其各行已经包含它自己那些行的字幕，否则取最长的字幕，延长其时间范围去覆盖它。整条字幕比阈值还短时，绝不会被接管。
- **行数超过限制时：开窗口。** 三行字幕持续三秒，变成两半，前一半是前两行，后一半是后两行；四行则分成三份，依此类推。不会截断任何内容。
- 翻译遵循同样的切分；保留第一条覆盖字幕的样式和位置。

**无法完全完成的内容，会在一个需要关闭的对话框中说明**，而不是在状态栏中：开窗口、被接管的区间、因太短而整条保留的字幕、不一致的样式、结束时间早于开始时间的字幕（原样保留）。

**当字幕没有按开始时间排序时，该条目会被拒绝，并说明原因**：字幕组是由相邻行连成的一串，核心从不自行排序。请先执行 `Sort Subtitles`，或使用打开对话框，它会按这个顺序依次执行这两项。

### 一次完成：`Repair Subtitles…`

`Repair Subtitles…` 依次执行前面三个条目，顺序只有这一种可行：先连接重复的字幕，再按开始时间排序，最后使时间范围互不重叠。当一个文件分段不当、顺序混乱又相互重叠，而你确定三项都需要时，就用这个条目。对话框询问切分设置（与 `Make Ranges Disjoint…` 相同，每次都会被记住），并说明会先连接再排序。状态栏——如果有无法完全完成的内容，则是需要关闭的对话框——会给出这三项的**同一份说明**：`2 repeated subtitles joined; already in order; 2 subtitles split, 1 merged`。每一项更正都是各自的历史记录条目：`Ctrl+Z` 逐项撤销。在命令行中：[`repair`](../subedit-cli/repair.md)。

### 打开时只有一个框

打开的文件如果有我们知道如何更正的问题，会把更正**放在一个对话框中**提出，对话框名为 `Problems found in this file`，而不是每个问题弹出一个。发现的每个问题占一行，带有复选框，默认选中：

- `Join the repeated subtitles`——有些字幕重复了与其相接的另一条字幕，并给出数量；
- `Sort the subtitles`——有些字幕没有按开始时间排列，并给出数量；
- `Make the ranges disjoint`——有些字幕在前一条结束之前就开始了，数量是在**文件排好顺序之后**统计的，因为更正正是在那时进行的。

**每个问题都在它被更正的位置计数**，计数基于一份副本，其中排在它之前的更正已经做完：一段被切成几块的文本是某些顺序错乱的原因，先把它连接起来，可能就不再有错乱——对话框随之不再提供排序。

没有发现的问题就没有对应的行。取消选中排序，会使另一个复选框**变灰并取消选中**：时间范围只有在排好顺序之后才能使其互不重叠。`Fix` 应用选中的项——先连接，再排序，然后切分，所用设置为上一次 `Make Ranges Disjoint…` 的设置——并给出**同一份说明**；`Keep as is` 不改动任何内容。**没有得到肯定答复，就不会做任何事**，每一项更正都是一个历史记录条目，而无需更正的文件不会引发任何询问。

在命令行中，[`disjoint`](../subedit-cli/disjoint.md) 对文件执行同样的操作，而 `--disjoint` 则在 [`convert`](../subedit-cli/convert.md#使时间范围互不重叠)、[`append`](../subedit-cli/append.md#使时间范围互不重叠) 和 [`split-file`](../subedit-cli/split-file.md#使时间范围互不重叠) 中顺带完成。

### 为什么不用 Gaupol 的快捷键

Gaupol 用 `M` 合并，用 `S` 拆分。单独一个字母会在到达正在编辑的单元格之前被表格截获，而 `Ctrl+S` 已经用于保存：这两个条目只能通过菜单使用。

## 撤销操作怎么说

**每个操作对应一条历史记录。** 合并五行只需一次 `Ctrl+Z` 就能撤销，并按原样还原这五行——位置、文本以及格式携带的一切。

| 操作 | `Undo` 显示的内容 |
| :-------- | :---------------- |
| 插入 | `Undo: inserting` |
| 删除 | `Undo: removing` |
| 合并 | `Undo: merging` |
| 拆分 | `Undo: splitting` |
| 连接重复的字幕 | `Undo: joining repeated subtitles` |
| 切分时间范围 | `Undo: making the ranges disjoint` |

打开时提出的更正，每一项更正对应一条历史记录：连接、排序、切分依次被撤销。

参见[撤销与重做](undo.md)。

## 单元格处于打开状态时的快捷键

只要单元格编辑器处于打开状态，`Ins` 和 `Del` 就属于输入框：删除键在其中擦除的是一个字符，而不是一条字幕。关闭编辑器——`Enter` 或 `Esc`——它们就恢复原来的含义。从菜单中执行时，`Remove Subtitles` 会先提交输入，与[编辑单元格](editing.md)中的其他操作一样。

本手册按菜单显示的形式称呼各个按键，参见[菜单](index.md#菜单)。
