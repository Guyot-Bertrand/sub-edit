# 剪切、复制和粘贴文本

<!-- machine-translated -->
> 本页为机器翻译，尚未经过熟悉该语言的读者审校。

`Edit` 菜单中的三个条目，位于 `Undo` 和 `Redo` 之下、`Find and Replace…` 之上。

| 条目 | 快捷键 | 作用 |
| :---- | :------- | :----------- |
| 剪切文本(T) | `Ctrl+X` | 复制选区中的文本，然后将其清空 |
| 复制文本(C) | `Ctrl+C` | 复制选区中的文本 |
| 粘贴文本(P) | `Ctrl+V` | 从第一条选中的行开始写入已复制的文本 |

**传递的只有文本，别无其他**：没有开始时间，没有结束时间，也不是整行。因此粘贴不会移动任何位置——接收文本的那一行，其时间仍然是它自己的。Gaupol 就是这样做的。

## 作用对象

**有翻译时，作用于当前列的文本**：当前单元格在 `Translation` 列时是翻译，其余情况是主文本——参见[表格](table.md#操作所针对的文本)。因此 `Cut Texts` 会清空翻译而保留主文本，`Paste Texts` 则写入你所在的那一列。**剪贴板不带有任何文档信息**：可以复制主文本中的一个单元格，粘贴到翻译中，反过来也可以。

**只针对选区，绝不针对整个文件**。只要没有选中任何内容，这三个条目就被禁用。在窗口的其他地方，“没有选中任何内容”表示“整个文件”；而在这里，一次不走运的 `Ctrl+X` 会清空文档中的所有文本，而粘贴也将没有可以起始的行。

单元格打开期间，`Ctrl+X`、`Ctrl+C` 和 `Ctrl+V` 属于输入框：它们剪切、复制和粘贴的是字符，就像 `Del` 在那里删除的是一个字符而不是一条字幕。从菜单启动时，这些条目会先提交输入：此时 `Copy Texts` 复制的就是刚刚输入的文本。参见[编辑单元格](editing.md)。

## 复制

`Copy Texts` 复制每一条选中行的文本，从第一条到最后一条。**不连续的选区会保持其形状**：选区中被漏掉的一行成为一个空洞，粘贴时不会覆盖它。

**文本为空的选中行同样成为空洞**：粘贴时，它会让目标行保持原样。因此只复制一个空文本，粘贴出来什么也没有。

系统剪贴板收到的这些文本是**纯文本，以空行分隔**——空洞在那里写成一个空文本，这也是空文本只能是空洞的原因：无论复制来自本窗口还是另一个程序，粘贴的结果都相同。因此在这里复制的内容可以粘贴到任何程序中，在别处复制的内容也可以粘贴到这里。

复制不会修改文档，也不会进入历史记录。

## 剪切

`Cut Texts` 先复制，然后**清空选中行的文本**。这些行保留下来，位置也不变：剪切不等于删除——要删除行，请使用 [`Remove Subtitles`](lines.md#删除)。

对已经全部为空的文本执行剪切，什么也不做，也不会进入历史记录。

## 粘贴

`Paste Texts` 从**第一条选中的行**开始写入剪贴板中的文本，每个文本一行，向下排列。

| 剪贴板的内容 | 发生的情况 |
| :-------------------------- | :----------- |
| 一段文本 | 它替换该行的文本 |
| 一个空洞，或复制的空文本 | 该行保留其文本 |
| 文本比剩下的行多 | 在末尾添加行来接收它们 |

添加的行与在最后一行之后插入的行一样产生：每条三秒，依次排列。**窗口会在信息框中说明这一点**：

```text
inserted 2 subtitles to fit the clipboard
```

粘贴之后，**写入的行处于选中状态**。

不改变任何内容的粘贴——相同的文本写在相同的行上——不会进入历史记录。

### 其他格式的标签会被转换

在本窗口中进行的复制**会记住其文档的格式**，而且这一记忆在打开另一个文件之后仍然保留。因此粘贴到另一种格式的文档中时，标签会被转换，就像 `Save As…` 所做的那样：从 Advanced SSA 复制的 `{\i1}Bonjour{\i0}`，会作为 `<i>Bonjour</i>` 粘贴到 SubRip 中。

**目标格式无法写出的内容会丢失，并且会说明这一点**，所用的措辞与 `Save As…` 相同：

```text
pasting SubRip texts into LRC: 1 tag dropped
```

与 `Save As…` 不同，这里事先不会询问：粘贴可以用 `Ctrl+Z` 撤销，文本会恢复原样。

**在 `subedit` 之外复制的文本没有格式**，按原样粘贴：无从转换起。从本窗口所作的复制，如果其后系统剪贴板已被替换，情况也是如此——起作用的是系统剪贴板的内容。

两条消息都需要时，它们合并在同一个框中，以分号隔开。

## 撤销操作对此怎么说

每个操作都是**一条**历史记录，无论它写入或添加了多少行。

| 操作 | `Undo` 显示的内容 |
| :-------- | :---------------- |
| 剪切 | `Undo: cutting texts` |
| 粘贴 | `Undo: pasting texts` |

参见[撤销与重做](undo.md)。
