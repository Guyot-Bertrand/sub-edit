# 撤销与重做

<!-- machine-translated -->
> 本页为机器翻译，尚未经过熟悉该语言的读者审校。

每个操作都会进入历史记录，并且可以撤销。编辑一个单元格算作**一条**记录：输入不会逐个按键记录，只有提交才算数。

| 操作 | 快捷键 | 位置 |
| :----- | :------- | :---- |
| 撤销 | `Ctrl+Z` | **编辑**菜单、工具栏 |
| 重做 | `Ctrl+Shift+Z` | **编辑**菜单、工具栏 |

## 操作会说明它将撤销什么

菜单中显示的不是“Undo”，而是“**Undo: editing a text**”，即后面跟着将被撤销的操作。工具栏按钮保留这个单独的词——否则它的宽度会随最后一次操作而变化，在指针下面移动——但它的工具提示带有完整的标签。

| 操作 | 该操作显示的内容 |
| :-------- | :-------------------- |
| 编辑一个文本单元格 | `editing a text` |
| 一个开始时间、一个结束时间 | `editing a start`, `editing an end` |
| 一个持续时间 | `editing a duration` |
| 插入行 | `inserting` |
| 删除行 | `removing` |
| 一次移动，包括 `Shift Whole File onto Grid` | `shifting` |
| 一次变换 | `transforming` |
| 一次帧率转换 | `converting the frame rate` |
| 对齐到某个帧率 | `aligning on the frame rate` |
| 删除提示 | `removing hearing-impaired mentions` |
| 设为斜体 | `putting in italics` |
| 去除斜体 | `taking italics out` |
| 更改大小写 | `changing the case` |
| 添加、删除对话破折号 | `adding dialogue dashes`, `removing dialogue dashes` |
| 合并行 | `merging` |
| 拆分一行 | `splitting` |
| 剪切、粘贴文本 | `cutting texts`, `pasting texts` |
| 调整持续时间 | `adjusting durations` |
| 打开翻译 | `opening a translation` |
| 追加文件 | `appending a file` |
| 拆分项目 | `splitting the project` |
| 在 `Correct Texts…` 中接受的更正，或由 `Check Spelling…` 作出的更正 | `correcting texts` |
| 一次替换、全部替换 | `replacing`, `replacing all` |

**二十七个标签，窗口所能产生的仅此而已**。核心命名了第二十八个——`sorting`——但窗口中没有任何操作会触及它：排序只在严格的顺序策略下发生，而窗口以宽松策略打开其文档，宽松策略只报告乱序，而不修复它。

**`Shift Whole File onto Grid` 与移动不作区分**，这是准确的：它就是一次移动，只不过移动量是测出来的，而不是输入的。

这些词与命令行的相同：它们只在核心中写一次。

当没有可撤销的内容时，该操作显示为普通的“Undo”，**并且被禁用**：它的快捷键不起作用。

## 修改标记

只要文件与磁盘上的文件不同，窗口标题就带有一个标记——星号，或者平台使用的其他标记。**标签页的标签也一样**，`premier.srt*`：标题只说你正在查看的项目，标签则说明你没有查看的那些。

**每个标签页都有自己的历史记录**。撤销只撤销当前标签页的项目所收到的内容——包括针对所有项目所作的 `Replace All`：它在每个受影响的项目中各留下一条记录。

**撤销回到起点时，标记就会消失**。这不只是显示上的细节：修改的次数是计数的，而不是记录成是或否，所以退回去可以使它回到零，标记随之消失。

## 需要了解的两件事

**参考点是上一次保存**，如果还没有保存过，则是文件打开时的状态。保存会移动参考点：标记消失，之后再撤销会使它重新出现。

撤销之后再进行的操作会**清除原本可以重做的内容**：重做将重放一个起始状态已不复存在的命令。这是所有编辑器的行为，而且是有意为之。

**单元格处于打开状态时**，`Undo` 和 `Redo`——无论来自菜单还是工具栏——会先提交输入，与[编辑单元格](editing.md)的其他操作一样。刚刚输入的内容于是成为历史记录的最后一条：`Undo` 撤销的是它，而不是它之前的操作；`Redo` 则没有可以重做的内容，因为一次输入会清除可重做的内容。如果打开的单元格中什么也没有输入，就不会留下记录：此时 `Undo` 撤销的是前一个操作。

历史记录保留一千条，超出的部分会遗忘最旧的。
