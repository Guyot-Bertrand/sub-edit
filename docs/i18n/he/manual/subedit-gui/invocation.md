# הפעלה

<!-- machine-translated -->
> דף זה הוא תרגום מכונה שעדיין לא נבדק על ידי דובר השפה.

```
subedit-gui [--version] [<file>]
```

| ארגומנט | חובה | ערך | ברירת מחדל |
| :------- | :------- | :---- | :------ |
| `<file>` | לא | הנתיב של קובץ כתוביות לפתיחה | אין — החלון נפתח ריק |
| `--version` | לא | — | — |

**קובץ אחד בלבד.** מתעלמים מהארגומנטים הבאים: החלון מחזיק
פרויקט אחד בלבד בכל רגע נתון.

## `--version`

כותב בפלט הסטנדרטי את הבלוק ש-`--version` של שורת הפקודה כותב, וחוזר
מיד, בלי לפתוח חלון. קוד יציאה `0`.

**`subedit <version>` לבדו בשורה הראשונה**, ואחריו שורה לכל ספרייה
שהחלון רץ מולה, עם הגרסה שנמצאה בזמן הריצה ובסוגריים הגרסה
שמולה הוא קומפל; ואחר כך שפות הממשק המותקנות, לפי קוד. במחשב
עם Qt 6.4.2:

```console
$ subedit-gui --version
subedit <version>
  ICU      74.2 (built with 74.2)
  Enchant  2.3.3 (built with 2.3.3)
  Qt       6.4.2 (built with 6.4.2)
  libmpv   2.2 (built with 2.2)
  Languages: en, fr
```

המספרים אינם מועתקים לכאן: הם של המחשב, ולמדריך הזה אין
בלוק שנוצר אוטומטית ושישמור על עדכניות הבלוק של התוכנית עצמה. הספריות הן
אלה של שורת הפקודה, ICU ו-Enchant, ושתיים שרק החלון מקשר אליהן — Qt,
ו-libmpv, הנגן, שגרסתו נקבעת לפי גרסת ממשק הלקוח שלו, זו
ש-`mpv.pc` מכריז עליה. את היתר מתארים ב
[מדריך שורת הפקודה](../subedit-cli/invocation.md#--version). המילים
`built with` ו-`Languages` עוקבות אחר שפת החלון; שום דבר אחר אינו עוקב.

`עזרה ▸ אודות subedit` מציג את אותן ספריות, מאותה רשימה, בטבלה —
השם, הגרסה שנטענה, הגרסה שמולה נבנה, שורה לכל אחת — ואחר כך את
השפות מתחתיה; הכותרות שלו עוקבות אחר שפת החלון.

## פתיחת קובץ

```console
$ subedit-gui film.srt
```

הפורמטים הנקראים הם **התשעה** שמסנן הפתיחה מונה — ראו
[פתיחה ושמירה](files.md#פתיחה). הפורמט מזוהה לפי התוכן
ולא לפי הסיומת, **וכך גם הקידוד**: BOM
אם הקובץ נושא אחד, ואחרת הקידוד שהבתים שלו מרמזים עליו.

## כשהפתיחה נכשלת

קובץ חסר, קובץ שאינו קריא, קובץ שהבתים שלו מפוענחים באף
קידוד, או קובץ שהתוכן שלו אינו מזוהה באף פורמט: **החלון נפתח
בכל זאת, ריק**, והכשל נכתב בזרם השגיאות.

**ההודעה נוקבת בסיבה**, באותן מילים כמו בשורת הפקודה:

| הודעה | מה קרה |
| :------ | :------------ |
| `does not exist` | הנתיב אינו מצביע על אף קובץ |
| `cannot be opened: permission denied` | המערכת מסרבת לפתוח אותו |
| `cannot be read` | המערכת סירבה מסיבה אחרת |
| `cannot be decoded in the chosen encoding` | הבתים אינם נקראים בקידוד שנבחר |
| `is in no format this tool knows` | אף פורמט אינו מזהה את התוכן |
| `holds nothing recognisable as a subtitle` | הפורמט מזוהה, אך דבר בו אינו כתובית |

```console
$ subedit-gui notes.txt
subedit-gui: notes.txt: is in no format this tool knows
```

פתיחה ריקה במקום סירוב להתחיל: הכלי עדיין שימושי
לדבר מה, וכשל של ארגומנט אינו סיבה לא להפעיל אותו.

**קובץ פגום אך קריא נפתח**, ואת מה שהקריאה אספה
בדרך אפשר לקרוא בלחצן בשורת המצב — ראו
[אבחוני הקריאה](files.md#אבחוני-הקריאה).

## קודי יציאה

| קוד | מתי |
| :--- | :--- |
| `0` | החלון נפתח ואז נסגר כרגיל, או ש-`--version` ענה |
| `2` | שגיאה בלתי צפויה לפני הפתיחה — Qt חסר, תצוגה לא זמינה |

הכשל בפתיחת קובץ **אינו משנה את קוד היציאה**: החלון
נפתח, וזה מה שהקוד מדווח עליו.

## דף ה-man

ההתקנה מניחה את `subedit-gui(1)` תחת `share/man/man1`:

```console
$ man subedit-gui
```

הוא נותן את צורת הקריאה, את `--version`, את הודעות הכשל בפתיחה, את
קודי היציאה, את שני משתני הסביבה ואת קובץ ההגדרות.
**הוא אינו מתאר את החלון** — המדריך הזה מתאר, והדף
מפנה לכאן.

## פלטפורמת Qt

`QT_QPA_PLATFORM` קובע על מה החלון רץ. **אם המשתנה
מוגדר, `subedit-gui` מכבד אותו בלי ארגומנט.**

אם אינו מוגדר, הוא מניח ל-Qt לבחור: הנגן המובנה מצייר את התמונה בתוך
החלון עצמו, ואינו מבקש דבר מהפלטפורמה — ראו
[הנגן](player.md).

`QT_QPA_PLATFORM=offscreen` מריץ את החלון במקום שאין בו
שרת גרפי — וכך עושות האינטגרציה הרציפה והבדיקות.

## שפה

החלון מדבר בשפת הסביבה שלו, **הנבחרת פעם אחת, בהפעלה**: שינוי
המשתנים של חלון רץ אינו משנה דבר עד ההפעלה הבאה. המשתנים והכללים
הם אלה של שורת הפקודה — `LANGUAGE`, `LC_ALL`, `LC_MESSAGES`, `LANG`, `LC_ALL=C` לאנגלית,
אנגלית **בלי מילה אחת** כשהשפה המבוקשת אינה מותקנת — המתוארים ב
[מדריך שורת הפקודה](../subedit-cli/invocation.md#שפה). הקטלוגים הם אותם
קבצים, המותקנים תחת `<prefix>/share/subedit/locale`.

**שפה שנבחרה ב-`עריכה ▸ העדפות…` באה ראשונה**, והסביבה נקראת רק
כשהבחירה היא `System default`, וכך היא עד שנבחרה שפה: שפה מותקנת שנבחרה שם
גוברת על כל משתנה, גם על `LC_ALL=C`. גם הבחירה חלה בהפעלה הבאה. ראו
[שפת הממשק](preferences.md#שפת-הממשק).

| מה | עוקב אחר השפה |
| :--- | :------------------- |
| התפריטים והפריטים שלהם, עם האותיות המסומנות בקו תחתון; סרגל הכלים; הסבר הכלים | כן |
| עמודות הטבלה ושל `תצוגה ▸ עמודות`, הלשוניות, שורת המצב, סרגל הניגון | כן |
| הלחצנים הסטנדרטיים ש-Qt מצייר בעצמו (`OK`, `Cancel`) | כן, כשהקטלוג של Qt עצמו לשפה הזו מותקן (`qtbase_<language>.qm`); אחרת אנגלית |
| תיבות הדו־שיח, הדפים של `Correct Texts…`, הכותרות והמסננים של תיבות הקבצים, תיבות ההודעה ומה שהן אומרות | כן |
| השורות שהחלון כותב בזרם השגיאות שלו, `subedit-gui: …` | כן, מלבד שם התוכנית |
| שמות תבניות התיקון ב-`Correct Texts…`, ותיאוריהן בהסבר הכלים | כן, לתבניות שמגיעות עם התוכנית; תבנית משלכם מוצגת כפי שהקובץ שלה כותב אותה |
| שמות של קידודים, סופי שורות ושפות איות (`UTF-8`, `CRLF`, `en_US`) | אף פעם: אלה שמות, לא מילים |
| קיצורי המקלדת | אף פעם: `Ctrl+S` הוא `Ctrl+S` בכל שפה |
| הודעה שהקטלוג אינו מתרגם | מוצגת באנגלית |

הגרסה הזו מתקינה את `ca`, `cs`, `de`, `es`, `fi`, `fr`, `gl`, `he`, `hu`, `ie`, `is`, `it_IT` ו-`nl` — קטלאנית, צ'כית, גרמנית,
ספרדית, פינית, צרפתית, גליסית, עברית, הונגרית, אינטרלינגואה, איסלנדית, איטלקית והולנדית — מתורגמות במלואן. הצרפתית נבדקה על ידי דובר
השפה; הקטלאנית, הצ'כית, הגרמנית, הספרדית, הפינית, הגליסית, העברית, ההונגרית, האינטרלינגואה, האיסלנדית, האיטלקית וההולנדית מתורגמות בתרגום מכונה ועדיין לא
נבדקו על ידי דובר השפה.
