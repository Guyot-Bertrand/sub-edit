# ביטול וביצוע חוזר

<!-- machine-translated -->
> דף זה הוא תרגום מכונה שעדיין לא נבדק על ידי דובר השפה.

כל פעולה נכנסת להיסטוריה וניתן לבטל אותה. תא שנערך נחשב ל**רשומה אחת**:
ההקלדה אינה נרשמת הקשה אחר הקשה, רק האישור נספר.

| פעולה | קיצור דרך | היכן |
| :----- | :------- | :---- |
| ביטול פעולה | `Ctrl+Z` | תפריט **עריכה**, סרגל הכלים |
| ביצוע חוזר | `Ctrl+Shift+Z` | תפריט **עריכה**, סרגל הכלים |

## הפעולה אומרת מה היא תבטל

התפריט אינו אומר "ביטול פעולה" סתם, אלא **"ביטול פעולה: עריכת טקסט"**, על שם
הפעולה שתבוטל. הלחצן בסרגל הכלים משאיר את המילה הקצרה בלבד — אחרת רוחבו
היה עוקב אחר הפעולה האחרונה, והוא היה זז מתחת לסמן — אבל הסבר הכלים שלו נושא את
התווית המלאה.

| מה בוצע | מה הפעולה אומרת |
| :-------- | :-------------------- |
| תא טקסט שנערך | `editing a text` |
| התחלה, סוף | `editing a start`, `editing an end` |
| משך | `editing a duration` |
| הוספת שורות | `inserting` |
| הסרת שורות | `removing` |
| הזזה, כולל `Shift Whole File onto Grid` | `shifting` |
| המרה לפי שתי נקודות | `transforming` |
| המרת קצב פריימים | `converting the frame rate` |
| יישור לקצב פריימים | `aligning on the frame rate` |
| הסרת אזכורים לכבדי שמיעה | `removing hearing-impaired mentions` |
| הפיכה לנטוי | `putting in italics` |
| הסרת הנטוי | `taking italics out` |
| שינוי של רישיות | `changing the case` |
| מקפים שנוספו, שהוסרו | `adding dialogue dashes`, `removing dialogue dashes` |
| מיזוג שורות | `merging` |
| פיצול שורה | `splitting` |
| טקסטים שנגזרו, שהודבקו | `cutting texts`, `pasting texts` |
| התאמת משכים | `adjusting durations` |
| פתיחת תרגום | `opening a translation` |
| הוספת קובץ | `appending a file` |
| פיצול הפרויקט | `splitting the project` |
| תיקון שהתקבל ב-`Correct Texts…`, או שבוצע על ידי `Check Spelling…` | `correcting texts` |
| החלפה, החלפת הכול | `replacing`, `replacing all` |

**עשרים ושבע תוויות, וזה כל מה שהחלון יכול להפיק.** הליבה נותנת שם לתווית עשרים
ושמונה — `sorting` — שאף פעולה בחלון אינה מגיעה אליה: מיון מתבצע רק
תחת מדיניות סדר קפדנית, ואילו החלון פותח את המסמכים שלו תחת המדיניות הסלחנית,
שמדווחת על חוסר סדר במקום לתקן אותו.

**`Shift Whole File onto Grid` אינה נבדלת מהזזה**, וזה מדויק: זו הזזה, שגודלה
נמדד ולא הוקלד.

אלה אותן מילים כמו בשורת הפקודה: הן כתובות פעם אחת, בליבה.

כשאין מה לבטל, הפעולה אומרת "ביטול פעולה" בלבד **והיא מושבתת**: קיצור הדרך שלה אינו עושה דבר.

## סימן השינוי

כותרת החלון נושאת סימן כל עוד הקובץ שונה מזה שבדיסק — כוכבית, או מה שהפלטפורמה
משתמשת בו במקומה. **כך גם תווית הלשונית**, `premier.srt*`: הכותרת מדברת רק על הפרויקט
שמסתכלים עליו, והתווית מספרת על אלה שאין מסתכלים עליהם.

**לכל לשונית יש היסטוריה משלה.** הביטול מבטל רק את מה שהפרויקט של הלשונית הנוכחית
קיבל — גם `Replace All` שבוצעה על כל הפרויקטים: היא משאירה רשומה אחת בכל פרויקט שנגעה בו.

**הסימן נעלם אם מבטלים עד נקודת ההתחלה.** זה אינו פרט של תצוגה: מספר השינויים
נספר ולא נרשם ככן או לא, ולכן חזרה לאחור יכולה להחזיר אותו לאפס והסימן נעלם.

## שני דברים שכדאי לדעת

**נקודת הייחוס היא השמירה האחרונה**, או פתיחת הקובץ אם לא הייתה שמירה. שמירה מזיזה
אותה: הסימן נעלם, וביטול לאחר מכן מחזיר אותו.

פעולה שבוצעה לאחר ביטול **מוחקת את מה שהיה אפשר לבצע שוב**: ביצוע חוזר היה מריץ
מחדש פקודה שמצב ההתחלה שלה אינו קיים עוד. זו התנהגות של כל עורך, והיא מכוונת.

**כשתא פתוח**, `Undo` ו-`Redo` — מהתפריט או מסרגל הכלים — מאשרים תחילה את מה שהוקלד,
כמו שאר המחוות של [עריכת תא](editing.md). מה שהוקלד זה עתה
הופך אז לרשומה האחרונה בהיסטוריה: `Undo` מבטל אותה, לא את הפעולה שלפניה; ל-`Redo` לא נשאר
מה לבצע שוב, שכן הקלט מוחק את מה שהיה אפשר לבצע שוב. תא פתוח שלא הוקלד בו דבר
אינו משאיר רשומה: `Undo` מבטל אז את הפעולה הקודמת.

ההיסטוריה שומרת אלף רשומות ושוכחת את הישנות ביותר מעבר לכך.
