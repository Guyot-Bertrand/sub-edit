תמלול שמע לכתוביות — [`transcribe`](transcribe.md) בשורת הפקודה,
[`Transcribe Audio…`](../subedit-gui/video.md#תמלול-השמע) בחלון — דורש שלושה
דברים ש**subedit אינה מצרפת ואינה מורידה**: מנוע, מודל למנוע הזה, ו-

**שום דבר אינו נשבר בלעדיהם.** שאר התוכנה פועלת כמקודם; רק התמלול
מושבת, עם הודעה שמפנה לכאן.

## המנוע: whisper.cpp

[whisper.cpp](https://github.com/ggml-org/whisper.cpp) הוא המנוע ש-subedit מפעילה. זו תוכנה,
`whisper-cli`, שרצה על מעבד רגיל — כרטיס גרפי רק מאיץ אותה. בנו אותה
כפי שהתיעוד שלה אומר (מהדר C++‎ ו-CMake מספיקים):

```bash
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -B build -DBUILD_SHARED_LIBS=OFF
cmake --build build -j --config Release
```

התוכנה היא אז `build/bin/whisper-cli`. כשבונים אותה עם `-DBUILD_SHARED_LIBS=OFF`, כמו לעיל, היא קובץ יחיד שאינו זקוק לספרייה לצידו, ולכן אפשר להעתיק אותה לכל מקום. שימו אותה במקום ש-`PATH` שלכם מוצא, או **ציינו את הנתיב שלה** ל-subedit בהגדרה `transcription.executable` — בחלון, ל[העדפות](../subedit-gui/preferences.md#תמלול) יש שדה לכך. בנייה לכרטיס גרפי מוסיפה אפשרות אחת לשורת `cmake` הראשונה: `-DGGML_CUDA=1` לכרטיס NVIDIA, `-DGGML_VULKAN=1` לרוב האחרים; subedit מפעילה את מה שהתקנתם ואינה בוחרת דבר במקומכם.

## מודל

המנוע קורא **מודל**, קובץ של כמה מאות מגה־בייט עד כמה ג'יגה־בייט שמורידים
פעם אחת. המודלים הרשמיים מופיעים ב-
[huggingface.co/ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp), ובמאגר
של המנוע יש סקריפט שמוריד אחד:

```bash
sh ./models/download-ggml-model.sh small
```

אחר כך ציינו את הנתיב שלו עם `--model` בשורת הפקודה, או בהגדרה `transcription.model`,
או ב[העדפות](../subedit-gui/preferences.md#תמלול) של החלון, שזוכרות אותו.

### איזה מודל לאיזו שפה

Whisper אינו מחליף מודל אחרי שמצא את השפה: **המודל שאתם נותנים קובע מה
הוא יכול לעשות.**

| מודל | שפות | מזהה את השפה | גודל |
| :---- | :-------- | :------------------- | :--- |
| `tiny`, `base`, `small`, `medium`, `large-v3`, `large-v3-turbo` | כמאה | כן | מכ-75 MB עד כ-3 GB |
| `tiny.en`, `base.en`, `small.en`, `medium.en` | אנגלית בלבד | לא | כמו אותו גודל למעלה |

- **לכל דבר חוץ מאנגלית, קחו מודל רב־לשוני** — כזה ששמו אינו כולל `.en`. מודל
  לאנגלית בלבד דוחה שפה אחרת: הפקודה אומרת זאת לפני שהיא עושה כל עבודה.
- **המודלים הקטנים ביותר גרועים בבירור מחוץ לאנגלית.** לצרפתית, גרמנית, ספרדית
  וכדומה, `small` הוא המינימום, ו-`medium` או `large-v3-turbo` נותנים תוצאות טובות בהרבה במחיר
  של יותר זיכרון ויותר זמן.
- **זיהוי השפה טוב רק כמו המודל.** מודל קטן עלול לטעות בפתיחה שמורכבת מ
  מוזיקה או משתיקה; ציינו את השפה עם `--language` כשאתם יודעים אותה.

## ffmpeg

[`ffmpeg`](https://ffmpeg.org/download.html) מחלץ את רצועת השמע של סרטון, ו-`ffprobe`, שמגיע
איתו, מונה את הרצועות. התקינו אותו עם מנהל החבילות של ההפצה שלכם. בלעדיו, קובץ
שמע שהמנוע קורא כמות שהוא (`wav`, `mp3`, `flac`, `ogg`) עדיין אפשר לתמלל, אבל סרטון
אי אפשר.

## בדיקה שהכול עובד

```bash
subedit-cli transcribe --model /path/to/ggml-small.bin --output film.srt film.mkv
```

אם משהו חסר, ההודעה אומרת מה, ומפנה לדף הזה.
