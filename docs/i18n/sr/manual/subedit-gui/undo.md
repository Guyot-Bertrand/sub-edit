# Опозив и понављање

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

Свака операција иде у историју и може се опозвати. Уређена ћелија се рачуна
као **један** унос: куцање се не бележи тастер по тастер, рачуна се само
потврда.

| Радња | Пречица | Где |
| :---- | :------ | :-- |
| Опозови | `Ctrl+Z` | мени **Уређивање**, трака са алаткама |
| Понови | `Ctrl+Shift+Z` | мени **Уређивање**, трака са алаткама |

## Радња именује оно што ће опозвати

Мени не каже „Опозови“ него **„Опозови: уређивање текста“**, према
операцији која ће бити опозвана. Дугме на траци са алаткама задржава голу реч — његова
ширина би иначе пратила последњу операцију, па би се померало под
показивачем — али његов опис алатке носи цео натпис.

| Операција | Шта радња чита |
| :-------- | :------------- |
| уређена ћелија текста | `editing a text` |
| почетак, крај | `editing a start`, `editing an end` |
| трајање | `editing a duration` |
| уметање редова | `inserting` |
| уклањање редова | `removing` |
| померање, укључујући `Shift Whole File onto Grid` | `shifting` |
| преобразба | `transforming` |
| претварање брзине кадрова | `converting the frame rate` |
| поравнање на брзину кадрова | `aligning on the frame rate` |
| уклањање напомена | `removing hearing-impaired mentions` |
| стављање у искошено писмо | `putting in italics` |
| уклањање искошеног писма | `taking italics out` |
| промена величине слова | `changing the case` |
| додате, уклоњене цртице | `adding dialogue dashes`, `removing dialogue dashes` |
| стапање редова | `merging` |
| дељење реда | `splitting` |
| исечени, налепљени текстови | `cutting texts`, `pasting texts` |
| подешавање трајања | `adjusting durations` |
| отварање превода | `opening a translation` |
| прикачињање датотеке | `appending a file` |
| дељење пројекта | `splitting the project` |
| исправка прихваћена у `Correct Texts…`, или направљена у `Check Spelling…` | `correcting texts` |
| замена, све замене | `replacing`, `replacing all` |

**Двадесет седам натписа, и то је све што прозор може да произведе.** Језгро именује
двадесет осми — `sorting` — до кога не допире ниједна радња прозора: ређање
се дешава само под строгом политиком редоследа, док прозор отвара своје документе
под попустљивом политиком, која јавља нарушен редослед уместо да га поправља.

**`Shift Whole File onto Grid` се не разликује од померања**, и то је
тачно: то је померање чији је износ измерен, а не укуцан.

То су исте речи као у командној линији: пишу се једном,
у језгру.

Када нема шта да се опозове, радња чита голо „Опозови“ **и искључена је**:
њена пречица не ради ништа.

## Ознака измене

Наслов прозора носи ознаку све док се датотека разликује од оне на
диску — звездицу, или шта год платформа користи уместо ње. **Исто чини и натпис
језичка**, `premier.srt*`: наслов говори само о пројекту који
гледате, натпис говори о онима које не гледате.

**Сваки језичак има своју историју.** Опозив опозива само оно што је пројекат
текућег језичка примио — укључујући `Replace All` начињену над свим пројектима:
она оставља по један унос у сваком пројекту који је дотакла.

**Нестаје ако се опозове до полазне тачке.** То није
детаљ приказа: број измена се броји, а не бележи као да-или-не, па
враћање може да га доведе до нуле и ознака нестаје.

## Две ствари које треба знати

**Упориште је последње чување**, или отварање датотеке ако чувања
није било. Чување га помера: ознака нестаје, а опозив после тога
враћа је.

Операција начињена после опозива **брише оно што је било за понављање**:
понављање би поново извело команду чије полазно стање више не постоји. То је
понашање сваког уређивача, и намерно је.

**Док је ћелија отворена**, `Undo` и `Redo` — из менија или са траке са алаткама —
прво потврђују унос, као остали покрети из
[Уређивање ћелије](editing.md). Оно што је управо укуцано тада постаје последњи
унос у историји: `Undo` опозива њега, а не претходну операцију; `Redo` нема
шта више да понови, јер унос брише оно што је било за понављање. Отворена
ћелија у коју ништа није укуцано не оставља унос: `Undo` тада опозива претходну
операцију.

Историја чува хиљаду уноса и заборавља најстарије преко тога.
