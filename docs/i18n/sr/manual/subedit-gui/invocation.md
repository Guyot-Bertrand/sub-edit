# Покретање

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

```
subedit-gui [--version] [<file>]
```

| Аргумент | Обавезно | Вредност | Подразумевано |
| :------- | :------- | :------- | :------------ |
| `<file>` | не | путања датотеке титлова коју треба отворити | нема — прозор се отвара празан |
| `--version` | не | — | — |

**Једна једина датотека.** Следећи аргументи се занемарују: прозор држи
само један пројекат одједном.

## `--version`

Пише на стандардни излаз блок који пише `--version` командне линије, и
одмах се враћа, без отварања прозора. Излазни код `0`.

**Само `subedit <version>` у првом реду**, затим по један ред за сваку библиотеку против које
прозор ради, са верзијом нађеном у време извршавања и, у заградама, оном
са којом је преведен; затим инсталирани језици сучеља, по шифри. На
машини са Qt 6.4.2:

```console
$ subedit-gui --version
subedit <version>
  ICU      74.2 (built with 74.2)
  Enchant  2.3.3 (built with 2.3.3)
  Qt       6.4.2 (built with 6.4.2)
  libmpv   2.2 (built with 2.2)
  Languages: en, fr
```

Бројеви овде нису преписани: то су бројеви машине, а овај приручник нема
генерисан блок који би одржавао тачним онај самог програма. Библиотеке су
оне из командне линије, ICU и Enchant, и две које повезује само прозор — Qt, и
libmpv, плејер, назначен верзијом свог клијентског API-ја, оном коју
објављује `mpv.pc`. Остало је описано у
[приручнику командне линије](../subedit-cli/invocation.md#--version). Речи
`built with` и `Languages` следе језик прозора; ништа друго га не следи.

`Помоћ ▸ О програму subedit` приказује исте библиотеке, са истог списка, у табели —
име, учитана верзија, верзија са којом је преведено, по један ред свака —, а испод
ње језике; њени наслови следе језик прозора.

## Отварање датотеке

```console
$ subedit-gui film.srt
```

Формати који се читају су **свих девет** које наводи филтер за отварање — види
[Отварање и чување](files.md#отварање). Формат се препознаје по садржају, а
не по наставку, **као и кодирање**: ознака редоследа бајтова (BOM),
ако је датотека има, а иначе кодирање које њени бајтови сугеришу.

## Када отварање не успе

Датотека која не постоји, нечитљива, она чији се бајтови не декодирају ни у
једном кодирању, или она чији садржај не препознаје ниједан формат: **прозор се
ипак отвара, празан**, а неуспех се пише на ток грешака.

**Порука именује узрок**, истим речима као и командна линија:

| Порука | Шта се догодило |
| :----- | :-------------- |
| `does not exist` | путања не означава ниједну датотеку |
| `cannot be opened: permission denied` | систем одбија да је отвори |
| `cannot be read` | систем је одбио из другог разлога |
| `cannot be decoded in the chosen encoding` | бајтови се не читају у задржаном кодирању |
| `is in no format this tool knows` | ниједан формат не препознаје садржај |
| `holds nothing recognisable as a subtitle` | формат је препознат, али ништа у њему није титл |

```console
$ subedit-gui notes.txt
subedit-gui: notes.txt: is in no format this tool knows
```

Отварање празно уместо одбијања покретања: алат још увек вреди за
нешто, а неуспех једног аргумента није разлог да се не покрене.

**Лоше формирана, али читљива датотека се отвара**, а оно што је читање успут
покупило може се прочитати на једном дугмету статусне траке — види
[дијагностику читања](files.md#дијагностика-читања).

## Излазни кодови

| Код | Када |
| :-- | :--- |
| `0` | прозор се отворио па је нормално затворен, или је `--version` одговорио |
| `2` | неочекивана грешка пре отварања — Qt недостаје, екран недоступан |

Неуспех отварања датотеке **не мења излазни код**: прозор се
отворио, а то је оно што код јавља.

## Man страница

Инсталација поставља `subedit-gui(1)` под `share/man/man1`:

```console
$ man subedit-gui
```

Она даје облик позива, `--version`, поруке о неуспеху отварања, излазне
кодове, две променљиве окружења и датотеку поставки.
**Не описује прозор** — то чини овај приручник, а страница
упућује овамо.

## Qt платформа

`QT_QPA_PLATFORM` бира на чему прозор ради. **Ако је променљива
постављена, `subedit-gui` је поштује без аргумента.**

Ако није, препушта избор Qt-у: уграђени плејер црта слику у
самом прозору, и ништа не тражи од платформе — види
[Плејер](player.md).

`QT_QPA_PLATFORM=offscreen` покреће прозор тамо где нема
графичког сервера — а то раде континуирана интеграција и тестови.

## Језик

Прозор говори језиком свог окружења, **изабраним једном, при покретању**: промена
променљивих покренутог прозора не мења ништа до следећег покретања. Променљиве и правила
су они из командне линије — `LANGUAGE`, `LC_ALL`, `LC_MESSAGES`, `LANG`, `LC_ALL=C` за
енглески, енглески **без речи** када тражени језик није инсталиран — описани у
[приручнику командне линије](../subedit-cli/invocation.md#језик). Каталози су исте
датотеке, инсталиране под `<prefix>/share/subedit/locale`.

**Језик изабран у `Уређивање ▸ Поставке…` има предност**, а окружење се чита само
када је ту `System default`, што је све док се други не изабере: инсталиран језик изабран ту
побеђује сваку променљиву, укључујући `LC_ALL=C`. И тај избор важи од
следећег покретања. Види
[Језик сучеља](preferences.md#језик-сучеља).

| Шта | Следи језик |
| :-- | :---------- |
| менији и њихове ставке, са подвученим словима; трака са алаткама; облачићи са саветима | да |
| ступци табеле и менија `Приказ ▸ Ступци`, језичци, статусни ред, трака репродукције | да |
| стандардна дугмад која Qt сам црта (`OK`, `Cancel`) | да, када је инсталиран Qt-ов властити каталог тог језика (`qtbase_<language>.qm`); иначе енглески |
| дијалози, странице `Correct Texts…`, наслови и филтери дијалога датотека, оквири са порукама и оно што говоре | да |
| редови које прозор пише на свој ток грешака, `subedit-gui: …` | да, осим имена програма |
| имена образаца исправки у `Correct Texts…`, и њихови описи у облачићима са саветима | да, за обрасце испоручене са програмом; образац самог корисника приказује се онако како га пише његова датотека |
| имена кодирања, завршетака редова и језика провере писања (`UTF-8`, `CRLF`, `en_US`) | никада: то су имена, а не речи |
| пречице на тастатури | никада: `Ctrl+S` је `Ctrl+S` на сваком језику |
| порука коју каталог не преводи | приказана на енглеском |

Ово издање инсталира `ca`, `cs`, `de`, `es`, `fi`, `fr`, `gl`, `he`, `hu`, `ie`, `is`, `it_IT`, `nl`, `pl`, `pt`, `pt_BR`, `ru`, `sr`, `tr` и `zh_CN` — каталонски, чешки, немачки,
шпански, фински, француски, галицијски, хебрејски, мађарски, интерлингве, исландски, италијански, холандски, пољски, португалски, бразилски португалски, руски, српски, турски и поједностављени кинески — преведене у потпуности. Француски је прегледао читалац
језика; каталонски, чешки, немачки, шпански, фински, галицијски, хебрејски, мађарски, интерлингве, исландски, италијански, холандски, пољски, португалски, бразилски португалски, руски, српски, турски и поједностављени кинески су машински преведени и још непрегледани од читаоца
језика.
