# `snap`

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

```
subedit-cli snap --rate <rate>
                 (--output FILE | --output-dir DIR | --in-place)
                 [--dry-run]
                 [--recursive]
                 <file>...
```

Поставља **сваку временску ознаку** — почетак и крај — на најближи кадар
задате брзине кадрова. Ништа се поново не усклађује: сваки положај се помера за
највише пола кадра.

## `snap` није `framerate`, а мешање једног с другим се не примећује

Две команде имају исти облик — датотеке, одредиште, брзину кадрова — а раде супротне ствари.

| | [`framerate`](framerate.md) | `snap` |
| :--- | :-------------------------- | :----- |
| шта израчунава | `t' = t x input rate / output rate` | најближи кадар, на мрежи опције `--rate` |
| за колико помера | сразмерно времену — **неколико секунди** на целовечерњем филму | највише пола кадра, **свуда** |
| за коју датотеку | датотеку чије је **време погрешно** | датотеку чије је време **исправно**, а мрежа погрешна |

**Случај употребе подкоманде `snap`**, речено до краја: филм са 25 кадрова у
секунди, датотека титлова написана на мрежи од 24, редови већ
отприлике на свом месту до на неколико милисекунди. Нема шта да се поново усклади
— само да се временске ознаке врате на праве кадрове.

**Случај употребе подкоманде `framerate`** је онај други: датотека временски
усклађена за мајстор копију са 25 коју желимо да пустимо на копији са 23.976 и чије време
до краја филма одлута за
неколико секунди.

Узимање једне за другу **не изазива никакву грешку**: обе
прихватају датотеку и пишу резултат. Ред приповедања је оно што
их разликује — `snap` увек каже за колико је померио положаје.

<!-- example: subedit-cli snap --help -->
```console
$ subedit-cli snap --help
Move every position onto the nearest frame of a frame rate (see framerate)
Usage: subedit-cli snap [OPTIONS] files...

Positionals:
  files TEXT ... REQUIRED     Subtitle files to align

Options:
  -h,--help                   Print this help message and exit
  -r,--recursive              Take directories as inputs, and every subtitle file in them
  --rate TEXT REQUIRED        Frame rate to align on: 25, 23.976
  --output TEXT               File to write, for a single input
  --output-dir TEXT           Directory to write into
  --in-place                  Write back over the inputs
  --dry-run                   Work out and say what would be written, and write nothing
```

## Аргументи и опције

| Опција | Обавезно | Вредности | Подразумевано |
| :----- | :----- | :------ | :----- |
| `<file>...` | да | једна или више путања | — |
| `--recursive`, `-r` | не | опција без вредности | искључено — види [Обрада стабла директоријума](lots.md) |
| `--rate` | **да** | брзина кадрова у кадровима у секунди, написана као за [`framerate`](framerate.md#писање-брзине-кадрова) | — |
| `--output` / `--output-dir` / `--in-place` | **једна од три**, осим уз `--dry-run` | види [Покретање](invocation.md#одредиште) | — |
| `--dry-run` | не | опција без вредности: израчуна и јави, ништа не пише — види [Прво видети, па писати](invocation.md#прво-видети-па-писати) | искључено |

Опција `--rate` прихвата **сваку исправну брзину кадрова**, а не само осам
стандардних: то је избор корисника, као код подкоманде `framerate`. Нула или негативна
брзина кадрова се одбија.

Формат прочитане датотеке се **чува**: промена формата је посао подкоманде
[`convert`](convert.md).

## Излаз

**Стандардни излаз** — ништа: резултат је написана датотека. Ни уз `--dry-run` ништа: нема датотеке, а ред приповедања то каже — види [Прво видети, па писати](invocation.md#прво-видети-па-писати).

| Ниво | Шта се додаје на стандардној грешци |
| :----- | :------------------------------------- |
| 1 | `<path>: N subtitles aligned on 25 fps, M positions moved, by at most 20 ms -> <destination>` |
| 2 | `<path>: SubRip, UTF-8, no BOM, LF line endings kept` — формат, кодирање, ознака и завршеци редова прочитане датотеке, враћени какви су били |
| 3 | `<path>: N bytes read, M written`, затим **свака дијагностика читања** — види [Покретање](invocation.md#читање-дијагностике) |

**Та два броја су смисао реда.** Пола кадра при 25 кадрова у
секунди износи двадесет милисекунди, и ништа веће ту не може бити написано. Ко је
хтео `framerate`, а укуцао `snap`, чита „by at most 20 ms“ тамо где је очекивао
секунде, и одмах зна.

## Пример

Ред на `00:00:01,010`, поравнат на 25 кадрова у секунди — дакле на
вишекратник од четрдесет милисекунди:

<!-- example: printf '1\n00:00:01,010 --> 00:00:03,020\nUn.\n\n' > a.srt; subedit-cli snap --rate 25 --output b.srt a.srt; cat b.srt -->
```console
$ printf '1\n00:00:01,010 --> 00:00:03,020\nUn.\n\n' > a.srt; subedit-cli snap --rate 25 --output b.srt a.srt; cat b.srt
a.srt: 1 subtitle aligned on 25 fps, 2 positions moved, by at most 20 ms -> b.srt
1
00:00:01,000 --> 00:00:03,040
Un.
```

## Два својства

**Поравнавање два пута не мења ништа други пут.** Положај који је већ на
кадру ту и остаје: то је иста операција примењена на исти резултат.

**Редослед титлова се чува.** Заокруживање на најближи кадар је
монотоно, па два почетка удаљена бар један кадар то и остају. Ближи један другом,
могу се стопити — а то је аномалија коју
[`inspect`](inspect.md#шта-јавља-anomalies) уме да именује, а не
инверзија.

### У JSON-у

Уз [`--format json`](invocation.md#излаз-који-скрипта-може-да-чита), објекат сваке датотеке садржи `counts.subtitles`, `counts.moved` (померени положаји) и `counts.furthest_ms` (највеће померање, у милисекундама). Пуна табела је она из одељка [Покретање](invocation.md#шта-свака-подкоманда-уписује-у-counts).

## Излазни кодови

Они из програма: `0` ако је свака датотека написана, `2` ако
ниједна, `3` ако само неке, `1` при грешци у употреби.

## Грешке

Оне брзине кадрова, реч по реч оне из подкоманде [`framerate`](framerate.md#грешке)
— обе читају исту вредност истим путем:

| Шта је изазива | Порука |
| :------------------ | :------ |
| нулта или негативна брзина кадрова | `"…" is not a frame rate: a frame rate must be strictly positive; nothing runs at that speed` |
| децимални зарез | `"…" is not a frame rate: use a decimal point and not a comma, in every language` |
| текст који није број | `"…" is not a frame rate: expected frames per second, like 25 or 23.976` |
| брзина кадрова ван сваке сразмере | `"…" is not a frame rate: no video runs at that many frames per second` |

**Ништа се не пише без једне од три опције одредишта**, а њихове грешке
заједничке су подкомандама које пишу:
види [Покретање](invocation.md#одредиште).
