## Језик

Командна линија говори језиком свог окружења: **њена помоћ, њено приповедање и њене
грешке** прате тражени језик. Примери у овом приручнику покрећу се на енглеском —
блокове генерише `make manual`, никада се не преписују ручно.

**Како се језик бира.** Прва од променљивих `LC_ALL`, `LC_MESSAGES` и `LANG` која је постављена и
није празна јесте локал; `LANGUAGE`, када је постављена, затим набраја тражене језике, раздвојене
двотачкама (`LANGUAGE=pt_BR:fr`), и чита се прва. То је редослед који прати gettext, а чита га
сам програм: локал не мора бити генерисан на машини.

| Правило | Дејство |
| :--- | :----- |
| кодирање и модификатор | занемарују се: `fr_FR.UTF-8@euro` тражи `fr_FR`, па `fr` |
| `LC_ALL=C`, локал `C` или `POSIX`, или никакав локал | енглески, а `LANGUAGE` се не чита |
| ставка која именује енглески (`en`, `en_GB`) | енглески: оно што за њом следи у `LANGUAGE` не чита се |
| језик чији каталог није инсталиран | следећи тражени, а после последњег енглески, **без иједне речи** |
| порука коју каталог не преводи | приказује се на енглеском |

**Име обрасца исправке** за који `correct` јавља да није могао да се примени такође прати језик,
када га каталог зна — то су обрасци који се испоручују са програмом; образац корисника
именује се како га пише његова датотека. Саме датотеке образаца никада се не преписују.

Каталози се инсталирају под `<prefix>/share/subedit/locale/<language>/LC_MESSAGES/subedit.mo`
и налазе се из директоријума саме извршне датотеке. Енглески је уграђен. Ова верзија инсталира `ca`, `cs`, `de`, `es`, `fi`, `fr`, `gl`, `he`, `hu`, `ie`, `is`, `it_IT`, `nl`, `pl`, `pt`, `pt_BR`, `ru`, `sr`, `tr` и `zh_CN` — каталонски,
чешки, немачки, шпански, фински, француски, галицијски, хебрејски, мађарски, интерлингве, исландски, италијански, холандски, пољски, португалски, бразилски португалски, руски, српски, турски и поједностављени кинески — преведене у целини. Француски је прегледао
читалац језика; каталонски, чешки, немачки, шпански, фински, галицијски, хебрејски, мађарски, интерлингве, исландски, италијански, холандски, пољски, португалски, бразилски португалски, руски, српски, турски и поједностављени кинески
машински су преведени и још непрегледани од читаоца језика.

Под `LANG=fr_FR.UTF-8`, `subedit-cli --help` почиње са „Lire,
inspecter et recaler des fichiers de sous-titres.“ Скрипта која чита речи текстуалног
излаза поставља `LANGUAGE=en` (или `LC_ALL=C`) — или чита `--format json`, који се никада не мења.

**Оно што никада не прати језик** — оно што скрипта чита:

| Никада се не преводи | Зашто |
| :--------------- | :-- |
| излаз `--format json`: кључеви, вредности, и `message` и `detail` неуспеха и упозорења | исти бајтови на сваком језику; речи су енглеске |
| излазни кодови | четири из одељка [Излазни кодови](#излазни-кодови), на сваком језику |
| откуцана имена: подкоманде, опције, њихове вредности (`off`, `srt`), метапроменљиве (`FILE`, `TEXT`, `OPTIONS`) | командна линија написана једном ради на сваком језику |
| имена образаца исправке које примају `correct --enable` и `--disable` | образац се зове енглеским именом које његова датотека садржи |
| имена формата и кодирања | формат се зове својим именом |
| сопствене дијагностике библиотеке CLI11 — недостајући обавезан аргумент, непозната опција, вредност коју опција не прихвата — и њено `Run with --help for more information.` | срочене унутар рашчлањивача на којем је командна линија изграђена; остају енглеске |

Тражење енглеског, ма какво било окружење:

<!-- example: LC_ALL=C LANGUAGE=fr subedit-cli shift --output-dir out a.srt; echo "code=$?" -->
```console

shift needs --by, or --to-grid to work the amount out from the positions
code=1
```

## Глобалне опције

**Пишу се пре имена подкоманде, и само ту.**
`subedit-cli --encoding cp1252 inspect film.srt` је исправан облик;
`subedit-cli inspect --encoding cp1252 film.srt` се одбија, са
`The following argument was not expected: --encoding`. Исто важи за
`--version`, `-v` и `--quiet`.

**`--help` је изузетак, и није баш изузетак**:
`subedit-cli inspect --help` се прихвата јер свака подкоманда носи своју, а пише се помоћ
подкоманде, не алата.

| Опција | Дејство |
| :----- | :---- |
| `-h`, `--help` | пише помоћ и стаје; помоћ подкоманде ако је једна именована |
| `--version` | пише `subedit <version>`, библиотеке према којима алат ради и инсталиране језике, и стаје — види [`--version`](#--version) |
| `-q`, `--quiet` | ниво 0 — никакво приповедање |
| `-v`, `-vv`, `-vvv` | нивои од 1 до 3; ниво 1 је подразумеван |
| `--encoding NAME` | чита датотеке у овом кодирању, уместо да га погађа |
| `--list-encodings` | пише кодирања која алат може да чита и пише, једно у реду, и **стаје** (код `0`) — види [`--list-encodings`](#--list-encodings) |
| `--format text\|json` | облик резултата на стандардном излазу: текст, или један JSON објекат по датотеци — види [Излаз који скрипта може да чита](#излаз-који-скрипта-може-да-чита) |
| `--config FILE` | чита поставке операција из `FILE` уместо из датотеке поставки корисника — види [Датотека поставки](#датотека-поставки) |
| `--no-config` | не чита ниједну датотеку поставки: свака поставка операције која није дата у реду добија своју уграђену подразумевану вредност — види [Датотека поставки](#датотека-поставки) |

Опције `--quiet` и `-v` у истом позиву се одбијају: две супротне намере
не решавају се у корист последње написане.

Опције `--config` и `--no-config` у истом позиву такође се одбијају, са
`--config excludes --no-config`, као и `--config` са празним именом, са
`--config needs a file name`: празно име не именује ниједну датотеку, а корисникова
датотека се не чита уместо ње.

### Датотека поставки

**[`adjust`](adjust.md) и [`correct`](correct.md) подразумевано читају поставке операција из
датотеке поставки** — вредности које `Adjust Durations…` и `Correct Texts…` памте у
прозору, или које је записала подкоманда [`config set`](config.md). Ниједна друга подкоманда је не чита. Датотека је:

```
$XDG_CONFIG_HOME/subedit/settings.conf
```

или `~/.config/subedit/settings.conf` када `XDG_CONFIG_HOME` није постављена, празна или није апсолутна
путања — датотека прозора, описана у [његовом приручнику](../subedit-gui/preferences.md#датотека).

**Приоритет, од најјачег: опција у командној линији, затим датотека, затим уграђена
подразумевана вредност.** Опција увек побеђује: `--speed off` искључује брзину коју датотека поставља. Чита се само
**блок операција** датотеке; поставке приказа (геометрија, ступци, тема…)
никада. [`config list`](config.md#config-list) именује кључеве и оне које командна
линија чита: девет кључева `duration-adjust.*`, `correction.human`, `correction.ocr`,
`correction.remove-blank` и `correction.line-break.max-lines`. **Свака од њих има опцију
која је за један позив надјачава**, ма како је датотека поставила — табеле у одељцима
[`adjust`](adjust.md#шта-даје-датотека-поставки) и
[`correct`](correct.md#шта-се-бира-а-шта-не) их именују.

**Читање корисникове датотеке никада не обара команду.** Датотека која недостаје даје подразумеване вредности; датотека
која не може да се прочита даје подразумеване вредности и то јавља; вредност која не може да се прочита задржава подразумевану и именује се;
непознат кључ се занемарује. Подкоманде `adjust` и `correct` никада не пишу ту датотеку.

**Оно што је прочитано јавља се**, на подразумеваном нивоу 1, на стандардној грешци, пре прве датотеке:

| Случај | Ред |
| :--- | :--- |
| датотека је прочитана | `settings: read <path>` |
| вредност у њој није могла да се прочита | `settings: <key>: cannot read '<value>', default kept` |
| корисникова датотека не постоји | `settings: <path> not found, defaults used` |
| датотека не може да се прочита | `settings: <path> unreadable, defaults used` |
| `--no-config` | ништа |

Са [`--format json`](#излаз-који-скрипта-може-да-чита), објекат сваке датотеке подкоманди `adjust` и
`correct` носи `settings`: путању која је прочитана, или `null` када ниједна није.


**`--no-config` чини извршавање поновљивим**: исти ред даје исти резултат на свакој
машини, ма шта њен корисник поставио у прозору. Користи се у скриптама, тестовима и пријавама грешака — или
`--config FILE` са датотеком која их прати.

**`--config FILE` именује другу датотеку**, која се чита на исти начин — **осим што мора да постоји**.
Име дато у командној линији није захтев за подразумеване вредности: када `FILE` не постоји,
`adjust` и `correct` стају пре него што се прочита било који улаз, пишу `settings file not found: <FILE>` на
стандардну грешку и излазе са кодом употребе `1`. `FILE` који постоји и не може да се прочита
даје подразумеване вредности и то јавља, као и корисникова датотека. [`config show`](config.md#config-show)
и даље приказује `FILE` који недостаје као `(not found)`, а [`config set`](config.md#config-set-и-config-unset) га и
даље ствара.

<!-- example: printf '1\n00:00:01,000 --> 00:00:01,200\nUn.\n\n' > a.srt; subedit-cli --config mine.conf adjust --dry-run a.srt; echo "code=$?" -->
```console
$ printf '1\n00:00:01,000 --> 00:00:01,200\nUn.\n\n' > a.srt; subedit-cli --config mine.conf adjust --dry-run a.srt; echo "code=$?"
settings file not found: mine.conf
code=1
```

### `--version`

**Верзија програма, сама у првом реду** — `subedit <version>`, оно што је излаз био до
0.15.38 и што скрипта чита. Затим **по један ред за сваку библиотеку према којој алат ради**, затим инсталирани
језици сучеља, на стандардном излазу; алат стаје, са кодом `0`. Подкоманда дата уз то
не извршава се, а `-q` и `-v` не мењају ништа.

<!-- example: subedit-cli --version | head -n 1 -->
```console
$ subedit-cli --version | head -n 1
subedit 1.0.1
```

Све заједно, на машини са ICU 74.2 и Enchant 2.3.3 — бројеви су машинини:

```console
$ subedit-cli --version
subedit <version>
  ICU      74.2 (built with 74.2)
  Enchant  2.3.3 (built with 2.3.3)
  CLI11    2.4.1 (built with 2.4.1)
  Languages: en, fr
```

| Библиотека | За шта је алат користи |
| :------ | :------------------------ |
| `ICU` | читање и писање кодирања, њихово откривање, промена величине слова |
| `Enchant` | провера писања подкоманде `correct` |
| `CLI11` | читање ове командне линије |

- **Сваки ред даје две верзије**: ону нађену за време рада, прву, и ону са којом је програм
  изграђен, у заградама. Разликују се када је библиотека машине надограђена пошто је
  програм изграђен — прва ствар коју треба навести у пријави грешке.
- **Заглавља библиотеке Enchant не носе верзију**: она у заградама је она коју је `pkg-config` јавио
  када је градња подешена.
- **CLI11 је уграђен у програм**, јер су његова заглавља све од њега што постоји: његове две верзије су
  увек исте.
- **Ни Qt ни libmpv**: командна линија не повезује ниједну и наводи само оно према чему ради.
  Прозор их наводи — види [његов приручник](../subedit-gui/invocation.md#--version).
- **`Languages`** наводи `en`, изворни језик, који не тражи каталог, затим сваки каталог
  инсталиран под `<prefix>/share/subedit/locale` који се чита, по шифри — језици које
  нуди `Edit ▸ Preferences…`.
- **Оно што прати језик**: `built with` и `Languages`. Први ред, имена,
  бројеви и шифре језика никада.
- **Са `--format json`**, пре или после `--version`, **један објекат у једном реду**: `schema`
  (`1`), `command` (`"version"`), `version`, `libraries` — низ
  `{"name":"ICU","loaded":"74.2","built":"74.2"}`, редом као у тексту — и `languages`, низ
  шифара. Ништа у њему се не преводи.

<!-- example: subedit-cli --version --format json | grep -o '"name":"[^"]*"' -->
```console
$ subedit-cli --version --format json | grep -o '"name":"[^"]*"'
"name":"ICU"
"name":"Enchant"
"name":"CLI11"
```

### `--list-encodings`

**Кодирања која алат може да чита и пише, једно у реду, сортирана по имену**, на стандардном излазу —
затим алат стаје, са кодом `0`, као `--version`: то је одговор, а не корак. Подкоманда
дата уз то не извршава се.

<!-- example: subedit-cli --list-encodings | grep '^UTF' | head -4 -->
```console
$ subedit-cli --list-encodings | grep '^UTF' | head -4
UTF-16BE
UTF-16LE
UTF-32BE
UTF-32LE
```

- **То су имена која прихвата `--encoding`**, канонска; њихови псеудоними (`cp1252`) такође се прихватају,
  без навођења.
- **Број зависи од инсталираног ICU**, а ниједно име није обећано осим оних које има сваки ICU
  (`UTF-8`, `UTF-16LE`, `windows-1252`…). Приручник зато не даје број.
- **`UTF-16` и `UTF-32` нису у њему**: ICU их зна, али њихов претварач пише сопствену ознаку,
  а модел их одбија — види испод. Списак за избор не нуди оно што би следеће поље
  одбило.
- **Са `--format json`**, **један објекат по кодирању**:
  `{"schema":1,"command":"list-encodings","name":"UTF-8"}`. То није извештај о датотеци: ови
  објекти **не носе ни `file` ни `ok`**, једини изузетак од омотнице из
  одељка [Облик](#облик). И даље су један објекат у реду, по један за ставку.
- **Ниво приповедања не мења ништа**: списак је резултат, а `-q` га не одузима.

### `--encoding`, и оно што не може да наметне

**Важи за сваку подкоманду**, јер све читају: датотека чије је
кодирање погрешно погођено остаје погрешна ма шта јој се радило, а опција
коју би носио само `inspect` оставила би неслагање без лека.

**Име је оно које користи ICU, и сви његови псеудоними се прихватају**: `cp1252`,
`windows-1252` и `WINDOWS 1252` именују исто кодирање. Скуп није написан
нигде: то је онај који ICU машине може да претвори, а
[`--list-encodings`](#--list-encodings) га набраја. Име које не може да претвори
одбија се пре него што се прочита и једна датотека:

```console
$ subedit-cli --encoding klingon-1 inspect film.srt
no encoding is named "klingon-1"
```

**Један изузетак, и само један: кодирање мора да именује свој редослед бајтова.**
`UTF-16` и `UTF-32` су имена која ICU зна и чији претварач пише **сопствену
ознаку**. Таква кодирања не могу да живе у овом моделу — ознака престаје
да буде избор, `--no-bom` би био прихваћен и непоштован — па се оба
одбијају, и при читању и при писању:

```console
$ subedit-cli --encoding UTF-16 inspect film.srt
"UTF-16" writes a byte order mark of its own; name the byte order, as UTF-16LE and UTF-16BE do
```

`UTF-16LE` и `UTF-16BE` читају и пишу исте бајтове, укључујући ознаку; оно
што прецизно име додаје јесте да се зна који је.

**Ознака редоследа бајтова побеђује опцију.** То је једина ствар коју датотека титлова
декларише о себи, а читање другачије него што се декларише значило би
послушати позиваоца против датотеке. Неслагање се **јавља**, као
дијагностика:

```console
$ subedit-cli -vvv --encoding cp1252 inspect avec-bom.srt
avec-bom.srt: a byte order mark that contradicts the encoding asked for ("UTF-16LE"), settled by the reader
```

То је оно што ради и Gaupol — поново започиње читање са кодирањем
ознаке — али не казујући то; овде разлика између оног што је тражено и
оног што је урађено није тишина.

**Само једна не дира ништа**, а то је десна колона: `inspect` чита и
јавља. Осталих деветнаест пишу, а оно што следи важи за седамнаест од њих:
[`append`](append.md) и [`split-file`](split-file.md) имају сваки свој број улаза и излаза — N датотека за
**један** резултат, једна датотека за **два** — а тиме и своје одредиште, које описују на својој страници.
[`config`](config.md) не пише ниједну датотеку титлова: чита и мења датотеку поставки, а
ништа од онога што следи се на њу не односи.

## Одредиште

Седамнаест подкоманди које пишу — [`convert`](convert.md),
[`shift`](shift.md), [`transform`](transform.md), [`framerate`](framerate.md),
[`snap`](snap.md), [`hearing-impaired`](hearing-impaired.md), [`adjust`](adjust.md),
[`replace`](replace.md), [`case`](case.md), [`italics`](italics.md),
[`dialogue-dashes`](dialogue-dashes.md), [`sort`](sort.md), [`join-repeats`](join-repeats.md),
[`disjoint`](disjoint.md), [`repair`](repair.md), [`correct`](correct.md), [`pair`](pair.md) — примају своје одредиште на исти начин. ([`append`](append.md) и
[`split-file`](split-file.md) имају своје, на својој страници.) [`inspect`](inspect.md) не пише ниједну датотеку и
не прихвата ниједну од ових опција.

**Одредиште које већ постоји се преписује**, без питања и без опције да
се то избегне: писање је атомско — датотека никада није напола записана, а
прекинуто писање оставља стару нетакнуту —, али претходни садржај је
изгубљен. То није мана коју треба задржати: то је правило, а поновно покретање команде
над истим излазним директоријумом покреће је поново над самом собом.

**Ништа се никада не пише без изричитог одредишта.** Три начина да се оно
зада међусобно се искључују, а један је потребан: без њега се ништа не пише, а излазни
код је `1` — осим са [`--dry-run`](#прво-видети-па-писати), који не пише ништа
и зато не захтева ниједно.

| Опција | Куда иде резултат |
| :----- | :---------------- |
| `--output FILE` | у ову датотеку, под овим тачним именом; један једини улаз |
| `--output-dir DIR` | у овај директоријум, под основним именом улаза |
| `--in-place` | преко улаза, атомским писањем |

Алат који преписује свој улаз зато што му ништа није речено је алат који се
престане користити други пут. Одбијање кошта један ред, а спашава
датотеку.

`--output` са више улаза се одбија: последња датотека би била записана преко
претходних. Са серијом, `--output-dir` је једина од три која има
смисла, уз `--in-place`.

**Излазни директоријум се ствара** ако недостаје, укључујући родитеље — за
`--output-dir`, и за директоријум у који пише `--output`. То се ради пошто је
командна линија потврђена и **пре прве датотеке**. Ако не може да се створи,
јавља се једном, ниједна датотека се не чита, а излазни код је
`2`.

**Серија се оцењује као целина пре писања.** Прво се израчуна одредиште сваког улаза,
а из тога следе два одбијања — грешке у употреби, код
`1`, **ниједна датотека није записана** и ниједан директоријум није створен:

- **два улаза која би завршила у истој датотеци** — `a/film.srt` и
  `b/film.srt` са `--output-dir`, или `a/film.srt` и `b/film.vtt` оба
  претворена у WebVTT, чије је коначно одредиште променило наставак. Порука
  именује одредиште и оба улаза; преименовање другог или
  допуштање да последњи победи изгубило би датотеку не казујући то, а одбијање
  кошта један ред;
- **одредиште које је један од улаза**, без `--in-place` — укључујући
  преко `--output-dir .`, преко `--output` или преко симболичке везе. Писање преко
  сопственог улаза је гест који се именује.

Две путање именују исту датотеку када то каже систем, а не када су
написане слично: `in/../in/film.srt` и `in/film.srt` су једна датотека.

**Наставак прати записани формат.** Мења се само код
подкоманде [`convert`](convert.md), једине која мења формат; остале
задржавају формат прочитане датотеке, а тиме и њен наставак.

| Шта их изазива | Порука |
| :------------------ | :------ |
| нема одредишта, без `--dry-run` | `no destination given: use --output, --output-dir or --in-place` |
| два одредишта | `--output, --output-dir and --in-place exclude one another` |
| `--output` на серији | `--output names one file but several were given: use --output-dir instead` |
| два улаза, једно одредиште | `<destination>: would be written by both <input> and <input>` |
| улаз би био преписан | `<destination>: would be written over the input <input>` — иста реченица за [`append`](append.md) и [`split-file`](split-file.md) |
| излазни директоријум који не може да се створи | `<directory>: cannot be created: permission denied`, или `: cannot be created` |
| одредиште које не може да се запише | `<path>: <destination>: cannot be written: permission denied`, или `: cannot be written` |
| знак којег нема у записаном кодирању | `<path>: holds a character the chosen encoding cannot write` |

**Последња заслужује једну реченицу.** Датотека се записује назад у **кодирању у којем је
прочитана**, као и са својим завршецима редова и својом ознаком. Ако је
измена унела у њу знак који то кодирање не познаје — на пример
`ł` у Latin-1 —, писање пада и **ништа се не пише**. Замена тог знака
знаком `?` значила би губљење текста пред очима оног ко га је управо написао.

## Прво видети, па писати

**`--dry-run`** прихвата свака од шеснаест подкоманди које пишу и свуда значи исто:
**прочитај, израчунај, јави, не пиши ниједну датотеку**. Додаје се у
ред који је требало покренути; примена је поновно покретање истог реда без њега. Израчунавање је
детерминистичко: оно што је `--dry-run` показао јесте оно што ће следеће извршавање записати, све док
се датотека не промени.

- **Не пише ниједну датотеку и не ствара ниједан директоријум**, укључујући `--in-place`: улазна
  датотека остаје каква је била.
- **Не захтева одредиште.** Оно може бити дато, и **тада се проверава као без
  `--dry-run`**: два улаза за исто одредиште, улаз који би био преписан,
  `--output` на серији, два начина да се каже куда — командна линија одбијена без `--dry-run`
  одбија се и са њим, истом реченицом и истим кодом `1`.
- **Излазни код је код правог извршавања**: `0` када је све израчунато, `2` или `3`
  када датотеке нису могле да се прочитају или обраде, `1` за употребу. Знак који
  кодирање датотеке није могло да запише обара пробно извршавање као и право.
  **То што измене постоје не мења код**: четири кода казују да ли је алат
  успео, а не да ли датотека одговара.
- **Приповедање то каже.** Тамо где право извршавање пише `-> <destination>`, пробно
  пише `(dry run, nothing written)`.

<!-- example: printf '1\n00:00:10,000 --> 00:00:12,000\nBonjour.\n\n' > a.srt; subedit-cli shift --by 1 --dry-run a.srt; ls -- *.srt -->
```console
$ printf '1\n00:00:10,000 --> 00:00:12,000\nBonjour.\n\n' > a.srt; subedit-cli shift --by 1 --dry-run a.srt; ls -- *.srt
a.srt: 1 subtitle shifted by 1.000 s (dry run, nothing written)
a.srt
```

**На подкоманди које мењају текстове** —
[`hearing-impaired`](hearing-impaired.md), [`replace`](replace.md), [`case`](case.md),
[`italics`](italics.md), [`dialogue-dashes`](dialogue-dashes.md) и [`correct`](correct.md) —, **стандардни излаз носи предложене
измене**. Један блок по измењеном титлу, редом датотеке:

```
<path>: subtitle <number>
- <the text before, line by line>
+ <the text after, line by line>
```

- **број** је онај који титл има у прочитаној датотеци, рачунат од један;
- сваки ред текста пре носи `- ` испред, сваки ред текста после `+ `: текст
  од више редова чита се какав јесте, а ред који сам почиње цртицом разговора
  даје `- - `;
- **титл који би операција уклонила** то каже у свом првом реду,
  `<path>: subtitle <number> (removed)`, и нема `+` редова;
- титл превода, са `--document translation`, најављује се са `(translation)` на истом
  месту — види [Превод](#превод);
- први ред сваког блока почиње путањом, тако да `grep '^film.srt: '`
  налази блокове једне датотеке у серији;
- **ниједан блок** када се ништа не би променило.

<!-- example: printf '1\n00:00:01,000 --> 00:00:03,000\n[Bruit de pas]\n\n2\n00:00:04,000 --> 00:00:06,000\nAttends [il tousse] Marie.\n\n3\n00:00:07,000 --> 00:00:09,000\n- [Grincement]\n- Qui est là ?\n\n' > mentions.srt; subedit-cli hearing-impaired --dry-run mentions.srt -->
```console
$ printf '1\n00:00:01,000 --> 00:00:03,000\n[Bruit de pas]\n\n2\n00:00:04,000 --> 00:00:06,000\nAttends [il tousse] Marie.\n\n3\n00:00:07,000 --> 00:00:09,000\n- [Grincement]\n- Qui est là ?\n\n' > mentions.srt; subedit-cli hearing-impaired --dry-run mentions.srt
mentions.srt: 2 subtitles cleaned, 1 removed (dry run, nothing written)
mentions.srt: subtitle 1 (removed)
- [Bruit de pas]
mentions.srt: subtitle 2
- Attends [il tousse] Marie.
+ Attends Marie.
mentions.srt: subtitle 3
- - [Grincement]
- - Qui est là ?
+ Qui est là ?
```

**Списак је исти у JSON-у**: објекат датотеке носи низ `changes`, види
[Облик](#облик), са `after` постављеним на `null` за уклоњен титл. **Израчунава се
само када га траже `--dry-run` или `--format json`**: серија од хиљада
титлова не гради га узалудно.

На **осталим подкомандама** — [`convert`](convert.md), [`shift`](shift.md),
[`transform`](transform.md), [`framerate`](framerate.md), [`snap`](snap.md),
[`adjust`](adjust.md), [`sort`](sort.md), [`append`](append.md), [`split-file`](split-file.md), [`pair`](pair.md) —, стандардни
излаз носи оно што би носио излаз правог извршавања, то јест у тексту ништа; у
JSON-у, објекат сваке датотеке са `"dry_run":true`, `"destination":null` и истим
`counts`.

## Два излаза, две улоге

| Излаз | Шта носи |
| :----- | :--------------- |
| стандардни | **резултат, и само резултат** — извештај подкоманде `inspect`, предложене измене текстуалне [`--dry-run`](#прво-видети-па-писати); са `--format json`, један објекат по датотеци — један по извршавању за [`append`](append.md), [`split-file`](split-file.md) и [`pair`](pair.md) |
| грешака | **све остало** — приповедање, упозорења, грешке |

Управо та подела омогућава да се резултат преусмери а да му се не примеша прича:

```console
$ subedit-cli inspect *.srt > rapport.txt
```

Извештај иде у датотеку, приповедање остаје на екрану.

## Излаз који скрипта може да чита

**`--format json`** замењује текст стандардног излаза са **једним JSON објектом по
улазној датотеци**, у формату JSON Lines: један збијен објекат у реду, у UTF-8 без
ознаке, завршетак реда је `\n`. `text` је подразумеван и не мења се. То је
глобална опција, па се пише пре подкоманде; вредност различита од
`text` и `json` је грешка у употреби, код `1`.

<!-- example: printf '1\n00:00:10,000 --> 00:00:12,000\nUn.\n\n' > a.srt; subedit-cli --format json shift --by 1 --output-dir sortie a.srt absent.srt; echo "code=$?" -->
```console
$ printf '1\n00:00:10,000 --> 00:00:12,000\nUn.\n\n' > a.srt; subedit-cli --format json shift --by 1 --output-dir sortie a.srt absent.srt; echo "code=$?"
a.srt: 1 subtitle shifted by 1.000 s -> sortie/a.srt
{"schema":1,"command":"shift","file":"a.srt","ok":true,"dry_run":false,"destination":"sortie/a.srt","counts":{"subtitles":1,"shifted_by_ms":1000},"warnings":[]}
absent.srt: does not exist
{"schema":1,"command":"shift","file":"absent.srt","ok":false,"error":{"kind":"not-found","message":"absent.srt: does not exist"}}
1 of 2 files shifted, 1 failed
code=3
```

**Један објекат по улазу, никада нула, никада два**, без обзира да ли је улаз успео или не, по
редоследу којим су улази дати — или нађени, са [`--recursive`](lots.md). Један
броји редове, један налази своје датотеке. **Три подкоманде су изузетак, јер њихов
број улаза и излаза није онај серије: [`append`](append.md) (N улаза, један излаз), [`split-file`](split-file.md)
(један улаз, два излаза) и [`pair`](pair.md) (две датотеке, један излаз) пишу **један објекат за цело
извршавање**, који именује датотеку коју њихова страница каже.** **Подкоманде које преписују зато пишу и
на стандардни излаз**, што њихов уговор у тексту није радио: њихова
датотека остаје њихов резултат, а објекат је његов извештај.

**Приповедање се не мења.** Опције `-q`, `-v`, `-vv` и `-vvv` делују на излаз грешака,
у тексту, као без `--format`; **стандардни излаз не варира с њима**.
Дијагностике читања, које текст држи на нивоу 3, јесу подаци и налазе се
**увек** у `warnings`. Грешка у употреби не пише објекат: открива се
пре него што се и једна датотека дотакне, па нема за шта да се веже; иде на излаз
грешака са кодом `1`, а стандардни излаз остаје празан.

### Облик

| Кључ | Садржај | Присутан |
| :-- | :------ | :------- |
| `schema` | цео број, верзија овог облика — `1` | увек |
| `command` | име подкоманде | увек |
| `file` | путања **како је дата**, или како ју је сложио обилазак директоријума | увек |
| `ok` | логичка вредност | увек |
| `error` | `{"kind", "message"}` | ако је `ok` лажно |
| `dry_run` | логичка вредност: истинито за [`--dry-run`](#прво-видети-па-писати) | ако је `ok` истинито, на подкоманди која пише |
| `destination` | записана путања, или `null` када је `dry_run` истинито: ништа није записано | исто |
| `counts` | објекат **целих бројева**, специфичан за подкоманду | исто |
| `changes` | низ `{"subtitle", "document", "before", "after"}`: измењени текстови, види испод | на подкоманди која мења текстове |
| `warnings` | низ `{"kind", "line"?, "detail"?, "settled"?}` | ако је `ok` истинито |
| `alignment` | како је превод постављен, види [Превод](#превод) | са `-t`, и за `pair` |
| `constraints` | коришћене поставке | `adjust` |
| `settings` | прочитана датотека поставки, или `null` када ниједна није — види [Датотека поставки](#датотека-поставки) | `adjust`, `correct`, ако је `ok` истинито |
| `inputs`, `tail` | један елемент по прикаченој датотеци; путања остатка | `append`; `split-file` |

`line` изостаје из дијагностике о целој датотеци; `detail` изостаје када нема
шта да се дода; `settled` је `true` када је читање нешто **решило** — обновљено
нумерисање —, а изостаје када је оставило ствари какве јесу.

**`changes`** набраја, редом датотеке, сваки титл чији се текст мења:
`subtitle` је његов број у прочитаној датотеци, рачунат од један; `document` је `"main"`
или `"translation"`; `before` је текст пре; `after` текст после, или **`null` када
је титл уклоњен**. Преломи редова текста су у њему `\n`. Пише се
за право извршавање као и за [`--dry-run`](#прво-видети-па-писати), и је **празан
(`[]`) када се ништа не мења**: његово присуство казује да подкоманда набраја своје измене,
његово одсуство да их нема.

**Нигде број са покретним зарезом.** Положај или трајање је цео број
**милисекунди** (`…_ms`); број је цео број; брзина кадрова је **ниска**
(`"25"`, `"24000/1001"`) јер је тачна, а рационалан број са покретним зарезом не
може да је садржи; концентрација мреже је цео број у **хиљадитим деловима** — `1000` је
савршена мрежа. Два излаза се тада пореде бајт по бајт, без заокруживања.

**Путања која није UTF-8** — Linux то допушта — не може да се представи у JSON-у:
пише се са U+FFFD на месту неисправних бајтова, а објекат носи упозорење
`path-not-utf8`. Верност такве путање није обећана, и то се каже.

### Шта свака подкоманда уписује у `counts`

| Подкоманда | Кључеви у `counts` |
| :------------ | :--------------- |
| [`shift`](shift.md) | `subtitles`, `shifted_by_ms` (са предзнаком) |

| [`pair`](pair.md) | `subtitles` (они записане датотеке); и, ван `counts`, `alignment` |
| [`inspect`](inspect.md) | нема `counts`: опис датотеке, види његову страницу |

### Идентификатори грешака

`error.kind` је један од ових; **читалац непознат идентификатор третира као
„друго“**.

| `kind` | Шта је то |
| :----- | :----------- |
| `not-found`, `permission-denied`, `io` | систем је одбио да чита — или да пише — датотеку |
| `unknown-format`, `no-subtitle-found`, `undecodable` | датотека је прочитана и не даје да се прочита |
| `unencodable` | знак који изабрано кодирање не може да запише |
| `no-byte-order-mark`, `no-frame-rate` | оно што `convert` не може да запише а да му се не каже |
| `before-the-origin`, `beyond-the-end`, `no-transform`, `no-grid` | операција која се не може применити на ову датотеку |
| `range-out-of-bounds` | `--range` који ова датотека не садржи |
| `no-style` | формат који не пише стил (TMPlayer, LRC), за `italics` |
| `refused` | свако друго одбијање операције |

### Шта је обећано, а шта није

**Обећано све док је `schema` једнак `1`**: имена кључева, њихов тип и јединица; значење
кључева `ok`, `file` и `destination`; **један објекат по улазу, редом улаза** — један по извршавању за три подкоманде са сопственим бројем улаза и излаза;
идентификатори `kind` који постоје; детерминизам — исти улази, исти аргументи,
исти бајтови.

**Није обећано**: **текст порука** (`message`, `detail`), енглески за човека,
који се исправља када треба — скрипта која га пореди унапред је покварена; **редослед
кључева** у објекту, утврђен али не зајамчен од стране JSON-а; присуство **кључева који још нису
додати**.

**Читалац зато занемарује непознат кључ**, а непознат `kind` третира као „друго“:
додавање кључа или идентификатора не мења `schema`. Уклањање или преименовање кључа,
промена типа или јединице, уклањање идентификатора повећава је — то је прекид,
најављен у CHANGELOG-у и овде.

## Нивои приповедања

Сваки ниво **садржи претходни**: пењање за један степен додаје, никада не
замењује.

| Ниво | Како | Шта носи излаз грешака |
| :----- | :------ | :------------------------------ |
| 0 | `--quiet` | ништа, **осим грешака** |
| 1 | подразумевано, или `-v` | један ред по обрађеној датотеци, и збир чим их има више |
| 2 | `-vv` | и оно што је препознато: формат, кодирање, BOM, завршеци редова |
| 3 | `-vvv` | и траг за отклањање грешака: прочитани и записани бајтови, и **свака дијагностика читања** |

**Грешке се никада не ућуткују, укључујући `--quiet`.** Команда која пада
нечујно не би оставила ништа осим свог излазног кода.

Збир се појављује тек од две датотеке: на једном улазу би
поновио ред пре себе.

## Читање дијагностике

Формати титлова читају се **колико год је могуће добро**: пред аномалијом
читач не стаје — одлучује, или оставља ствари какве јесу, и то јавља. Оно на
шта је наишао излази на **нивоу 3**, један ред по дијагностици, на излаз
грешака:

```
a.srt: 2 diagnostics while reading
a.srt: line 6: SubRip numbers that do not follow ("7"), settled by the reader
a.srt: line 9: a line that fits nowhere, left as it stands
```

Свих седамнаест подкоманди их јавља, не само [`inspect`](inspect.md):
датотека прочитана колико год је могуће добро, а затим записана назад, прошла је кроз исте одлуке, а њихово
ућуткивање натерало би да се верује да се ништа није десило.

**Дијагностика никада није неуспех.** Датотека је прочитана, команда је
успела, излазни код је `0`. Зато живе на најдетаљнијем
нивоу: ниже би затрпале ред који казује шта је заиста
урађено.

### Шта носи сваки ред

| Део | Шта казује |
| :----- | :------------- |
| `line N` | где, рачунато од 1, како то приказује уређивач; **изостаје** за оно што се тиче целе датотеке |
| реченица | на шта се наишло, међу дванаест категорија испод |
| `("…")` | погрешан текст из датотеке, када категорија није довољна; скраћен на 80 бајтова |
| крај | шта је учињено поводом тога: `settled by the reader`, или `left as it stands` |

**Две категорије немају ред**, и то су две које се тичу
кодирања: бајтови су одмеравани, или је њихова ознака читана, пре него што је једини
ред датотеке постојао. Њихов ред зато почиње реченицом, без `line N`
испред — нема места које би се именовало.

**Крај реда је оно што је најважније.** `settled by the reader` значи
да је читач одлучио и да записана датотека носи његову одлуку — недостајуће
нумерисање се обнавља. `left as it stands` значи да није дирнуо
ништа јер **може одлучити само корисник**: титл који се завршава пре него што
почне остаје какав јесте.

### Број реда једног блока

Аномалија о **целом блоку** везује се за његов ред
времена, а не за тачан ред који је изазива. Недоследно нумерисање
написано у реду 5 зато се јавља у реду 6, оном реда времена који
следи — погрешан број је у `("…")`. Саме по себи јављају се само аномалије о
**једном реду** — нечитљив ред времена, текст пре првог.

### Дванаест категорија

| Реченица | Шта је изазива |
| :----- | :------------------ |
| `a line that fits nowhere` | ред који не улази ни у један блок |
| `a timing line that could not be read` | нечитљив ред времена |
| `a SubRip block without its number` | недостајуће нумерисање, обновљено при писању |
| `SubRip numbers that do not follow` | нумерисање које скаче |
| `text before the first timing line` | текст пре првог реда времена |
| `a WebVTT block of an unknown kind` | непрепознат блок формата WebVTT |
| `declares an event column this tool cannot fill` | колона догађаја формата Sub Station Alpha коју овде ништа не попуњава |
| `counts in frames and states no rate; it was read at` | датотека у кадровима која не наводи брзину кадрова — употребљена брзина је детаљ |
| `carries no end times; each one was taken from the next start` | формат без крајева, TMPlayer или LRC: **ниједан крај у табели не долази из датотеке** |
| `more than one kind of line ending` | помешани завршеци редова |
| `an encoding nothing declared` | кодирање је предложено одмеравањем бајтова, и није UTF-8 |
| `a byte order mark that contradicts the encoding asked for` | датотека носи ознаку, а `--encoding` је именовао другу — ознака побеђује |

**Три из средине су оне из фазе 9**, а последња два од та
три не говоре о реду већ о целој датотеци: казују да
приказана вредност није прочитана. Попуњена колона `End` на LRC-у,
положај у MicroDVD-у — датотека ништа од тога није носила.

**Операција може да дода сопствену**, која није дијагностика читања:
[`correct`](correct.md#образац-који-се-не-може-применити) јавља, са титлом, образац
који је одустао. Јавља се на нивоу 1 и носи, у објекту датотеке, идентификатор
`pattern-failed` — никада неуспех датотеке.

## Превод

Датотека превода обрађује се **као свака датотека титлова**:
`subedit-cli case --to sentence film.fr.srt` мења је без ичег новог. Оно што упаривање додаје, и што
три опције казују, је уско: **знати како редови превода падају на
титлове главне датотеке** — то је `inspect -t` —, и **мењати превод држећи га
положеног на његову главну датотеку**, истим правилима као прозор.

| Опција | Где | Вредност | Подразумевано |
| :----- | :---- | :----- | :----- |
| `-t`, `--translation-file` | `inspect`, `hearing-impaired`, `replace`, `case`, `italics`, `dialogue-dashes`, `correct`, `pair` | датотека превода | — |
| `--document` | шест текстуалних подкоманди, не `inspect` ни `pair` | `main` или `translation` | `main` |
| `--align-method` | као `-t` | `position` или `number` | `position` |

- **`position`** упоређује средину сваког реда са границама титлова: ред који недостаје не
  помера оне који следе. **`number`** шаље ред *n* на титл *n*, не гледајући
  положаје. Положај је подразумеван, из разлога који има и прозор: ред који недостаје усред
  превода упареног по броју помера сав остатак.
- **`--document translation` захтева `-t`, а `-t` захтева `--document translation`** на текстуалној
  подкоманди — једно без другог је грешка у употреби, код `1`, јер је прочитана датотека коју ниједан гест
  не користи пропуст, а не склоност. `-t` на `inspect` нема `--document`: он
  јавља. **`--align-method` без `-t` је такође грешка у употреби.**
- **`-t` именује датотеку, па има смисла само за један улаз**: са више улаза, или
  са директоријумом узетим преко `--recursive`, одбија се као `--output`, **пре него што се датотека
  прочита**. За серију, покреће се један позив по пару.
- **Датотека превода идентична главној се одбија** — ма како јој
  је путања написана: `<translation>: the file is already open as the main document`, код `2`.
- **Пише се само документ на који се циља**, на **његовој путањи и у његовом формату**: формат,
  кодирање и завршеци редова датотеке превода. `--output` именује датотеку
  превода, `--output-dir` ставља тамо њено основно име, `--in-place` је преписује; **главна датотека
  се никада не дира**. Путање у извештају су путање превода.
- **Титлови које упаривање оживи** — ред до којег ништа није стигло — записују се у
  превод са **својим положајима**, ма који био метод; **титл који нико
  није превео записује се као блок без текста**, који се чита без аномалије.
- **`--encoding` и `--frame-rate` важе за обе датотеке.**
- Подкоманде за **положаје** — `shift`, `transform`, `framerate`, `snap`, `adjust` — немају
  ове опције: дају им се обе датотеке, као серија,
  `subedit-cli shift --by 2 film.srt film.fr.srt --output-dir out/`.
- **Писање превода поново усклађеног на главну датотеку** — једина ствар коју упаривање ради а коју датотека сама не ради —
  посао је подкоманде [`pair`](pair.md), која нема ни `--document` ни `--recursive`.

```console
00:00:01,000 --> 00:00:02,000
Bonjour.

2
00:00:03,000 --> 00:00:04,000
Au revoir.
```

Са `--format json`, објекат сваке датотеке носи и кључ `alignment`, који казује како је
превод положен — `{"file", "method", "attached", "born", "untranslated", "out_of_order"}`, као
кључ `translation` подкоманде [`inspect`](inspect.md#у-json-у) — а, **са `--dry-run`**, `changes` набраја
титлове превода, сваки са `"document":"translation"`.

## Више датотека

Свака подкоманда прихвата више путања, осим [`append`](append.md), [`split-file`](split-file.md) и
[`pair`](pair.md), чији је број улаза и излаза онај на њиховој страници. Свака се обрађује
независно: неуспех једне не прекида остале, а неуспеси
се јављају са именом датотеке и разлогом.

**Директоријум стоји за датотеке које садржи, са `--recursive` (`-r`)**:
без ове опције његово навођење је грешка у употреби, код `1`, и ништа се не
обрађује — боље га је одбити него не обрадити ништа и вратити `0`:

<!-- example: mkdir films; printf '1\n00:00:01,000 --> 00:00:02,000\nUn.\n\n' > films/a.srt; subedit-cli inspect films; echo "code=$?" -->
```console
$ mkdir films; printf '1\n00:00:01,000 --> 00:00:02,000\nUn.\n\n' > films/a.srt; subedit-cli inspect films; echo "code=$?"
films: is a directory: use --recursive
code=1
```

Обилазак, стабло задржано под `--output-dir` и оно што се оставља
по страни описани су у одељку [Обрада стабла директоријума](lots.md).

## Man странице

Инсталација ставља **по једну man страницу за сваку подкоманду** поред `subedit-cli(1)`:
`subedit-cli-shift(1)`, `subedit-cli-convert(1)` и остале, по једну за сваки ред
[табеле подкоманди](#подкоманде). Страница `subedit-cli(1)` садржи ово поглавље — глобалне опције,
излазе, излазне кодове — а свака друга страница садржи поглавље своје подкоманде, укључујући
њене примере. Страница прозора, `subedit-gui(1)`, је поред њих.

```console
$ man subedit-cli
$ man subedit-cli-shift
```

**Странице се не пишу одвојено од овог приручника**: генеришу се из њега када се
програм гради, па казују оно што он казује и не могу да одлутају од њега. Одељак FILES сваке
странице именује директоријум у који је приручник инсталиран.

| Странице | Где се инсталирају |
| :---- | :----------------------- |
| енглеске | `share/man/man1` |
| сваки инсталиран језик — каталонски, чешки, немачки, шпански, фински, француски, галицијски, хебрејски, мађарски, интерлингве, исландски, италијански, холандски, пољски, португалски, бразилски португалски, руски, српски, турски, поједностављени кинески | `share/man/<language>/man1` — `share/man/fr/man1` |

**`man` бира језик по локалу**, као и програм: под француским локалом,
`man subedit-cli` приказује француску страницу, а језик чије странице нису инсталиране добија
енглеске. `-L` тражи језик ма какав био локал:

```console
$ man -L fr subedit-cli-shift
```

## Излазни кодови

| Код | Значење |
| :--- | :------------ |
| `0` | све је успело |
| `1` | грешка у употреби — непозната опција, неважећа вредност, забрањена комбинација |
| `2` | ниједна датотека није могла да се обради |
| `3` | неке датотеке су обрађене, друге не |

Кодови `2` и `3` разликују се да би скрипта знала како да поступи без поновног читања излаза:
„ништа није успело“ и „једна недостаје“ не траже исту реакцију.

Грешка у употреби открива се **пре сваке обраде**: никада не оставља
серију напола обрађену.

## Грешке

| Шта је изазива | Шта се пише, на излаз грешака |
| :------------------ | :--------------------------------------- |
| непозната опција или подкоманда | погрешно име, и упућивање на `--help` |
| `--quiet` са `-v` | `--quiet and -v ask for opposite things; give one or the other` |
| `--config` са `--no-config` | `--config excludes --no-config` |
| `--config` са празним именом | `--config needs a file name` |
| датотека недостаје | `<path>: does not exist` |
| нечитљива датотека | `<path>: cannot be opened: permission denied` |
| кодирање које пише сопствену ознаку | `"<name>" writes a byte order mark of its own; name the byte order, as UTF-16LE and UTF-16BE do` |
| бајтови који се не декодирају | `<path>: cannot be decoded in the chosen encoding` |
| формат није препознат | `<path>: is in no format this tool knows` |
| ништа што личи на титл | `<path>: holds nothing recognisable as a subtitle` |
| `--document translation` без `-t` | `--document translation needs the translation file: use -t` |
| `-t` без `--document translation` | `-t names a translation to change: use --document translation` |
| `--align-method` без `-t` | `--align-method needs a translation file: use -t` |
| `-t` са више улаза, или директоријумом | `-t names one file but several inputs were given: use one invocation per pair` |
| превод идентичан главној датотеци | `<translation>: the file is already open as the main document` |
