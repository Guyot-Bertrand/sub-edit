# `pair`

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

```
subedit-cli pair (--output FILE | --output-dir DIR | --in-place)
                 -t FILE [--align-method position|number]
                 [--dry-run]
                 <main>
```

Пише **превод поново усклађен по положајима главне датотеке** и каже како су његови редови пронашли свој
титл. То је `Open Translation…` из прозора — [исто упаривање](../subedit-gui/files.md#отварање-превода),
иста реченица — иза чега следи писање резултата, које прозор обавља преко `Save Translation`.

**То је једина ствар коју упаривање ради а да је датотека обрађена сама не ради.** Остале подкоманде
које примају `-t` мењају превод који читају — [`case`](case.md), [`replace`](replace.md)… —; `pair` не мења
ништа у тексту: он **полаже** превод на главну датотеку и пише оно што је полагање дало. Главна датотека се
чита да би примила редове, а **никада се не пише**.

- **Пише се превод**, на **својој путањи и у свом формату**: формат, кодирање и
  завршеци редова датотеке превода. Његови титлови су **на положајима главне датотеке**: ред који
  је пао поред ознаке враћа себи границе титла који преводи.
- **`-t` је обавезан.** `pair` без превода нема шта да полаже: то је грешка у употреби, код `1`.
- **Једна главна датотека**, и без `--recursive`: пар су две датотеке, а стабло нема
  начина да каже који превод иде уз коју главну датотеку. За серију, по једно покретање за сваки пар.
- **`--output` именује датотеку написаног превода, `--output-dir` ставља тамо његов основни назив, `--in-place`
  га преписује**, као код сваке подкоманде која прима `-t` — види [Превод](invocation.md#превод).
- **`--document` не постоји**: циља се само један документ, превод.

## Аргументи и опције

| Опција | Обавезно | Вредности | Подразумевано |
| :----- | :----- | :------ | :----- |
| `<main>` | да | **једна** путања | — |
| `-t`, `--translation-file` | **да** | датотека превода | — |
| `--align-method` | не | `position` или `number` — види [Превод](invocation.md#превод) | `position` |
| `--output` / `--output-dir` / `--in-place` | **једна од три**, осим уз `--dry-run` | види [Покретање](invocation.md#одредиште) | — |
| `--dry-run` | не | опција без вредности: израчуна и јави, ништа не пише — види [Прво видети, па писати](invocation.md#прво-видети-па-писати) | искључено |

Превод је каснио 0,3 s: сваки ред је пронашао титл који његова средина
додирује, а написана датотека носи положаје главне датотеке.

## Шта поравнање каже

Реченица је **она коју каже прозор** када отвара превод, сваки њен део само када није
нула — табелу њених делова види у одељку [`inspect -t`](inspect.md#превод--t). **Пише се
од нивоа 1**, а не на нивоу 2 као код осталих подкоманди: овде поравнање није
детаљ обраде, већ је резултат.

**Шта поравнање ради са написаном датотеком**:

- **титл који нико није превео пише се као блок без текста**, који се чита без аномалије;
- **титл рођен из реда** — реда до кога ништа није стигло — пише се са **својим положајима**, ма који
  био метод: написана датотека зато може имати више титлова од главне;
- **све што је документ носио као превод брише се** пре полагања, што се не односи на командну линију:
  главна датотека се чита сама.

**Два метода** дају исту датотеку када ред пада на свој титл, а не дају
када ред недостаје или је превод померен — зато је метод избор и зато је
положај подразумеван. Осам случајева из `src/test/data/paires/` их набраја, са очекиваном датотеком за
сваки метод.

## Излаз

**Стандардни излаз** — ништа: резултат је написана датотека.

| Ниво | Шта се додаје на стандардној грешци |
| :----- | :------------------------------------- |
| 1 | `<translation>: translation: N lines attached; … -> <destination>` — **путања је она превода**, а то је написана датотека; уз `--dry-run`, `(dry run, nothing written)` уместо `-> <destination>` |
| 2 | `<translation>: SubRip, UTF-8, no BOM, LF line endings kept` — формат, кодирање, ознака и завршеци редова **превода**, враћени какви су били |
| 3 | `<translation>: N bytes read, M written`, затим **свака дијагностика читања** главне датотеке и превода — види [Покретање](invocation.md#читање-дијагностике) |

### У JSON-у

Уз [`--format json`](invocation.md#излаз-који-скрипта-може-да-чита), **један објекат**, чији је `file` превод, а
`destination` написана датотека. `counts.subtitles` броји **титлове написане датотеке**, укључујући оне које је
један ред оживео. Кључ `alignment` — `{"file", "method", "attached", "born", "untranslated", "out_of_order"}` —
носи исте бројеве као реченица, као кључ `translation` подкоманде [`inspect`](inspect.md#у-json-у).

## Излазни кодови

Они из програма: `0` ако је превод написан — или израчунат, уз `--dry-run` —, `2` ако једна од две датотеке није могла
бити прочитана или ако одредиште није могло бити написано, `1` при грешци у употреби. **Лоше поравнат превод није
неуспех**: пише се, а реченица каже шта није нашло своје место.

## Грешке

| Шта их изазива | Порука |
| :------------------- | :------ |
| нема `-t` | `pair needs the translation file to lay over the main one: use -t` |
| `--document` | `The following argument was not expected: --document` — за `pair` не постоји |
| више од једне главне датотеке | `The following argument was not expected: <path>` |
| превод је главна датотека | `<translation>: the file is already open as the main document`, код `2` |
| једна од датотека недостаје, нечитљива је или непознатог формата | исто као свуда, са путањом датотеке која је крива |
