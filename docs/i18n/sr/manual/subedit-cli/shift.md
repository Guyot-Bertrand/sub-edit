# `shift`

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

```
subedit-cli shift (--by <time> | --to-grid)
                  (--output FILE | --output-dir DIR | --in-place)
                  [--dry-run]
                  [--recursive]
                  <file>...
```

Помера **сваки** положај у датотеци за исти износ, у једном смеру или
у другом. Ниједан титл не остаје на екрану ни дуже ни краће:
управо то чини померање померањем.

<!-- example: subedit-cli shift --help -->
```console
$ subedit-cli shift --help
Move every position of a file by a fixed amount
Usage: subedit-cli shift [OPTIONS] files...

Positionals:
  files TEXT ... REQUIRED     Subtitle files to shift

Options:
  -h,--help                   Print this help message and exit
  -r,--recursive              Take directories as inputs, and every subtitle file in them
  --by TEXT                   Amount to move by: 2.999, -7.001, or 00:00:07.001
  --to-grid                   Move by the amount that puts the positions back on their frame grid
  --output TEXT               File to write, for a single input
  --output-dir TEXT           Directory to write into
  --in-place                  Write back over the inputs
  --dry-run                   Work out and say what would be written, and write nothing
```

## Аргументи и опције

| Опција | Обавезно | Вредности | Подразумевано |
| :----- | :----- | :------ | :----- |
| `<file>...` | да | једна или више путања | — |
| `--recursive`, `-r` | не | опција без вредности | искључено — види [Обрада стабла директоријума](lots.md) |
| `--by` | **једна од две** | трајање са предзнаком, види испод | — |
| `--to-grid` | **једна од две** | опција без вредности: износ се мери, види испод | — |
| `--output` / `--output-dir` / `--in-place` | **једна од три**, осим уз `--dry-run` | види [Покретање](invocation.md#одредиште) | — |
| `--dry-run` | не | опција без вредности: израчуна и јави, ништа не пише — види [Прво видети, па писати](invocation.md#прво-видети-па-писати) | искључено |

Формат прочитане датотеке се **чува**: промена формата је посао подкоманде
[`convert`](convert.md).

## `--to-grid`: износ измерен уместо задат

Датотека чији су положаји на мрежи кадрова **до на
константу** била је померена, а та константа може се измерити на самим положајима.
`--to-grid` је мери и примењује, а да је нико не мора знати.

Износ је **својствен свакој датотеци**: две датотеке померене са исте
мреже за две различите вредности враћају се свака за своју. Он се
исписује у приповедању, заједно са пронађеном брзином кадрова.

**Путања је најкраћа.** Преко пола кадра, најближа линија мреже
је следећа: исправка иде унапред уместо да се враћа назад за
скоро цео кадар.

<!-- example: k=0; while [ $k -lt 12 ]; do s=$((1000 + k*47000 + (k%3)*40 + 7)); e=$((s+2000)); k=$((k+1)); printf '%d\n%02d:%02d:%02d,%03d --> %02d:%02d:%02d,%03d\nRéplique %d.\n\n' $k $((s/3600000)) $((s/60000%60)) $((s/1000%60)) $((s%1000)) $((e/3600000)) $((e/60000%60)) $((e/1000%60)) $((e%1000)) $k; done > decale.srt; subedit-cli shift --to-grid --output recale.srt decale.srt -->
```console
$ k=0; while [ $k -lt 12 ]; do s=$((1000 + k*47000 + (k%3)*40 + 7)); e=$((s+2000)); k=$((k+1)); printf '%d\n%02d:%02d:%02d,%03d --> %02d:%02d:%02d,%03d\nRéplique %d.\n\n' $k $((s/3600000)) $((s/60000%60)) $((s/1000%60)) $((s%1000)) $((e/3600000)) $((e/60000%60)) $((e/1000%60)) $((e%1000)) $k; done > decale.srt; subedit-cli shift --to-grid --output recale.srt decale.srt
decale.srt: 12 subtitles shifted by -0.007 s onto their 25 fps grid -> recale.srt
```

**Датотека која није ни на једној познатој мрежи се одбија, уз објашњење зашто.** Нема
шта да се поново споји, а фаза измерена на шуму померила би датотеку
насумично. Види [`inspect`](inspect.md#шта-јавља-frame-rate-grid) да
се сазна шта датотека даје пре него што се операција покуша.

Опције `--by` и `--to-grid` обе кажу за колико се помера: њихово
заједничко навођење је грешка у употреби, као и навођење ниједне.

**`--to-grid` није [`snap`](snap.md).** Он помера целу датотеку
за исту вредност и **тачно** чува релативно време; `snap`
помера сваки положај независно и успут упија оне који су
били исправљени ручно. На чистој датотеци обоје дају исти
резултат; на делимичној, не дају.

## Писање трајања

Два облика, и само два:

| Облик | Примери |
| :---- | :------- |
| секунде | `30`, `2.999`, `-7.001`, `+1.5` |
| временска ознака | `00:00:07.001`, `01:39:37.040`, `-00:00:07.001` |

Оба кажу исто: `--by 7.001` и `--by 00:00:07.001` дају
исту датотеку.

**Децимални сепаратор је тачка**, јер командна линија говори енглески.
Зарез се одбија, а не тумачи: пола света пише `7,001`
за седам хиљада и један, а читати то као седам секунди била би претпоставка —
погрешна за ту половину.

**Резолуција је милисекунда.** Финије се одбија уместо да се тихо
заокружи: прећутно заокруживање дало би резултат који не одговара ничему од
траженог.

<!-- example: printf '1\n00:00:10,000 --> 00:00:12,000\nBonjour.\n\n' > a.srt; subedit-cli shift --by -7.001 --output b.srt a.srt; cat b.srt -->
```console
$ printf '1\n00:00:10,000 --> 00:00:12,000\nBonjour.\n\n' > a.srt; subedit-cli shift --by -7.001 --output b.srt a.srt; cat b.srt
a.srt: 1 subtitle shifted by -7.001 s -> b.srt
1
00:00:02,999 --> 00:00:04,999
Bonjour.
```

## Померање пре почетка се одбија

Враћање иза нуле даје код `2` и **ништа не пише**. Порука именује
титл који није могао да прихвати померање, чиме уједно каже
докле се може ићи.

Разлог није начело: положај пре почетка пише се као
`-00:00:01,000`, облик који не дефинише ниједан од девет формата и који ниједан читач
не прихвата. Језгро такве положаје допушта — њихово одбијање
учинило би операцију уређивања посебним случајем — али датотека је нешто друго него
модел у меморији.

<!-- example: printf '1\n00:00:01,000 --> 00:00:03,000\nBonjour.\n\n' > a.srt; subedit-cli shift --by -7.001 --output b.srt a.srt; echo "code=$?" -->
```console
$ printf '1\n00:00:01,000 --> 00:00:03,000\nBonjour.\n\n' > a.srt; subedit-cli shift --by -7.001 --output b.srt a.srt; echo "code=$?"
a.srt: subtitle 1 would start before the origin, which no subtitle file can hold
code=2
```

## Излаз

**Стандардни излаз** — ништа: резултат је написана датотека. Ни уз `--dry-run` ништа: нема датотеке, а ред приповедања то каже — види [Прво видети, па писати](invocation.md#прво-видети-па-писати).

| Ниво | Шта се додаје на стандардној грешци |
| :----- | :------------------------------------- |
| 1 | `<path>: N subtitles shifted by 2.999 s -> <destination>` |
| 2 | `<path>: SubRip, UTF-8, no BOM, LF line endings kept` — формат, кодирање, ознака и завршеци редова прочитане датотеке, враћени какви су били |
| 3 | `<path>: N bytes read, M written`, затим **свака дијагностика читања** — види [Покретање](invocation.md#читање-дијагностике) |

### У JSON-у

Уз [`--format json`](invocation.md#излаз-који-скрипта-може-да-чита), објекат сваке датотеке садржи `counts.subtitles` (сваки титл датотеке) и `counts.shifted_by_ms` (померање, у целим милисекундама, **са предзнаком**). Пуна табела је она из одељка [Покретање](invocation.md#шта-свака-подкоманда-уписује-у-counts).

## Излазни кодови

Они из програма: `0` ако је свака датотека написана, `2` ако
ниједна, `3` ако само неке, `1` при грешци у употреби.

## Грешке

| Шта је изазива | Порука |
| :------------------ | :------ |
| децимални зарез | `"…" is not a time: use a decimal point and not a comma, in every language` |
| финије од милисекунде | `"…" is not a time: positions are held to the millisecond, no finer` |
| текст који није трајање | `"…" is not a time: expected seconds like 2.999, or a timestamp like 00:00:07.001` |
| померање пре почетка | `<path>: subtitle N would start before the origin, which no subtitle file can hold` |

**Ништа се не пише без једне од три опције одредишта**, а њихове
грешке заједничке су подкомандама које пишу:
види [Покретање](invocation.md#одредиште).
