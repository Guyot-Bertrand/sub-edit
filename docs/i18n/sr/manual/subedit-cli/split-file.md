# `split-file`

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

```
subedit-cli split-file --at N --head FILE --tail FILE
                       [--dry-run] [--sort] [--disjoint]
                       <file>
```

Дели датотеку **на два дела**: почетак и крај. То је `Split Project…` из прозора — [исти мотор](../subedit-gui/operations.md#split-project),
исти бројеви, иста одбијања — и **тачна супротност подкоманде [`append`](append.md)**: прикачињање краја на
почетак враћа почетну датотеку.

- **`--at N` је број првог титла краја**, нумерисан како га нумерише табела
  прозора: од 1. `--at 3` ставља титлове 1 и 2 у почетак, а трећи и остале у
  крај. Вредност иде **од другог до последњег**: за рез је потребан титл са сваке стране.
- **Крај се враћа на почетак времена**: помера се за минус крај последњег титла који је остао у почетку,
  а његови положаји чувају свој редослед и размак. Због тога је `split-file` супротност подкоманде `append`.
- **Оба дела задржавају формат, кодирање, ознаку редоследа бајтова и завршетке редова прочитане датотеке** и
  при писању се изнова нумеришу од 1, као свака датотека која се уписује назад.
- **Два излаза, па сопствено одредиште**: `--head` и `--tail`, **обе обавезне**. Опције `--output`,
  `--output-dir`, `--in-place` и `--recursive` за `split-file` не постоје и одбијају се као свака непозната
  опција, код `1`: нема ни директоријума у који би се сместиле две именоване датотеке, ни улаза који би се преписао.

<!-- example: subedit-cli split-file --help -->
```console
$ subedit-cli split-file --help
Cut a subtitle file in two, a head and a tail
Usage: subedit-cli split-file [OPTIONS] file

Positionals:
  file TEXT REQUIRED          Subtitle file to cut

Options:
  -h,--help                   Print this help message and exit
  --at N                      Number of the first subtitle of the tail, as the table numbers them
  --head FILE                 File to write the subtitles before the cut to
  --tail FILE                 File to write the subtitles from the cut on to
  --dry-run                   Work out and say what would be written, and write nothing
  --sort                      Put the subtitles in order of their start before cutting; --at counts in that order
  --disjoint                  Cut overlapping subtitles so that no range overlaps another, before cutting
```

## Аргументи и опције

| Опција | Обавезно | Вредности | Подразумевано |
| :----- | :----- | :------ | :----- |
| `<file>` | да | **једна** путања | — |
| `--at` | да | цео број, од 2 до броја титлова датотеке | — |
| `--head`, `--tail` | **да, обе**, осим уз `--dry-run` | путање датотека; њихов директоријум се ствара ако недостаје | — |
| `--dry-run` | не | опција без вредности: израчуна и јави, ништа не пише — види [Прво видети, па писати](invocation.md#прво-видети-па-писати) | искључено |
| `--sort` | не | опција без вредности: поставља титлове по редоследу почетка **пре дељења**; `--at` броји по том редоследу | искључено |
| `--disjoint` | не | опција без вредности: сече титлове који се преклапају **пре дељења**; `--at` броји у ономе што остане, види [Раздвајање интервала](#раздвајање-интервала) | искључено |

**Уз `--dry-run` није потребно никакво одредиште**: ниједно не сме бити задато, али не само једно од два —
`--head` и `--tail` иду заједно. Оне које су задате оцењују се као без `--dry-run`.

**Та два одредишта не могу бити ни улаз ни иста датотека**: писање преко онога што се
чита, или писање краја преко почетка, одбија се пре било каквог читања, код `1`.

Други титл, који остаје у почетку, завршава се на 4 s: крај се помера уназад за 4 s, а трећи титл,
који је почињао на 6 s, почиње на 2 s.

## Сечење по временском редоследу

`--at` нумерише титлове **како их даје датотека**. У датотеци чији је редослед нарушен, почетак зато није половина која је најранија
у времену. `--sort` поставља титлове по редоследу њихових почетака **пре просуђивања реза** — стабилно, као што то ради [`sort`](sort.md) —, а
`--at` тада броји по том редоследу.

Никада по подразумеваној вредности. Уз опцију, датотека на првом нивоу приповедања каже колико је титлова померено (`<path>: N subtitles moved`
или `<path>: already in order`), а запис `--format json` садржи број `moved`, **одсутан без опције**.

## Раздвајање интервала

Никада по подразумеваној вредности. Опција ради оно што ради [`disjoint`](disjoint.md), **са његовим подразумеваним поставкама**, пре просуђивања реза, после ређања: `--at` броји у ономе што тиме остане. Потребна је уређена датотека: у супротном се одбија, а `--sort` — који долази први — унапред је доводи у ред. Датотека то каже на првом нивоу приповедања (`<path>: N subtitles split, M merged`), а запис `--format json` садржи бројеве `split` и `merged`, **одсутне без опције**.

## Када се рез одбија

**Два дела који се преклапају на резу не деле се.** Ако би титл краја почињао пре
краја последњег титла остављеног иза, померање би га одвело пре почетка филма — негативан положај,
који не пише ниједан формат. `split-file` одбија **именујући титл**, речима прозора:

```text
o.srt: Cannot split at subtitle 3: subtitle 3 would fall before the start of the video. Cut somewhere else.
```

Код је `2` и **ништа се не пише**. Треба сећи на другом месту. Слетање тачно на почетак је допуштено: нула је
положај.

**`--at` ван датотеке одбија се на исти начин**, чим се датотека прочита: `--at 1` — први титл не може
почети крај, ништа не би остало — и `--at` иза последњег титла, што би оставило празан
крај. Датотека са једним титлом не може се делити.

## Излаз

**Стандардни излаз** — ништа: резултат су две написане датотеке.

| Ниво | Шта се додаје на стандардној грешци |
| :----- | :------------------------------------- |
| 1 | `<path>: split at subtitle N: H subtitles in the head, T subtitles in the tail -> <head>, <tail>`; уз `--dry-run`, `(dry run, nothing written)` уместо `-> …` |
| 2 | `<path>: SubRip, UTF-8, no BOM, LF line endings kept` — формат, кодирање, ознака и завршеци редова прочитане датотеке, враћени какви су били |
| 3 | `<path>: N bytes read, H and T written`, затим **свака дијагностика читања** — види [Покретање](invocation.md#читање-дијагностике) |

### У JSON-у

Уз [`--format json`](invocation.md#излаз-који-скрипта-може-да-чита), **један објекат**, чији је `file` подељена датотека.
**`destination` је почетак** — датотека у коју улаз постаје — а **`tail` крај**, путања, или `null` уз
`--dry-run` као `destination`. Бројеви `counts`: `subtitles` (они прочитане датотеке), `head` и `tail` (они сваког
дела).

## Излазни кодови

| Код | Када |
| :--- | :---- |
| `0` | обе датотеке су написане — или израчунате, уз `--dry-run` |
| `1` | грешка у употреби: нема `--head` и `--tail`, опција коју `split-file` нема, одредиште које је улаз или друго одредиште, `--at` који није позитиван цео број |
| `2` | датотека није могла бити прочитана, **рез је одбијен** (ван датотеке, или преклапање), или одредиште није могло бити написано. Кода `3` нема: обрађује се једна датотека |

**Почетак се пише први**: диск који одбије крај оставља почетак за собом, а код је `2`.

## Грешке

| Шта их изазива | Порука |
| :------------------- | :------ |
| ни `--head` ни `--tail` | `no destination given: split-file writes two files, use --head and --tail` |
| само једна од две, уз `--dry-run` | `--head and --tail go together: give both, or neither with --dry-run` |
| оба одредишта су иста датотека | `<path>: named as both the head and the tail` |
| одредиште је улаз | `<path>: would be written over the input <input>` |
| `--at` ван датотеке | `<file>: --at 9: the file holds 3 subtitles, and the tail can start from 2 to 3` |
| датотека са једним титлом | `<file>: a file of 1 subtitle cannot be split: a cut needs a subtitle on each side` |
| преклапање | `<file>: Cannot split at subtitle N: subtitle M would fall before the start of the video. Cut somewhere else.` |
| датотека недостаје, нечитљива је или непознатог формата | `<path>: does not exist`… — као свуда |
