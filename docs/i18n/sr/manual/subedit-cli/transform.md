# `transform`

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

```
subedit-cli transform --first <index>=<time> --last <index>=<time>
                      (--output FILE | --output-dir DIR | --in-place)
                      [--dry-run]
                      [--recursive]
                      <file>...
```

Исправља **сваки** положај у датотеци на основу две тачке чија је тачна
вредност позната. То је операција која је потребна титловању које одлута
— тачно на почетку, погрешно на крају — где [`shift`](shift.md), који све помера за
исти износ, не може ништа.

Формат прочитане датотеке се **чува**: промена формата је посао подкоманде
[`convert`](convert.md).

<!-- example: subedit-cli transform --help -->
```console
$ subedit-cli transform --help
Correct every position from two points known to be right
Usage: subedit-cli transform [OPTIONS] files...

Positionals:
  files TEXT ... REQUIRED     Subtitle files to transform

Options:
  -h,--help                   Print this help message and exit
  -r,--recursive              Take directories as inputs, and every subtitle file in them
  --first TEXT REQUIRED       Earlier reference, as <index>=<time>: 1=00:00:01.000
  --last TEXT REQUIRED        Later reference, as <index>=<time>: 3=00:00:10.000
  --output TEXT               File to write, for a single input
  --output-dir TEXT           Directory to write into
  --in-place                  Write back over the inputs
  --dry-run                   Work out and say what would be written, and write nothing
```

## Аргументи и опције

| Опција | Обавезно | Вредности | Подразумевано |
| :----- | :----- | :------ | :----- |
| `<file>...` | да | једна или више путања | — |
| `--recursive`, `-r` | не | опција без вредности | искључено — види [Обрада стабла директоријума](lots.md) |
| `--first` | **да** | референца, `<index>=<time>` | — |
| `--last` | **да** | референца, `<index>=<time>` | — |
| `--output` / `--output-dir` / `--in-place` | **једна од три**, осим уз `--dry-run` | види [Покретање](invocation.md#одредиште) | — |
| `--dry-run` | не | опција без вредности: израчуна и јави, ништа не пише — види [Прво видети, па писати](invocation.md#прво-видети-па-писати) | искључено |

Кратког облика нема: те две опције пишу се само у
пуном облику.

## Писање референце

Референца именује титл и каже где његов **почетак** сада мора пасти:

```
<index>=<time>
```

**Индекс се броји од 1**, како се приказује и како га нумерише
SubRip датотека. `0` се одбија, као и индекс иза последњег
титла.

**Време се пише као код подкоманде [`shift`](shift.md)** — секунде или
временска ознака, децимални сепаратор је тачка, резолуција је милисекунда:

| Облик | Примери |
| :---- | :------- |
| секунде | `10`, `2.999` |
| временска ознака | `00:00:10.000`, `01:39:37.040` |

`--first 3=10` и `--first 3=00:00:10.000` кажу исто.

Опције `--first` и `--last` именују две тачке, а не интервал. Њихова имена кажу
очекивану употребу — једна референца на почетку датотеке, друга на крају — а не
ограничење: њихова замена даје исти резултат, а **све изван
те две референце следи као и оно између њих**.

## Шта други положаји постају

Две референце одређују фактор размере, и сваки положај га прати:

```
t′ = y₁ + (t − x₁) × r      with r = (y₂ − y₁) / (x₂ − x₁)
```

`x₁`, `x₂` су тренутни почеци два именована титла, `y₁`, `y₂` тражена
времена. Фактор се држи као тачан рационалан број, а **заокруживање
се обавља само једном**, на милисекунду; управо то чини да две
референце падну **тачно** на тражена времена, а не до на хиљадити део
(види [ADR 0013](../../../../adr/0013-mise-a-l-echelle-exacte-des-positions.md)).

Сваки титл остаје на екрану **сразмерно** времену колико је тамо остајао:
крај прати исту размеру као почетак. Трансформација није
померање и нема његово својство.

<!-- example: printf '1\n00:00:01,000 --> 00:00:03,000\nUn.\n\n2\n00:00:05,001 --> 00:00:07,000\nDeux.\n\n3\n00:00:09,000 --> 00:00:11,000\nTrois.\n\n' > a.srt; subedit-cli transform --first 1=00:00:01.000 --last 3=00:00:10.000 --output b.srt a.srt; cat b.srt -->
```console
$ printf '1\n00:00:01,000 --> 00:00:03,000\nUn.\n\n2\n00:00:05,001 --> 00:00:07,000\nDeux.\n\n3\n00:00:09,000 --> 00:00:11,000\nTrois.\n\n' > a.srt; subedit-cli transform --first 1=00:00:01.000 --last 3=00:00:10.000 --output b.srt a.srt; cat b.srt
a.srt: 3 subtitles transformed onto 1=00:00:01.000 and 3=00:00:10.000 -> b.srt
1
00:00:01,000 --> 00:00:03,250
Un.

2
00:00:05,501 --> 00:00:07,750
Deux.

3
00:00:10,000 --> 00:00:12,250
Trois.
```

Прва референца се не помера, трећа иде са 9 s на 10 s: фактор је
`9/8`, а други титл — који нико није именовао — иде са
`5,001` на `5,501`, то јест `1000 + 4001 × 9/8` заокружено једном.

## Две референце које то нису

| Ситуација | Када се види | Код |
| :-------- | :------------- | :--- |
| `--first` и `--last` именују исти индекс | пре било каквог читања | `1` |
| индекс је иза последњег титла | при отварању датотеке | `2` или `3` |
| два именована титла почињу у истом тренутку | при отварању датотеке | `2` или `3` |

Сва три се одбијају из истог разлога: `x₂ − x₁` је нула, а две
тачке које се поклапају не одређују праву. Враћање дељења нулом прерушеног у
резултат било би горе од одбијања.

Први случај је **грешка у употреби** — криве су две опције ма какве
биле датотеке, па треба једна порука, а не по једна за сваку датотеку. Остала
два зависе од отворене датотеке, па се рачунају као неуспех
обраде.

<!-- example: printf '1\n00:00:01,000 --> 00:00:03,000\nUn.\n\n' > a.srt; subedit-cli transform --first 2=1.000 --last 2=4.000 --output b.srt a.srt; echo "code=$?" -->
```console
$ printf '1\n00:00:01,000 --> 00:00:03,000\nUn.\n\n' > a.srt; subedit-cli transform --first 2=1.000 --last 2=4.000 --output b.srt a.srt; echo "code=$?"
--first and --last both name subtitle 2, and two references on one subtitle define no transform
code=1
```

Индекс ван граница се одбија **именујући границу**, што уједно каже
шта је могло бити написано:

<!-- example: printf '1\n00:00:01,000 --> 00:00:03,000\nUn.\n\n2\n00:00:05,000 --> 00:00:07,000\nDeux.\n\n' > a.srt; subedit-cli transform --first 1=1.000 --last 9=10.000 --output b.srt a.srt; echo "code=$?" -->
```console
$ printf '1\n00:00:01,000 --> 00:00:03,000\nUn.\n\n2\n00:00:05,000 --> 00:00:07,000\nDeux.\n\n' > a.srt; subedit-cli transform --first 1=1.000 --last 9=10.000 --output b.srt a.srt; echo "code=$?"
a.srt: subtitle 9 is past the end: the file holds 2 subtitles
code=2
```

## Положај пре почетка се одбија

Као код подкоманде [`shift`](shift.md), и из истог разлога: негативан положај
пише се као `-00:00:01,000`, облик који не дефинише ниједан од девет формата и који ниједан
читач не прихвата. Случај настаје овде када титл лежи **пре
прве референце**, а размера га гурне иза нуле. Ништа се не
пише, код је `2`, а порука именује титл који је крив.

## Излаз

**Стандардни излаз** — ништа: резултат је написана датотека. Ни уз `--dry-run` ништа: нема датотеке, а ред приповедања то каже — види [Прво видети, па писати](invocation.md#прво-видети-па-писати).

| Ниво | Шта се додаје на стандардној грешци |
| :----- | :------------------------------------- |
| 1 | `<path>: N subtitles transformed onto 1=00:00:01.000 and 3=00:00:10.000 -> <destination>` |
| 2 | `<path>: SubRip, UTF-8, no BOM, LF line endings kept` — формат, кодирање, ознака и завршеци редова прочитане датотеке, враћени какви су били |
| 3 | `<path>: N bytes read, M written`, затим **свака дијагностика читања** — види [Покретање](invocation.md#читање-дијагностике) |

Референце се пишу назад са децималном тачком, ма како биле укуцане.

### У JSON-у

Уз [`--format json`](invocation.md#излаз-који-скрипта-може-да-чита), објекат сваке датотеке садржи `counts.subtitles` (сваки титл датотеке). Пуна табела је она из одељка [Покретање](invocation.md#шта-свака-подкоманда-уписује-у-counts).

## Излазни кодови

Они из програма: `0` ако је свака датотека написана, `2` ако
ниједна, `3` ако само неке, `1` при грешци у употреби.

## Грешке

| Шта је изазива | Порука |
| :------------------ | :------ |
| референца без `=` | `"…" is not a reference: write it <index>=<time>, as in 3=00:00:10.000` |
| референци недостаје једна половина | `"…" is missing one of its two halves: write it <index>=<time>, as in 3=00:00:10.000` |
| индекс `0` | `"0" is not a subtitle number: subtitles are counted from 1, as the file shows them` |
| индекс који није цео број | `"…" is not a subtitle number: expected a whole number, counted from 1 as the file shows them` |
| неисправно време | оне из подкоманде [`shift`](shift.md) |
| `--first` и `--last` на истом индексу | `--first and --last both name subtitle N, and two references on one subtitle define no transform` |
| индекс ван граница | `<path>: subtitle N is past the end: the file holds M subtitles` |
| два титла која почињу заједно | `<path>: subtitles N and M start at the same moment, so they define no transform` |
| положај пре почетка | `<path>: subtitle N would land before the origin, which no subtitle file can hold` |

**Ништа се не пише без једне од три опције одредишта**, а њихове
грешке заједничке су подкомандама које пишу:
види [Покретање](invocation.md#одредиште).
