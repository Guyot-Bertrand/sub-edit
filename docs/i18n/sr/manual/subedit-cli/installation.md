# Инсталација

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

**Ова страница важи за оба програма** — `subedit-cli` и `subedit-gui`.
Граде се и инсталирају заједно.

Два пута: **изворни пакет**, `.deb` или `.rpm`, или **градња из
изворног кода**, која затим инсталира где год се пожели.

## Пакети

Оба производи CPack из **истих правила инсталације**:
стављају исте датотеке на иста места, а разликују се само по
именима пакета од којих зависе — исте библиотеке се другачије
зову на Debian-у и на Fedori.

```bash
sudo apt install ./subedit_<version>_amd64.deb      # Debian, Ubuntu
sudo dnf install ./subedit-<version>.x86_64.rpm     # Fedora, and relatives
```

| Шта пакет инсталира | Где |
| :---------------------- | :-- |
| `subedit-cli`, `subedit-gui` | `/usr/bin` |
| ставку менија, икону, метаподатке за центар за софтвер | `/usr/share/applications`, `/usr/share/icons`, `/usr/share/metainfo` |
| овај приручник, у Markdown-у | `/usr/share/subedit/manual` |
| његов превод на сваки инсталиран језик — каталонски, чешки, немачки, шпански, фински, француски, галицијски, хебрејски, мађарски, интерлингве, исландски, италијански, холандски, пољски, португалски, бразилски португалски, руски, српски, турски, поједностављени кинески | `/usr/share/subedit/manual/<language>` — `ca`, `cs`, `de`, `es`, `fi`, `fr`, `gl`, `he`, `hu`, `ie`, `is`, `it_IT`, `nl`, `pl`, `pt`, `pt_BR`, `ru`, `sr`, `tr`, `zh_CN` |
| Gaupol-ове обрасце исправки | `/usr/share/subedit/patterns` |
| man странице програма `subedit-cli`, по једну за сваку подкоманду, и програма `subedit-gui` — види [Man странице](invocation.md#man-странице) | `/usr/share/man/man1` |
| странице програма `subedit-cli` на сваком инсталираном језику — каталонски, чешки, немачки, шпански, фински, француски, галицијски, хебрејски, мађарски, интерлингве, исландски, италијански, холандски, пољски, португалски, бразилски португалски, руски, српски, турски, поједностављени кинески | `/usr/share/man/<language>/man1` — `ca`, `cs`, `de`, `es`, `fi`, `fr`, `gl`, `he`, `hu`, `ie`, `is`, `it_IT`, `nl`, `pl`, `pt`, `pt_BR`, `ru`, `sr`, `tr`, `zh_CN` |

Оба пакета **препоручују, а не захтевају** `ffmpeg`: без њега прозор
само престаје да нуди брзину кадрова коју филм декларише — види
[шта `ffmpeg` мења](../subedit-gui/video.md#ffmpeg-није-потребан).

### Шта пакети траже од дистрибуције

**Инсталира се са `apt` или `dnf`, никада са `dpkg -i` или `rpm -i`.** Те две
команде само спусте пакет не решавајући његове зависности: једва
наброје оне које недостају и стану. Ово одговара `rpm -i` на
Fedori која има шта јој треба на дохват `dnf`:

```console
$ rpm -i subedit-0.13.0-1.fc43.x86_64.rpm
error: Failed dependencies:
        libicui18n.so.77()(64bit) is needed by subedit-0.13.0-1.fc43.x86_64
        libicuuc.so.77()(64bit) is needed by subedit-0.13.0-1.fc43.x86_64
```

`sudo dnf install ./subedit-<version>-1.fc43.x86_64.rpm` довлачи те
библиотеке, тамо где постоје.

**Треба узети `.rpm` Fedore коју корисник има**: име датотеке носи
верзију, `fc42`, `fc43`, `fc44`. Сваки је грађен на тој Fedori, према
њеном ICU — `cat /etc/fedora-release` каже који узети. `.rpm` с друге
Fedore тражи ICU који ваша нема.

| Зависност | `.deb` | `.rpm` | Ограничење |
| :--------- | :----- | :----- | :--------- |
| Qt 6: `Widgets`, `Gui`, `Core` | `libqt6widgets6`, `libqt6gui6`, `libqt6core6` | `qt6-qtbase-gui` | **≥ 6.4**, за прозор |
| libmpv | `libmpv2` или `libmpv1` | `mpv-libs` | извршна датотека се повезује са `libmpv.so.2` |
| Enchant 2 | `libenchant-2-2` | `enchant2` | провера писања, и задаци `join-words` и `split-words` подкоманде [`correct`](correct.md) |
| **ICU** | **`libicu74`** | `libicu`, то јест `libicuuc.so.N` и `libicui18n.so.N` **Fedore која га је градила** | **верзија коју има Fedora из `.rpm`**, тачно — види испод |
| glibc и libstdc++ | — | — | **довољно нове**: оне из Ubuntu-а 24.04 за `.deb`, оне Fedore из `.rpm` за њега |

**ICU је ограничење које је важно и не може се ублажити
променом једног реда пакета.** Симболи библиотеке ICU носе број њене
главне верзије (`u_strToUTF8_74`): извршна датотека грађена према ICU 74 не може
да се повеже са ICU 76 или 77. Шире написана зависност дозволила би да се пакет
инсталира, па да падне при покретању — тачно навођење је оно што
остаје поштено. **Зато се `.rpm` не гради једном, већ на
свакој објављеној Fedori**, према њеном ICU; `.deb` се гради на Ubuntu-у 24.04.

| Дистрибуција | Шта даје |
| :----------- | :---------------- |
| Ubuntu 24.04 | `.deb` се инсталира: ICU је тамо верзије 74 |
| Fedora 42, 43, 44 | `.rpm` њене верзије (`…fc42…`, `…fc43…`, `…fc44…`) се инсталира **преко `dnf`**, грађен према ICU те Fedore |
| Fedora rawhide (следећа), остале дистрибуције са `.rpm` | **не**: за њих се не гради ниједан `.rpm` — гради се из изворног кода |
| свака Debian или Ubuntu дистрибуција чији ICU није верзије 74 | **не**: `.deb` захтева `libicu74` — гради се из изворног кода |

**Градња из изворног кода је резервна могућност и нема ово
ограничење**: повезује се са ICU-ом машине, ма која му била верзија.
Исто је потребно и на дистрибуцији чији је glibc старији
од онога у пакетима.

### Шта је тестирано код сваког, а шта није

**Два се не проверавају подједнако далеко, и боље је то рећи него дозволити да
се верује у једнакост која не постоји.** Развој тече на Ubuntu-у; `.rpm`
грађен тамо не може се тамо инсталирати. Инсталира се другде: на
Fedori у контејнеру, једном недељно.

| | `.deb` | `.rpm` |
| :--- | :----- | :----- |
| списак датотека | проверава се | проверава се, и **пореди са списком за `.deb`** |
| декларисане зависности | проверава се да су присутне | проверава се да су присутне |
| да имена зависности постоје у дистрибуцији | да, оне су Ubuntu-ове | **да**, решава их `dnf` |
| да се пакет инсталира | не — за то су потребна права администратора | **да**, на Fedori у контејнеру |
| да се инсталиране извршне датотеке покрећу | да, из привременог префикса | **да**, из инсталираног пакета |

**Провера на Fedori тестира `.rpm` грађен на Ubuntu-у, а не оне који се
објављују.** Та слика нема сопствени ICU 74: пакет се тамо инсталира јер
Fedora држи компатибилни `libicu74`, а провера би била зелена све док
тај пакет постоји. Објављене `.rpm` датотеке граде се на својој Fedori и више не
зависе од те компатибилности. Види
[шта пакети траже](#шта-пакети-траже-од-дистрибуције).

**Поређење два списка је провера која је најважнија.** Два
пакета излазе из исте инсталације: разлика међу њима била би
мана правила инсталације, а не формата.

**Оно што `.deb` и даље не доказује јесте да се инсталира**, а разлог
се није променио: `dpkg -i` тражи права администратора, која капија
квалитета нема и не сме да тражи. `.rpm` се, пак, инсталира у
контејнеру који никоме не припада. Види
[ADR 0023](../../../../adr/0023-deb-et-rpm-pour-la-premiere-livraison.md).

**Flatpak и AppImage се не нуде**, и то је избор — а не превид.
Објашњен је у истом ADR-у и **коначан** је: дистрибуција која
није ни из породице Debian-а ни из породице Fedore гради из
изворног кода, што следећи одељак описује у целини.

## Градња из изворног кода

### Предуслови

| Шта је потребно | Зашто | Debian, Ubuntu |
| :------------ | :------- | :------------- |
| CMake ≥ 3.28 | градња | `cmake` |
| C++23 преводилац — довољан је GCC 13 | — | `g++` |
| `make`, `pkg-config` | градња | `make`, `pkg-config` |
| CLI11 | читање командне линије | `libcli11-dev` |
| Qt 6 ≥ 6.4, модул `Widgets` | прозор | `qt6-base-dev` |
| `libmpv` | уграђени плејер | `libmpv-dev` |
| ICU | читање кодирања | `libicu-dev` |
| Enchant 2 | библиотека провере писања | `libenchant-2-dev` |

**Последња четири су потребна чак и за градњу само
`subedit-cli`**: CMake подешавање их тражи за цео пројекат и
стаје ако недостају. ICU и Enchant су потребни двоструко — извршна датотека их учитава, један
за претварање кодирања, други за проверу писања — и
то су једине библиотеке трећих страна које учитава за време рада.

**Мрежна веза при првом `cmake`**: тест библиотека Catch2
преузима се са GitHub-а при подешавању. Не преузима се поново
после. За градњу самог алата, без мреже, види испод.

#### Шта није потребно

| Шта је необавезно | Шта се губи без тога |
| :-------------------- | :--------------------- |
| `ffmpeg`, због свог `ffprobe` | прозор више не нуди брзину кадрова коју филм декларише — [појединости](../subedit-gui/video.md#ffmpeg-није-потребан) |
| сервер приказа | ништа за `subedit-cli`; `subedit-gui` га тражи да би се приказао |

### Градња

```bash
git clone git@github.com:Guyot-Bertrand/sub-edit.git subedit
cd subedit
make build
```

Извршне датотеке настају у `build/dev/bin/` — `subedit-cli` и
`subedit-gui`.

За оптимизовану верзију:

```bash
make release
```

Обе извршне датотеке су тада у `build/release/bin/` — `subedit-cli` и
`subedit-gui`. Циљ не гради ништа друго: ни мерење брзине, ни
комплетан тест од краја до краја, који имају своје циљеве.

**Овај циљ треба претпоставити двема еквивалентним `cmake` командама**, које
немају начина да знају колико процеса оптимизација у време повезивања сме да
покрене: при сваком повезивању покреће их онолико колико има језгара.
`make release` јој прослеђује `JOBS`, као и остатку градње.

### Инсталирање

```bash
make release
cmake --install build/release --prefix ~/.local
```

Шта се инсталира, на путањама које `GNUInstallDirs` одређује за изабрани
префикс:

| Датотека | Где |
| :------ | :-- |
| `subedit-cli`, `subedit-gui` | `<prefix>/bin` |
| ставка менија радне површине | `<prefix>/share/applications` |
| икона | `<prefix>/share/icons/hicolor/scalable/apps` |
| метаподаци за центар за софтвер | `<prefix>/share/metainfo` |
| овај приручник, у Markdown-у | `<prefix>/share/subedit/manual` |
| његов превод на сваки инсталиран језик — каталонски, чешки, немачки, шпански, фински, француски, галицијски, хебрејски, мађарски, интерлингве, исландски, италијански, холандски, пољски, португалски, бразилски португалски, руски, српски, турски, поједностављени кинески | `<prefix>/share/subedit/manual/<language>` — `ca`, `cs`, `de`, `es`, `fi`, `fr`, `gl`, `he`, `hu`, `ie`, `is`, `it_IT`, `nl`, `pl`, `pt`, `pt_BR`, `ru`, `sr`, `tr`, `zh_CN` |
| Gaupol-ови обрасци исправки | `<prefix>/share/subedit/patterns` |
| man странице оба програма, по једна за сваку подкоманду програма `subedit-cli` | `<prefix>/share/man/man1` |
| странице програма `subedit-cli` на сваком инсталираном језику — каталонски, чешки, немачки, шпански, фински, француски, галицијски, хебрејски, мађарски, интерлингве, исландски, италијански, холандски, пољски, португалски, бразилски португалски, руски, српски, турски, поједностављени кинески | `<prefix>/share/man/<language>/man1` — `ca`, `cs`, `de`, `es`, `fi`, `fr`, `gl`, `he`, `hu`, `ie`, `is`, `it_IT`, `nl`, `pl`, `pt`, `pt_BR`, `ru`, `sr`, `tr`, `zh_CN` |

**То су исте датотеке које инсталирају пакети**: пакети из њих настају,
уместо да се описују други пут.

Са `--prefix ~/.local`, обе извршне датотеке слећу у `~/.local/bin`,
који је у `PATH`-у већине дистрибуција. Системски префикс —
на пример `/usr/local` — тражи одговарајућа права.

**Ставка менија стављена под `~/.local` не појави се увек одмах**:
радне површине поново читају свој кеш својим темпом. `subedit-gui` се у међувремену
покреће из терминала, као свака друга команда.

`DESTDIR` се поштује, што пакер очекује: инсталација у привремено подручје
не дира ништа изван тог директоријума.

```bash
DESTDIR=/tmp/scene cmake --install build/release --prefix /usr
```

### Градња самог алата

Тестови се граде подразумевано, и они траже мрежу —
`make release` их не гради, али подешава пројекат, а управо
подешавање преузима Catch2. Довољно је једном их искључити: та
поставка остаје у CMake кешу, а наредне градње је задржавају.

```bash
cmake --preset release -DSUBEDIT_BUILD_TESTS=OFF
make release
```

То никога не ослобађа ничега: капија квалитета их
захтева.

### Ако градња падне при повезивању

Лавина порука „undefined reference to `std::cout`“ на исправном коду
обично значи да алтернатива `c++` у систему показује на `gcc` уместо на
`g++`: C++ се преводи, али стандардна библиотека није повезана.

```bash
ls -l /etc/alternatives/c++                                       # check
sudo update-alternatives --install /usr/bin/c++ c++ /usr/bin/g++ 100   # fix
CXX=g++ make build                                                # work around
```

CMake подешавање открива тај случај и стаје са овом поруком уместо да
пусти да повезивање падне.

### Ако инсталација пакета јавља проблем са `libicu`

```console
error: Failed dependencies:
        libicuuc.so.74()(64bit) is needed by subedit-<version>.x86_64
```

Три узрока, која се разликују по откуцаној команди и по имену датотеке:

- **`rpm -i`**: не решава ништа. Покушава се поново са
  `sudo dnf install ./subedit-<version>.fcNN.x86_64.rpm`;
- **`.rpm` без `fcNN` у имену**, или са друге Fedore, а не ваше:
  тражи ICU машине која га је градила. Узима се онај чији је `fcNN`
  излаз команде `cat /etc/fedora-release`;
- **нема `.rpm` за вашу верзију**: Fedora rawhide или друга дистрибуција.
  Ниједан пакет овог репозиторијума се тамо неће инсталирати;
  [гради се из изворног кода](#градња-из-изворног-кода).
