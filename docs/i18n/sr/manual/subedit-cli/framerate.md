# `framerate`

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

> **Ово није [`snap`](snap.md).** Ова команда **мења размеру
> датотеке**: служи када је усклађивање времена погрешно и до краја филма одлута за неколико
> секунди. `snap` враћа временске ознаке на најближу
> мрежу не усклађујући ништа поново, и служи када је усклађивање већ
> исправно. Обе имају исти облик, једну брзину кадрова или две, а њихово мешање не изазива
> никакву грешку.

```
subedit-cli framerate --from <fps> --to <fps>
                      (--output FILE | --output-dir DIR | --in-place)
                      [--dry-run]
                      [--recursive]
                      <file>...
```

Поново усклађује време датотеке усклађене за једну брзину кадрова на другу. То је
операција коју захтева датотека титлова када је преузета за примерак
који није онај филма који неко има — на пример, PAL DVD наспрам NTSC преноса.

Формат прочитане датотеке се **чува**: промена формата је посао подкоманде
[`convert`](convert.md).

<!-- example: subedit-cli framerate --help -->
```console
$ subedit-cli framerate --help
Re-time a file mastered at one frame rate for another
Usage: subedit-cli framerate [OPTIONS] files...

Positionals:
  files TEXT ... REQUIRED     Subtitle files to re-time

Options:
  -h,--help                   Print this help message and exit
  -r,--recursive              Take directories as inputs, and every subtitle file in them
  --from TEXT REQUIRED        Frame rate the file is timed at: 25, 23.976
  --to TEXT REQUIRED          Frame rate to time it for: 24, 29.97
  --output TEXT               File to write, for a single input
  --output-dir TEXT           Directory to write into
  --in-place                  Write back over the inputs
  --dry-run                   Work out and say what would be written, and write nothing
```

## Аргументи и опције

| Опција | Обавезно | Вредности | Подразумевано |
| :----- | :----- | :------ | :----- |
| `<file>...` | да | једна или више путања | — |
| `--recursive`, `-r` | не | опција без вредности | искључено — види [Обрада стабла директоријума](lots.md) |
| `--from` | **да** | брзина кадрова, види испод | — |
| `--to` | **да** | брзина кадрова, види испод | — |
| `--output` / `--output-dir` / `--in-place` | **једна од три**, осим са `--dry-run` | види [Покретање](invocation.md#одредиште) | — |
| `--dry-run` | не | опција без вредности: рачуна и јавља, ништа не пише — види [Прво видети, па писати](invocation.md#прво-видети-па-писати) | искључено |

Опција `--from` је брзина кадрова за коју је датотека **усклађена**, а `--to` она за коју
се жели. Замена једне другом помера датотеку у
супротном смеру — око седам секунди на дугометражном филму између 25 и
23.976 — и ништа то не јавља пре него што се филм погледа.

## Писање брзине кадрова

У кадровима у секунди, укључујући децимале, са тачком као раздвојником:

```
25      24      23.976      29.97      60
```

**Нула или негативна брзина кадрова се одбија**: то није брзина кадрова.

### Три NTSC брзине кадрова не могу се написати тачно

`23.976`, `29.97` и `59.94` су **ознаке**. Брзине кадрова које
именују јесу `24000/1001`, `30000/1001` и `60000/1001`, а ниједна нема
коначан децимални запис. Алат их као такве препознаје:

| Шта је написано | Шта именује |
| :------------- | :------------------ |
| `23.976` | `24000/1001` — филм пребачен на NTSC видео |
| `24` | `24` — филм |
| `25` | `25` — PAL и SECAM видео |
| `29.97` | `30000/1001` — NTSC видео |
| `30`, `50`, `60` | саме себе |
| `59.94` | `60000/1001` |

Препознавање се односи на **вредност, а не на знакове**: `23.9760`
именује исту брзину кадрова као `23.976`.

Свака друга децимала узима се дословно — `23.9` није ничији
стандард, ту се не може ништа прочитати. Управо зато је горња табела
потребна: без ње би `23.976` било `23976/1000`, а командна линија
би за исте речи говорила нешто друго него прозор.

## Шта положаји постају

```
t′ = round( t × (from / to) )
```

Филм усклађен на 23.976 и пуштен са 25 кадрова у секунди тече брже,
па његови титлови стижу раније; у супротном смеру стижу
касније.

**Чинилац је тачан рационалан број, а заокруживање се обавља само једном.** Пут
који изгледа једнако — претварање положаја у број кадра на
улазној брзини, па назад у милисекунде на излазној — то
није: сваки положај квантизује на улазној мрежи и греши до
пола кадра, измерено 21 ms. Види
[ADR 0013](../../../../adr/0013-mise-a-l-echelle-exacte-des-positions.md).

У пракси је од 25 до 23.976 чинилац `1001/960`:

| Прочитан положај | Записан | Шта би дао пролазак кроз кадрове |
| -----------: | -----: | -----------------------------------------: |
| `1 010 ms` | `1 053 ms` | `1 043 ms` |
| `3 600 017 ms` | `3 753 768 ms` | `3 753 750 ms` |

<!-- example: printf '1\n00:00:01,010 --> 00:00:02,020\nUn.\n\n' > a.srt; subedit-cli framerate --from 25 --to 23.976 --output b.srt a.srt; cat b.srt -->
```console
$ printf '1\n00:00:01,010 --> 00:00:02,020\nUn.\n\n' > a.srt; subedit-cli framerate --from 25 --to 23.976 --output b.srt a.srt; cat b.srt
a.srt: 1 subtitle retimed from 25 to 24000/1001 fps -> b.srt
1
00:00:01,053 --> 00:00:02,106
Un.
```

## Излаз

**Стандардни излаз** — ништа: резултат је записана датотека. Са `--dry-run` такође ништа: нема датотеке, а ред приповедања то каже — види [Прво видети, па писати](invocation.md#прво-видети-па-писати).

| Ниво | Шта се додаје на излаз грешака |
| :----- | :------------------------------------- |
| 1 | `<path>: N subtitles retimed from 25 to 24000/1001 fps -> <destination>` |
| 2 | `<path>: SubRip, UTF-8, no BOM, LF line endings kept` — формат, кодирање, ознака и завршеци редова прочитане датотеке, враћени какви су били |
| 3 | `<path>: N bytes read, M written`, затим **свака дијагностика читања** — види [Покретање](invocation.md#читање-дијагностике) |

**Приповедање именује тачну брзину кадрова, а не откуцану ознаку.** Писање
`23.976` у том реду јавило би претварање које се није десило; то је
једино место где се види која је од две употребљена. Брзина кадрова коју
децимала записује тачно приказује се ту као децимала, остале као разломак.

### У JSON-у

Са [`--format json`](invocation.md#излаз-који-скрипта-може-да-чита), објекат сваке датотеке носи `counts.subtitles` (сваки титл датотеке). Пуна табела је у одељку [Покретање](invocation.md#шта-свака-подкоманда-уписује-у-counts).

## Излазни кодови

Они самог алата: `0` ако је свака датотека записана, `2` ако ниједна није, `3` ако су
само неке, `1` при грешци у употреби.

Ниједно одбијање не зависи од садржаја датотеке: две брзине кадрова увек одређују
чинилац. То је једина од подкоманда које пишу чија сва
одбијања долазе пре првог читања.

<!-- example: printf '1\n00:00:01,010 --> 00:00:02,020\nUn.\n\n' > a.srt; subedit-cli framerate --from 0 --to 25 --output b.srt a.srt; echo "code=$?" -->
```console
$ printf '1\n00:00:01,010 --> 00:00:02,020\nUn.\n\n' > a.srt; subedit-cli framerate --from 0 --to 25 --output b.srt a.srt; echo "code=$?"
"0" is not a frame rate: a frame rate must be strictly positive; nothing runs at that speed
code=1
```

## Грешке

| Шта је изазива | Порука |
| :------------------ | :------ |
| нула или негативна брзина кадрова | `"…" is not a frame rate: a frame rate must be strictly positive; nothing runs at that speed` |
| децимални зарез | `"…" is not a frame rate: use a decimal point and not a comma, in every language` |
| текст који није број | `"…" is not a frame rate: expected frames per second, like 25 or 23.976` |
| претерано велика брзина кадрова | `"…" is not a frame rate: no video runs at that many frames per second` |

**Ништа се не пише без једне од три опције одредишта**, а њихове
грешке заједничке су подкомандама које пишу:
види [Покретање](invocation.md#одредиште).
