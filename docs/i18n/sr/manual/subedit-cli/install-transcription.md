# Инсталирање алата за транскрипцију

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

За транскрипцију звука у титлове — [`transcribe`](transcribe.md) у командној линији,
[`Transcribe Audio…`](../subedit-gui/video.md#транскрипција-звука) у прозору — потребне су три
ствари које **subedit не испоручује и не преузима**: мотор, модел за тај мотор и
`ffmpeg`. Ви их инсталирате и кажете subedit-у где се налази модел.

**Без њих ништа не престаје да ради.** Остатак програма ради као и пре; само се транскрипција
искључује, уз поруку која упућује овамо.

## Мотор: whisper.cpp

[whisper.cpp](https://github.com/ggml-org/whisper.cpp) је мотор који subedit покреће. То је програм,
`whisper-cli`, који ради на обичном процесору — графичка картица га само убрзава. Изградите га
како каже његова сопствена документација (довољни су C++ преводилац и CMake):

```bash
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -B build -DBUILD_SHARED_LIBS=OFF
cmake --build build -j --config Release
```

Програм је потом `build/bin/whisper-cli`. Изграђен са `-DBUILD_SHARED_LIBS=OFF`, као изнад, то је једна датотека којој поред себе није потребна никаква библиотека, па је можете копирати где год желите. Ставите га тамо где га `PATH` налази, или **наведите његову путању** subedit-у поставком `transcription.executable` — у прозору за то постоји поље у [поставкама](../subedit-gui/preferences.md#транскрипција). Градња за графичку картицу додаје једну опцију првом реду `cmake`: `-DGGML_CUDA=1` за NVIDIA картицу, `-DGGML_VULKAN=1` за већину осталих; subedit покреће ону коју сте инсталирали и ништа не бира уместо вас.

## Модел

Мотор чита **модел**, датотеку од неколико стотина мегабајта до неколико гигабајта коју
преузимате једном. Званични модели су наведени на
[huggingface.co/ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp), а
складиште мотора има скрипту која преузима један од њих:

```bash
sh ./models/download-ggml-model.sh small
```

Затим наведите његову путању са `--model` у командној линији, или поставком `transcription.model`,
или у [поставкама](../subedit-gui/preferences.md#транскрипција) прозора, које је памте.

### Који модел за који језик

Whisper не мења модел кад нађе језик: **модел који дате одређује шта
може.**

| Модел | Језици | Открива језик | Величина |
| :---- | :-------- | :------------------- | :--- |
| `tiny`, `base`, `small`, `medium`, `large-v3`, `large-v3-turbo` | око стотину | да | од око 75 MB до око 3 GB |
| `tiny.en`, `base.en`, `small.en`, `medium.en` | само енглески | не | као исте величине изнад |

- **За све осим енглеског узмите вишејезични модел** — онај чије име нема `.en`. Модел само за енглески
  одбија други језик: команда то каже пре било каквог рада.
- **Најмањи модели су приметно лошији ван енглеског.** За француски, немачки, шпански и
  слично, `small` је минимум, а `medium` или `large-v3-turbo` дају много боље резултате по цену
  више меморије и више времена.
- **Откривање језика је добро колико и модел.** Мали модел може погрешити на почетку састављеном од
  музике или тишине; кажите језик са `--language` кад га знате.

## ffmpeg

[`ffmpeg`](https://ffmpeg.org/download.html) издваја звучну нумеру филма, а `ffprobe`, који долази
уз њега, набраја нумере. Инсталирајте га менаџером пакета ваше дистрибуције. Без њега се звучна
датотека коју мотор чита каква јесте (`wav`, `mp3`, `flac`, `ogg`) и даље може транскрибовати, али филм
не може.

## Провера да ли ради

```bash
subedit-cli transcribe --model /path/to/ggml-small.bin --output film.srt film.mkv
```

Ако нешто недостаје, порука каже шта, и упућује на ову страницу.
