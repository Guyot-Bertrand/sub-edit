# subedit — приручник

<!-- machine-translated -->
> Ова страница је машински превод који још није прегледао читалац језика.

subedit чита, прегледа и поново усклађује време у датотекама титлова. Састоји се
од два програма који деле исто језгро, а тиме и иста правила и исте речи.

| Програм | Чему служи | Његов приручник |
| :-------- | :-------------- | :--------- |
| `subedit-gui` | отворити датотеку, видети је у табели, уређивати је, пратити је уз филм | [приручник прозора](subedit-gui/index.md) |
| `subedit-cli` | обрађивати датотеке у серијама, из скрипте, без сучеља | [приручник командне линије](subedit-cli/index.md) |

Оба читају и пишу **девет формата** — SubRip, WebVTT, SubViewer 2,
Sub Station Alpha, Advanced SSA, MicroDVD, MPL2, TMPlayer, LRC — и
препознају формат по садржају, а не по наставку. **И кодирање се
препознаје по садржају**: датотека у Latin-1, CP1252 или UTF-16
се отвара, јавља се како је прочитана, и записује се назад у свом кодирању —
датотека која се отвори па сачува без измене не помера се ни за један бајт.

## Шта овај приручник обећава

**Описује оно што постоји, никада оно што је планирано.** Шта ће доћи, и
којим редом, налази се у [мапи пута](../../../feuille-de-route.md).

**Овај приручник је писан на енглеском и преведен.** Преводи га прате
страницу по страницу, у директоријуму `docs/i18n/` спремишта, једно стабло по језику. Програми
говоре језиком свог окружења; називи које приказују — подкоманде,
опције, ставке менија — овде се наводе онако како их програм пише на енглеском.

**Примери и слике су генерисани, текст није.** Блокови `console`
добијају се стварним извршавањем команде; снимци екрана, градњом
правог прозора и његовим фотографисањем. Ниједно од та два
не може, дакле, описивати алат који више не постоји. Без мреже остаје
текст око њих, чија исправност почива на прегледу.

**Снимци екрана показују обе палете**, `Light` и `Dark` — оне које
[поставке](subedit-gui/preferences.md#тема) нуде.

## Два програма говоре исте речи

Један разлог да се чита било који приручник док се користи други: поруке
о грешкама, називи формата, пресуде о мрежи и ознаке опозива
пишу се **једном**, у језгру, а оба програма их
наводе. Одбијена датотека даје исту реченицу на обе стране.

Разликује се оно што свака површина може да уради:

| | `subedit-gui` | `subedit-cli` |
| :--- | :------------ | :------------ |
| више датотека одједном | да — један језичак по пројекту | да |
| превод уз главну датотеку | да | да — `-t` код текстуалних подкоманди, и [`pair`](subedit-cli/pair.md) да се поново усклади |
| прикачити датотеку, поделити пројекат | да | да — [`append`](subedit-cli/append.md), [`split-file`](subedit-cli/split-file.md) |
| опозив | да, хиљаду уноса | није применљиво — ништа се не мења на самој датотеци без питања |
| ручно уређивање текста или положаја | да | не |
| уметање, брисање, стапање и дељење редова | да | не |
| налажење и замена | да | да — [`replace`](subedit-cli/replace.md) |
| исецање, копирање и лепљење текстова | да | не |
| подешавање трајања, искошеног писма, величине слова, цртица | да | да — [`adjust`](subedit-cli/adjust.md), [`italics`](subedit-cli/italics.md), [`case`](subedit-cli/case.md), [`dialogue-dashes`](subedit-cli/dialogue-dashes.md) |
| исправљање текстова по обрасцима | да — `Correct Texts…` | да — [`correct`](subedit-cli/correct.md) |
| провера писања реч по реч | да — `Check Spelling…` | не |
| гледање филма током усклађивања времена | да | не |
| писање преко улаза | `Save` | `--in-place` |
