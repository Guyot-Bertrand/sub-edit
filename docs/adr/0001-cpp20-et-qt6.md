# 0001 — Write subedit in C++20 with Qt 6

**Date:** 2026-08-04
**Status:** accepted

## Context

subedit rewrites Gaupol, a subtitle editor written in Python with GTK 4, in a
compiled native language. Performance is not a measured pain but a cross-cutting
design goal: adopt data structures and algorithms that do not waste.

Two constraints frame the choice:

- **Linux first, portable later** — see [0003](0003-linux-d-abord.md). Any
  choice that would make a Windows port costly must be avoided.
- **A table view of several thousand rows** must stay smooth, which implies
  virtualised rendering.

## Decision

C++20 with Qt 6. The core library `subedit_core` is written in plain C++, with
no dependency on Qt, like Gaupol's `aeidon` package, which is independent of its
interface.

## Alternatives dismissed

- **Rust + GTK 4** — Rust is excellent at bulk text processing, and GTK 4 would
  be the closest to the original. But GTK's Windows support is precisely what
  led Gaupol to drop that platform as of version 1.3.1. Choosing GTK would mean
  inheriting the very problem we want to avoid.
- **Rust + a portable toolkit (Slint, Qt bindings)** — Slint is young and would
  require writing the virtualisation of the large table ourselves; the Rust
  bindings to Qt are fragile. The cost would fall on the most visible part of
  the application.
- **wxWidgets** — native everywhere, but its table views cope badly with large
  volumes.

## Consequences

Qt provides, without our writing them, a virtualised model/view, an
internationalisation foundation, a media player and identical rendering on the
three systems. The LGPLv3 licence with dynamic linking is compatible with the
project's GPL-3.0.

In return, C++ offers no memory guarantee by construction: the rules of
[docs/principes-de-conception.md](../principes-de-conception.md) and their
mechanisation in `make check` — clang-tidy, ASan with LeakSanitizer — are not
optional; they make up for what the language does not guarantee.

Keeping Qt out of the core is what will make it possible, should this choice be
reconsidered, to replace only the interface.
