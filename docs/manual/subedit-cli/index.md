# subedit-cli — manuel

Outil en ligne de commande de subedit : manipulation de fichiers de sous-titres
sans interface graphique, en traitement par lot ou depuis un script.

> **État actuel.** `subedit-cli` n'affiche que sa version. Les commandes de
> conversion, de décalage et de correction relèvent de la phase 3 du projet ;
> voir la [feuille de route](../../feuille-de-route.md). Ce manuel décrit ce qui
> existe, jamais ce qui est prévu.
