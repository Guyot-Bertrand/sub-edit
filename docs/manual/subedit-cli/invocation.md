# Invocation

```
subedit-cli
```

Affiche la version de la bibliothèque avec laquelle l'outil a été construit,
puis se termine.

```console
$ subedit-cli
subedit 0.1.0
```

## Code de retour

| Code | Signification |
| :--- | :------------ |
| `0` | succès |
